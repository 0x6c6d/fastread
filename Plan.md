## Architecture
- **cmd/fastread**: responsibility: flag parsing (stdlib `flag`, flags before the positional arg, `--` ends flags), validation, wiring, exit codes (0/1/2), one-line errors `fastread: <msg>` on stderr, resume save/delete, `signal.NotifyContext(ctx, SIGINT, SIGTERM)`. Core is `run(args []string, stdin io.Reader, stdout, stderr io.Writer, env func(string) string) int`, unit-testable; `main` only calls `os.Exit(run(...))`. `--version` prints `fastread <version>` (`-ldflags -X main.version`, default from `debug.ReadBuildInfo`, else `dev`). talks to: all internal packages.
- **internal/input**: source selection (R1), type detection by extension + magic (R2), loaders txt/md/epub/fb2/pdf (R3–R6), typed errors (R7, R12). Returns `Document{Paragraphs []string, Path string (abs, empty for raw/stdin), SHA256 [32]byte}`. Shared hardened helpers in `safe.go` (single place for: size-capped reads, capped zip opening/reading, XML decoder construction, recover-wrapper for the PDF library). Sentinels: `ErrNotFound`, `ErrCorruptEPUB`, `ErrEmpty`, `ErrUnsupported`, `ErrNoText` (message `no extractable text (scanned PDF?)`), `ErrCorruptPDF`, `ErrTooLarge`. talks to: stdlib `archive/zip`, `encoding/xml`, `golang.org/x/net/html`, `github.com/ledongthuc/pdf`.
- **internal/tokenize**: `Tokenize(paragraphs []string) []Token` with `Token{Text string; ParaEnd bool}`; splits on Unicode whitespace, punctuation stays attached; `Sanitize` drops C0, DEL, C1 and bidi control runes (U+202A–202E, U+2066–2069) from every token before any UI sees it; tokens empty after sanitising are dropped. talks to: nothing (stdlib + `rivo/uniseg`).
- **internal/orp**: `Position(word) int` = R9 table value on letter/digit grapheme clusters (the numbers in §8 AC7); `Index(word) int` = grapheme-cluster index of the focus cluster in the whole token (leading punctuation clusters + Position); zero letters/digits → middle cluster `(n-1)/2`. talks to: `rivo/uniseg`.
- **internal/timing**: constants (`SentenceMul=2.0`, `ClauseMul=1.5`, `LongWordStep=0.05`, `LongWordCap=0.5`, `LongWordFrom=8`, `ParagraphMul=2.5`) in one file; pure `Delay(word string, wpm int) time.Duration` (R10 signature) = `DelayPara(word, wpm, false)`; pure `DelayPara(word, wpm, paraEnd bool)`. talks to: nothing.
- **internal/state**: (a) `Player`: pure playback model, no I/O: index, playing, wpm, size, showProgress, showHelp; `Apply(Action) (quit bool)` with all R26 clamps; absolute-deadline scheduling (`next = prevDeadline + DelayPara(...)`, never `now + delay`); effective wpm from an injected `Clock` (words shown ÷ unpaused minutes). (b) resume `Store`: dir resolution (`$XDG_STATE_HOME` if absolute, else `$HOME/.local/state`) + `/fastread`, one file per source `<hex sha256(abs path)>.json` = `{"path","sha256","index"}`, atomic write (temp in same dir, fsync, rename), modes 0700/0600, `StartIndex(flagStart, noResume, saved, n)`. talks to: timing, filesystem.
- **internal/tui**: (a) pure renderer `Render(Model, w, h) Frame` (cell grid with style attributes) + `Encode(Frame, ColorMode) []byte` (ANSI); colour mode from `NO_COLOR`/`COLORTERM`/`TERM`; embedded block-glyph font (Go source tables) for sizes 2–5; R16 focus column, R17 fallback, R18 widths via `rivo/uniseg`, R19 ticks, R20 splitting, progress/help rows. (b) runtime: `Terminal` interface (real impl on `/dev/tty` with `golang.org/x/term` raw mode + `x/sys/unix` ioctl size; fake impl for tests), key decoder (bytes → Action), SIGWINCH, loop driven by `Player` deadlines with injectable `Clock`, alt-screen enter/restore on every exit path incl. panic. talks to: state, orp, timing, tokenize types.
- **internal/gui**: only package importing `gioui.org`. Files with Gio use `//go:build !nogui && cgo`; `stub.go` (`//go:build nogui || !cgo`) returns `ErrUnavailable` from `Run` without importing Gio. `layout.go` imports no Gio package: pure `Layout(LayoutInput) LayoutResult` over advances in `golang.org/x/image/math/fixed.Int26_6` (focus x, origin x, baseline y, tick rects, shrink/split decision). Window loop: Gio events, `op.InvalidateCmd{At: deadline}` for timing, embedded `goregular` font via `text.NewShaper(text.NoSystemFonts(), ...)`. Exit path: `Run(ctx, opts, finish func(last int, err error))` returns an error synchronously when no display env or stub; otherwise runs the window loop in a goroutine and calls `app.Main()` (never returns on Linux), and the goroutine calls `finish` exactly once (cmd's `finish` saves state, prints, `os.Exit`). talks to: state, orp, timing.
- **e2e/** (build tag `e2e`, excluded from `go test ./...`): Go tests that `go build` the binary into `t.TempDir()`, drive it via an isolated tmux server (`tmux -L fastread-e2e-<pid>`, fixed size, `capture-pane -e -p`) or `Xvfb -displayfd` + `xdotool`; temp `XDG_STATE_HOME`; every external call under a context timeout.
- **Data flow:** args/stdin → input.Select/Load → Document → tokenize → []Token (empty → ErrEmpty) → state.StartIndex (Store lookup for files only) → tui.Run / gui.Run with Player → last index → Store.Save / Delete (files only) → exit code.
- **Test-name convention** (exit criteria rely on it): `passes T P` := `go test -count=1 -run "^T\$" -v ./P 2>&1 | grep -q -- "--- PASS: T"` (proves the test exists and passes). Golden files under `internal/tui/testdata/golden/`, regenerated only with `go test ./internal/tui -update`.

## Model-Routing Policy
- **haiku**: clear boundary, small diff, mechanically verifiable. Examples: `LICENSE` + `third_party/*/LICENSE` files; `timing` constants file and base `Delay` table test; converting font8x8 arrays into Go tables in `internal/tui/glyph` (verified by goldens/row counts).
- **sonnet** (default): multi-file features, moderate design judgment. Examples: Markdown stripper and FB2 loader (calling only the opus-owned `safe.go` helpers); `state.Player` key model + effective wpm; TUI `Render`/goldens/split/progress; GUI pure `Layout` math; `docs/usage.md`; e2e tmux tests.
- **opus**: architecture, security, concurrency, Consequential assumptions. Examples: `internal/input/safe.go` (size caps, capped zip reader, XML decoder config, PDF recover wrapper), EPUB loader (zip-entry path resolution, DRM detection), PDF loader, `tokenize.Sanitize` and `Encode` control stripping; resume `Store` (privacy, modes, atomic writes); source selection/A3 heuristic and CLI contract (rows 2–3); TUI terminal/loop/signals/restore/leak test; Gio window loop + `app.Main`/`finish` exit path; walking skeleton (fixes every seam and the dependency pins, row 4).
- **Rule:** quality first, then cost; never pick a lower tier if a wrong result costs more to redo. A security or Consequential rule beats a cost example. Security-critical logic lives in shared opus-built code (`internal/input/safe.go`, `tokenize.Sanitize`, `tui.Encode`'s stripping, `state.Store` write path, the single `ledongthuc/pdf` call site); modules that only call it (Markdown, FB2, TXT loaders; GUI drawing) may be sonnet, and the supervisor then runs the negative checks (oversized input, hostile zip, escape-sequence text, bad modes) itself.

## Risks & Open Questions
- **x11-xcb missing (row 5):** full cgo build of Gio fails today; T000 blocks until `sudo apt install libx11-xcb-dev`. Nothing in the loop may work around it (no `nox11` tag: X11 is required for the Xvfb check).
- **Toolchain drift (row 4):** any `go get ...@latest` raises `go.mod` to 1.26 and triggers a toolchain download under `GOTOOLCHAIN=auto`. Mitigation: pins, `GOTOOLCHAIN=local` in D2 and dependency tasks; opus for the task that sets `go.mod`.
- **Gio v0.10.3 is 10 days old (released 2026-09-28):** API/behaviour on no-display and `DestroyEvent.Err` paths unverified; covered by TestE2EGUINoDisplay/TestE2EGUIBadDisplay; fallback pin `v0.10.2` (2026-08-10) if a regression blocks, logged as a Changelog entry.
- **Untrusted parsing (rows 11, 13, 14, 16):** zip bombs, path tricks, XML, PDF library panics; opus + negative tests (TestEPUBLimits, TestEPUBCorrupt, TestPDFCorrupt, TestEncodeStripsControls).
- **Terminal escape injection:** sanitising in tokenizer and again in `Encode`; negative test with ESC/CSI/OSC/C1 bytes in input.
- **Resume privacy and data (rows 21, 22):** state may contain absolute paths (sensitive); modes 0700/0600, no text, tests only under temp `XDG_STATE_HOME`; never touch the real `~/.local/state` in tests (supervisor checks `git status` and that `~/.local/state/fastread` was not created by the run).
- **CLI contract (rows 2, 3):** path-like heuristic and single-argument rule are public behaviour; documented in `docs/usage.md`; changing later breaks scripts.
- **DRM/legal (rows 13, 39):** encrypted EPUBs rejected, never decrypted; licence texts shipped; font8x8 is public domain (notice kept).
- **GUI exit path (row 8):** `app.Main` never returns; a missed `finish` call leaves state unsaved or the process hanging; opus + TestE2EGUIXvfb asserts exit 0 within a timeout.
- **Flaky timing/leak tests under `-race` or load (rows 32, 33):** generous bounds, fake clocks, polling; a flaky test is a failure to fix, not to retry.
- **`/dev/tty` dependence (row 24):** tests use the fake `Terminal`; e2e uses tmux ptys only.
- **Wayland unverified (row 37):** reported "not run"; X11 path only.
- **Third-party maintenance:** `ledongthuc/pdf` lightly maintained; alternative `pdfcpu` recorded in spec; swap is contained behind the single wrapper.
