# T003: ORP focus index skeleton

Phase 1 · Model: opus: adds the first third-party dependency to `go.mod` under the toolchain pins (Consequential assumption, Risk: toolchain drift) · Depends-on: T001

## Brief
Create package `internal/orp`, which picks the focus (ORP) grapheme cluster of a word. It adds
the dependency `github.com/rivo/uniseg` pinned at `v0.4.7`.

Dependency: run exactly `GOTOOLCHAIN=local go get github.com/rivo/uniseg@v0.4.7` after the import
exists (then `GOTOOLCHAIN=local go mod tidy` is allowed). Afterwards `go.mod` must still say
`go 1.24.x` and must not contain a toolchain newer than go1.24.

Definitions (contract for all later tasks, both UIs use them):
- Split the token into extended grapheme clusters with `uniseg` (e.g. `uniseg.NewGraphemes` or
  `uniseg.FirstGraphemeClusterInString`).
- A cluster is a *letter/digit cluster* iff its first rune satisfies `unicode.IsLetter` or
  `unicode.IsDigit`.
- `L` = number of letter/digit clusters. R9 table: L=1 → 0; 2–5 → 1; 6–9 → 2; 10–13 → 3;
  14+ → 4.

File `internal/orp/orp.go`, package doc "Package orp computes the optimal recognition point
(focus cluster) of a word. It must never import UI packages." Exactly this exported API:
```go
// Position returns the R9 table value for word: the rank of the focus cluster among the
// word's letter/digit clusters. If the word has no letter/digit cluster it returns (n-1)/2
// where n is the number of grapheme clusters (0 for the empty string).
func Position(word string) int

// Index returns the 0-based grapheme-cluster index of the focus cluster within the whole
// word (leading punctuation counted): the index of the letter/digit cluster with rank
// Position(word). With no letter/digit cluster it returns (n-1)/2 (0 for "").
func Index(word string) int

// Clusters returns the word's extended grapheme clusters in order (nil for "").
func Clusters(word string) []string
```
Never split a cluster; never panic on any input (empty string, invalid UTF-8, lone combining
mark, emoji ZWJ sequences).

File `internal/orp/orp_test.go`, table-driven:
- `TestPositionBasic`: `a`→0, `ab`→1, `hello`→1, `wonderful`→2, `reading,`→2,
  `"extraordinary"` (with the double quotes)→3, `internationally`→4, `--`→0, `—`→0, `...`→1,
  `""` (empty string)→0.
- `TestIndexBasic`: `a`→0, `hello`→1, `"hello"`→2, `(wonderful)`→3, `"extraordinary"`→4,
  `--`→0, `...`→1, `don't`→1, `""`→0.
- `TestNoPanic`: Position/Index/Clusters on `"\xff\xfe"`, `"́"`, `"👩‍👩‍👧"`, `"éé"`
  return values with `0 <= Index < max(1, len(Clusters))`.

Constraints: imports only the standard library and `github.com/rivo/uniseg`; no UI imports.
