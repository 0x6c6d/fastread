# T027: Full tokenizer (paragraph breaks, Sanitize)

Phase 3 · Model: opus: `Sanitize` is the first defence against terminal-escape injection from untrusted text (§5 security, Risk "Terminal escape injection") · Depends-on: T002

## Brief
Complete package `internal/tokenize` (module `github.com/0x6c6d/fastread`) for R8 and the §5
rule that text from input files never reaches a UI with control characters. Existing (keep
the names, signatures and the passing test `TestTokenizeBasic` unchanged):
```go
type Token struct {
    Text    string
    ParaEnd bool
}
func Tokenize(paragraphs []string) []Token
```

Add to `internal/tokenize/tokenize.go` (or a new `sanitize.go` in the same package):
```go
// Sanitize returns s with every invalid UTF-8 byte sequence replaced by U+FFFD and these
// runes removed: C0 controls U+0000–U+001F, DEL U+007F, C1 controls U+0080–U+009F, bidi
// embedding/override/isolate controls U+202A–U+202E and U+2066–U+2069. Every other rune is
// kept unchanged (combining marks, ZWJ U+200D, LRM U+200E, emoji, U+FFFD, NBSP). Pure; when
// nothing changes it returns s without allocating.
func Sanitize(s string) string
```
Note a raw byte `0x9B` is invalid UTF-8 and is an 8-bit CSI on some terminals: it must come
out as U+FFFD, never as the byte.

New `Tokenize` semantics (document them in its doc comment):
1. Each input paragraph is first split further into paragraphs at blank lines (a line,
   delimited by `\n`, `\r\n` or `\r`, that is empty or contains only `unicode.IsSpace` runes)
   and at U+2029 PARAGRAPH SEPARATOR. U+2028 LINE SEPARATOR is plain whitespace.
2. Each paragraph is split on `unicode.IsSpace` into fields; punctuation stays attached.
3. Each field is passed through `Sanitize`; fields that become empty are dropped.
4. `ParaEnd` is set on the last surviving token of each paragraph (so a dropped
   control-only last field moves `ParaEnd` to the previous token); a paragraph with no
   surviving token adds nothing. The last token of the whole result has `ParaEnd` true.
5. One pass over the input, no `regexp`, no per-rune string concatenation: loading and
   tokenizing 5 MB must stay well under 2 s (an existing perf test may exercise this).
