# T005: Input skeleton (source selection, raw text and stdin)

Phase 1 · Model: opus: source selection is the CLI contract of Consequential assumption 2 and fixes the typed-error API every loader uses · Depends-on: T001

## Brief
Create package `internal/input` with the typed errors, the `Document` type, source selection and
the raw-text/stdin loaders. File loaders (txt, md, epub, fb2, pdf), the size-capped helpers and the
"looks like a path" heuristic come in later tasks; do not add them here.

Files to create:
- `internal/input/errors.go`, exactly these sentinels (later tasks wrap them with `%w`):
  ```go
  var (
      ErrNotFound    = errors.New("file not found")
      ErrCorruptEPUB = errors.New("corrupt EPUB")
      ErrEmpty       = errors.New("empty text")
      ErrUnsupported = errors.New("unsupported file type")
      ErrNoText      = errors.New("no extractable text (scanned PDF?)")
      ErrCorruptPDF  = errors.New("corrupt PDF")
      ErrTooLarge    = errors.New("input too large")
      ErrNoInput     = errors.New("no input: give text or a file, or pipe text on stdin")
  )
  ```
- `internal/input/input.go`, package doc "Package input selects and loads the text source. It
  must never import UI packages." Exactly this API:
  ```go
  // Document is loaded text split into paragraphs.
  type Document struct {
      Paragraphs []string
      Path       string   // absolute path of a file source; "" for raw text and stdin
      SHA256     [32]byte // SHA-256 of the file bytes; zero for raw text and stdin
  }

  type Kind int
  const (
      KindRaw Kind = iota // the positional argument is the text
      KindStdin           // read stdin
      KindFile            // the positional argument is an existing file
  )

  type Source struct {
      Kind Kind
      Text string // KindRaw: the argument
      Path string // KindFile: the argument as given
  }

  // Select applies R1. hasArg reports whether a positional argument was given.
  //  - hasArg and os.Stat(arg) finds a regular file  -> KindFile
  //  - hasArg and arg is an existing directory       -> error wrapping ErrUnsupported
  //  - hasArg otherwise                              -> KindRaw (path heuristic added later)
  //  - !hasArg and stdinIsTTY                        -> ErrNoInput (caller exits 2 with usage)
  //  - !hasArg and !stdinIsTTY                       -> KindStdin
  func Select(arg string, hasArg, stdinIsTTY bool) (Source, error)

  // Load returns the document for src. KindRaw: ParseText of the text. KindStdin: reads all of
  // stdin, then ParseText. KindFile: not implemented in the walking skeleton, returns an error
  // wrapping ErrUnsupported ("file input not implemented yet"). Read errors are wrapped with %w.
  func Load(src Source, stdin io.Reader) (Document, error)

  // ParseText decodes b as UTF-8 and splits it into paragraphs:
  // invalid UTF-8 bytes -> U+FFFD; a leading BOM (EF BB BF) is dropped; CRLF and lone CR -> LF;
  // a paragraph is a run of lines separated by one or more blank (whitespace-only) lines;
  // lines of a paragraph are joined with "\n"; no empty or whitespace-only paragraphs.
  func ParseText(b []byte) []string
  ```
  Do not cap or limit the stdin read in this task (a later security task routes all reads through
  one size-capped helper); do not tokenize here; `ErrEmpty` is raised by the caller after
  tokenizing.
- `internal/input/input_test.go`, table-driven:
  - `TestParseText`: `"a b\n\nc"` → `["a b","c"]`; `"\xEF\xBB\xBFhi"` → `["hi"]`; `"x\r\ny\r\rz"`
    → `["x\ny","z"]`; `"a\n \t\nb"` → `["a","b"]`; `"bad\xffbyte"` → `["bad�byte"]`;
    `""` and `"\n\n  \n"` → no paragraphs.
  - `TestSelectBasic` (use `t.TempDir()`): existing regular file → KindFile with Path as given;
    the temp dir itself → `errors.Is(err, ErrUnsupported)`; `"Hello wonderful world"` → KindRaw;
    no arg + TTY → `errors.Is(err, ErrNoInput)`; no arg + not TTY → KindStdin.
  - `TestLoadRawStdin`: raw `"a b\n\nc"` → 2 paragraphs, Path "" and zero SHA256; stdin from
    `strings.NewReader("x y")` → `["x y"]`; a reader that returns an error → non-nil error;
    KindFile → `errors.Is(err, ErrUnsupported)`.
  - `TestErrorMessages`: `ErrNoText.Error() == "no extractable text (scanned PDF?)"` and all eight
    sentinels are distinct (`errors.Is` false pairwise).

Constraints: standard library only; no UI imports; never write to the filesystem outside
`t.TempDir()`.
