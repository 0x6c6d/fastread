# T038: Block-glyph sizes 2-5 with size and rune fallback

Phase 4 · Model: sonnet: pure layout over a given glyph API, every number pinned by table tests · Depends-on: T006, T037

## Brief
Package `internal/tui` (module `github.com/0x6c6d/fastread`) renders frames; today `Render`
draws every size as level-1 text. Add block glyphs for sizes 2–5 (R15) and the automatic
size fallback (R17). Existing API (keep; extend only as stated):
```go
type Style uint8 // StylePlain, StyleFocus, StyleTick
type Cell struct { Text string; Style Style; Cont bool } // Text "" = blank cell
type Frame struct { W, H int; Cells [][]Cell }           // Cells[y][x]
type Model struct { Word string; Size int; Paused, ShowProgress, ShowHelp bool
    Index, Total, WPM, EffectiveWPM int }
func FocusColumn(w int) int // w/2
func Render(m Model, w, h int) Frame
```
Level 1 (exists, keep): clusters `cs := orp.Clusters(word)`, focus `fi := orp.Index(word)`;
the focus cluster starts at column w/2, the others are placed left and right of it by display
width (`uniseg.StringWidth`), a 2-wide cluster uses a second `Cont` cell.
Glyph API (package `internal/tui/glyph`, exists): `Rows(size)` 1,3,5,7,9; `Width(size)`
1,4,6,8,10; `Has(r rune) bool`; `Block(r, size) (rows []string, ok bool)` = `Rows` strings
of `Width` runes from `' ' '▀' '▄' '█'`.

Add:
1. Field `Size int` in `Frame`: the size level actually drawn; 0 when nothing is drawn.
2. `internal/tui/layout.go`:
   ```go
   // EffectiveSize returns the size level Render uses for word at w x h:
   // 0 if w < 20 or h < 5; otherwise s := clamp(size, 1, 5), decreased while s >= 2 and
   // not (glyph.Rows(s)+4 <= h && w-w/2 >= 2*glyph.Width(s)-glyph.Width(s)/2);
   // then 1 if s >= 2 and some grapheme cluster of word is not exactly one rune r with
   // glyph.Has(r) (R15 fallback for the whole word); else s.
   func EffectiveSize(word string, size, w, h int) int
   ```
   (The width condition makes a two-glyph display step fit: size 4 needs w ≥ 23, size 5
   w ≥ 29.)
3. `Render`: `s := EffectiveSize(m.Word, m.Size, w, h)`; `Frame.Size = s`. s == 0 → every
   cell blank `StylePlain` (a later task adds the too-small text). Word rows:
   `R := glyph.Rows(s)`, `y0 := h/2 - (R-1)/2`, rows y0..y0+R−1 (level 1 stays on row h/2).
   Size ≥ 2: `W := glyph.Width(s)`; glyph box k (cluster k) covers columns
   `x_k = w/2 - W/2 + (k-fi)*W` .. x_k+W−1 and rows y0..y0+R−1 (focus column w/2 = focus box
   start + W/2); cell (x_k+i, y0+j) = rune i of `Block(...)[j]`: `' '` → blank cell, else
   `Text` = that rune. All R×W cells of the focus box get `StyleFocus` (blank ones too, so
   NO_COLOR reverse video shows the whole box); every other cell `StylePlain`. Cells outside
   the frame are skipped, never a panic. Rows 0 and h−1 stay free (help/progress, later).

Tests, `internal/tui/glyph_render_test.go`, table-driven (helpers in the file):
- `TestSizeFallback`: `Model{Word: "Hello", Size: 5}`, w×h → `Frame.Size`: 80×24→5,
  29×24→5, 28×24→4, 23×24→4, 22×24→3, 20×24→3, 80×13→5, 80×12→4, 80×11→4, 80×10→3,
  80×9→3, 40×8→2, 40×7→2, 40×6→1, 40×5→1, 19×4→0, 19×24→0, 80×4→0; Size 3 at 80×24→3;
  Size 1, 0, −2 → 1; Size 9 → 5. Each equals `EffectiveSize`. The AC14 sequence
  80×24 → 40×8 → 19×4 gives 5, 2, 0 without panic. For every case with Size ≥ 1: the rows
  holding a `StyleFocus` cell are exactly y0..y0+R−1 per the formula, `y0-1 >= 1` and
  `y0+R <= h-2`.
- `TestGlyphFallback`: sizes 2–5 at 80×24 (`Frame.Size` = requested size): `Hello`, `naïve`
  (U+00EF), `¿Qué?`, `ÆØÅ`, `a`, `x-y`, `©2026`: the `StyleFocus` cells are exactly the W×R
  rectangle starting at (w/2 − W/2, y0); every glyph box k equals `glyph.Block` of rune k
  (ink → Text, `' '` → ""). Fallback words at sizes 2–5 → `Frame.Size` 1: `日本`,
  `nai\u0308ve` (decomposed), `€5`, `Ωmega`, `“quoted”`, `👍`, `e\u0301`: exactly one
  `StyleFocus` cell, at (w/2, h/2), with `Text == orp.Clusters(w)[orp.Index(w)]`.
