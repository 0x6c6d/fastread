Phase 7 · Model: opus: licence texts are Consequential assumption row 39 and Risk "DRM/legal" (legal high-risk), pinned to opus however small; the content is fixed byte for byte by the script · Depends-on: T008, T037

## Brief
Ship the licence texts of the two embedded fonts (spec §5 legal, Plan row 39). Create exactly
these two files and nothing else (the root `LICENSE` already exists; do not touch it):

1. `third_party/gofont/LICENSE`: a byte-for-byte copy of the Go fonts licence as shipped in
   the pinned module `golang.org/x/image v0.36.0` (the GUI embeds
   `golang.org/x/image/font/gofont/goregular`). The source file is
   `$(GOTOOLCHAIN=local go list -m -f '{{.Dir}}' golang.org/x/image)/font/gofont/ttfs/README`
   (the Bigelow & Holmes BSD-style licence text, starting `These fonts were created by the
   Bigelow & Holmes foundry`). Copy it with `cp` (the module cache is read-only; the copy
   must be a normal writable file, mode 0644: `chmod 0644` after copying). Do not edit,
   reflow or add to it.

2. `third_party/misc-fixed/LICENSE`: the public-domain notice of the X11 misc-fixed fonts
   (X.Org `font-misc-misc`) from which `internal/tui/glyph/gen.go` generated the TUI block
   glyphs. Write exactly the text between the two marker lines below (ASCII, LF line endings,
   a single trailing newline after the last line, two spaces after each `font.` inside the
   quoted notices, no trailing spaces, no tabs):

==================================================

generated by internal/tui/glyph/gen.go from these public-domain fonts, as installed by the
Debian package xfonts-base under /usr/share/fonts/X11/misc/:

  size 2  4x6-ISO8859-1.pcf.gz   COPYRIGHT "Public domain font.  Share and enjoy."

  size 4  7x14-ISO8859-1.pcf.gz  COPYRIGHT "Public domain font.  Share and enjoy."
  size 5  9x18-ISO8859-1.pcf.gz  COPYRIGHT "Public domain font.  Share and enjoy."

font-misc-misc/COPYING:

Constraints: only these two files under `third_party/`; no Go code; no network (the module is
already in the module cache); do not change `go.mod`/`go.sum`.
