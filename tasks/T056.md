# T056: Phase 5 gate: live keys e2e and the exit criterion

Phase 5 · Model: sonnet: one e2e test on the existing harness and parser; the script runs the Phase 5 exit criterion · Depends-on: T050, T051, T052, T053, T054, T055

## Brief
Package `e2e` (module `github.com/0x6c6d/fastread`; every file starts with `//go:build e2e`,
`_test.go` suffix). Existing helpers (do not change signatures): `e2e/helpers_test.go`
(`buildBinary`, `stateEnv`, `newTmux`, `capture`, `sendKeys` with tmux key names, `resize`,
`waitFor`, `watchWords`, shell quoting), `e2e/screen_test.go` (`parseScreen`, `focusCols`,
`tickCols`), `e2e/proc_test.go` (`paneState`, `appPID`); `internal/tui`: `HelpText`
(row 0 when help is on), progress row h−1 = bar + `word i/N  E wpm`; `glyph.Rows(size)`.

Behaviour under test (R26-R28 live, through real tmux key sequences: Right `ESC[C`, Left
`ESC[D`, Up `ESC[A`, Down `ESC[B`, Home `ESC[1~`, PPage `ESC[5~`, F1 `ESCOP`, Escape lone
`ESC`): Space pause/resume; Left/Right ±1 word paused, ±10 playing; Home → word 0; Up/Down
wpm ±25; `[`/`]` size −1/+1 (1–5); `p` toggles the progress row; `?` toggles the help row;
`q`/Esc/Ctrl+C quit with exit 0; other keys do nothing.

Create `e2e/keys_test.go`, `TestE2EKeys`: tmux 80×24, `--no-resume --size 1 --wpm 50`, 200
words `k000`…`k199` as raw text. Word on screen = first `k[0-9]{3}` of `capture(false)`; a
screen is accepted only when two consecutive captures are identical; every expectation is
polled up to 2 s. Steps: wait for `k000`; `Space` (paused; note word n); `PPage`, `F1`, `x`,
`Q` → after 500 ms same word n, no `EXIT:` line; `Right` → n+1; `Right` → n+2; `Left` →
n+1; `Home` → `k000`; `]` → two ticks `glyph.Rows(2)+1` rows apart at column 40; `[` → back
to size 1 (tick rows 2 apart); progress row shows `word 1/200`; `p` → no line contains
`word 1/`; `p` → shown again; `?` → row 0 starts with `space pause`; `?` → row 0 blank;
`Up` and `Down` → still running, same word; `Space` (playing) then `Right` → a word ≥ 10
within 1 s; `Escape` → `EXIT:0` within 2 s and `paneState` main screen, cursor visible.
Log the screen of the failing step.

Constraints: create only `e2e/keys_test.go`; never use the default tmux server, the user's
sessions or the real `~/.local/state`; every external call under a timeout; whole test well
under 120 s; `go vet -tags e2e ./...` clean. If a step fails because of program behaviour,
report the key, the expected and the seen screen; do not change non-test code.
