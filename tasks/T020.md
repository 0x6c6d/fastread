# T020: FB2 loader (body text only)

Phase 2 · Model: sonnet: XML walk on top of the hardened opus-built decoder helpers; the supervisor runs the negative checks · Depends-on: T015

## Brief
Replace the stub in `internal/input/fb2.go` (package `input`, module
`github.com/0x6c6d/fastread`) with the real FB2 loader. Keep the exact signature:
```go
func loadFB2(b []byte, lim Limits) ([]string, error)
```
Existing helpers you must use (in `safe.go`, do not change): `newXMLDecoder(r io.Reader)
*xml.Decoder` (non-strict, HTML entities, never resolves external entities; non-UTF-8
encodings → error wrapping `ErrUnsupported`) and `walkXML(d *xml.Decoder, maxDepth int, fn
func(tok xml.Token, depth int) error) error` (depth above `maxDepth` → `ErrTooLarge`). Never
call `xml.NewDecoder` yourself. Also existing: `Limits{MaxBytes int64; MaxEntries, MaxDepth
int}`, `DefaultLimits()`, `LoadFile(path string) (Document, error)` (detects FB2 by the
`<FictionBook` root), `fixtureFile(t *testing.T, name string, data []byte) string` in
`fixture_test.go` (writes `testdata/<name>` only with `-update-fixtures`, else requires it).

Rules (R5): text comes only from inside `body` elements (every `body`, including
`<body name="notes">`, in document order); `description`, `binary` and anything outside a body
are ignored. Match element local names only (`Name.Local`), so the default FB2 namespace and
prefixes such as `fb:body` work. A paragraph ends at the start and at the end of each of
`p v subtitle title text-author date empty-line section epigraph poem stanza cite table tr`;
inline elements (`emphasis strong a style sup sub strikethrough code`) never split a word
(`wo<emphasis>rd</emphasis>` → `word`); `image` yields nothing. Only `xml.CharData` contributes
text (comments, directives and processing instructions are ignored). A paragraph is its text
with whitespace runs collapsed to one space and trimmed; empty paragraphs are dropped.
Errors: walk/syntax errors → `fmt.Errorf("invalid FB2: %w", err)` (keeps `ErrTooLarge` and
`ErrUnsupported` matchable); a document without body text → no paragraphs and no error (the
caller reports empty text). Never panics.

Fixture `internal/input/testdata/sample.fb2` (create via the test with `-update-fixtures`;
UTF-8; exactly this structure):
```xml
<?xml version="1.0" encoding="UTF-8"?>
<FictionBook xmlns="http://www.gribuser.ru/xml/fictionbook/2.0" xmlns:l="http://www.w3.org/1999/xlink">
<description><title-info><book-title>Hidden Title</book-title>
<annotation><p>Hidden annotation</p></annotation></title-info></description>
<body><title><p>Body Title</p></title>
<section><p>First body paragraph.</p><p>Second <emphasis>body</emphasis> paragraph.</p></section></body>
<body name="notes"><section><p>Note text.</p></section></body>
<binary id="c.jpg" content-type="image/jpeg">SGlkZGVu</binary>
</FictionBook>
```

`internal/input/fb2_test.go`, table-driven `TestFB2BodyOnly` (AC4):
- the fixture via `LoadFile(fixtureFile(t, "sample.fb2", data))` → paragraphs exactly
  `["Body Title", "First body paragraph.", "Second body paragraph.", "Note text."]`; no
  paragraph contains `Hidden` or `SGlkZGVu`.
- direct `loadFB2` rows: `fb:` prefixed elements with `xmlns:fb` → body text found;
  `<p>wo<emphasis>rd</emphasis> &amp; more&#160;text</p>` → `["word & more text"]`;
  `<v>line one</v><v>line two</v>` inside `stanza` → two paragraphs; a body with only an
  `image` → no paragraphs, nil error; no `body` at all → no paragraphs, nil error.
- negative rows: a DOCTYPE declaring `<!ENTITY x SYSTEM "file:///<temp file>">` used as
  `&x;` in a body paragraph never yields the temp file's content `SECRET`;
  `encoding="windows-1251"` → `errors.Is(err, ErrUnsupported)`; 300 nested `section`s with
  `Limits{MaxDepth: 256, …}` → `errors.Is(err, ErrTooLarge)`; input cut off inside a tag →
  non-nil error, no panic; 1 MiB of body paragraphs loads in under 2 s (20 s under `-race`,
  using the package's `raceEnabled` test constant if one exists, else a plain generous 20 s
  bound).

Constraints: stdlib only; change only `fb2.go`, `fb2_test.go` and the fixture.

## Verification
`scripts/verify/T020.sh` exits 0. It runs the check command, `TestFB2BodyOnly` (also with
`-race`) and the detection/load tests, checks the fixture and that `fb2.go` uses `walkXML`
and not `xml.NewDecoder`. Negative checks: an FB2 file with text only in `<description>`
exits 1 with `empty text`; an FB2 file nested 300 deep exits 1 with one line containing
`too large`.
