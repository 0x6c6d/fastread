# T014: Source selection with the path-like rule (A3)

## Brief
Finish R1/R7 source selection in package `internal/input` (module
`github.com/0x6c6d/fastread`). Keep the exact signature and the existing `Source`/`Kind` types:
```go
func Select(arg string, hasArg, stdinIsTTY bool) (Source, error)
```
`Select` currently lives in `internal/input/input.go`; move it into a new
`internal/input/select.go` (delete it from `input.go`), together with:
```go
// LooksLikePath reports whether arg, which is not an existing file, should be treated as a
// mistyped path rather than as raw text.
func LooksLikePath(arg string) bool
```
Rule (exact): `arg` contains no Unicode whitespace (`unicode.IsSpace`) AND at least one of:
contains `/`; starts with `.`; starts with `~`; ends, case-insensitively, in `.txt`, `.md`,
`.epub`, `.fb2` or `.pdf`. The empty string is not path-like.

`Select` decision table (first match wins):
1. `!hasArg && stdinIsTTY` → error wrapping `ErrNoInput`; `!hasArg && !stdinIsTTY` → `KindStdin`.
2. `os.Stat(arg)` succeeds: regular file → `KindFile{Path: arg}`; directory → error wrapping
   `ErrUnsupported` (message names the argument and says it is a directory); any other file type
   (FIFO, socket, device) → error wrapping `ErrUnsupported` ("not a regular file"), so a FIFO is
   never opened and cannot block.
3. `os.Stat` fails (any error: not-exist, ENOTDIR, ENAMETOOLONG, EACCES):
   `LooksLikePath(arg)` → error `fmt.Errorf("%s: %w", arg, ErrNotFound)`; otherwise `KindRaw`
   with `Text: arg`.
No tilde expansion (the shell does that), no `-` alias for stdin, no filesystem writes.
Error messages are one line (no newline even when `arg` contains one; raw text with newlines
is never path-like because a newline is whitespace).

`internal/input/select_test.go` (package `input`, table-driven, files only in `t.TempDir()`):
