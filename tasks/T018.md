# T018: EPUB loader (container, OPF spine, zip-entry resolution)

Phase 2 · Model: opus: untrusted zip/XML input, zip entry names must never become paths (R4; Consequential assumptions 11 and 13; Risk "untrusted parsing") · Depends-on: T015, T017

## Brief
Replace the stub in `internal/input/epub.go` (package `input`, module
`github.com/0x6c6d/fastread`) with the real loader. Existing helpers you must use (do not
change them): in `safe.go` `Limits{MaxBytes int64; MaxEntries, MaxDepth int}`,
`DefaultLimits()`, `openZip(b []byte, lim Limits) (*zipArchive, error)`, `(*zipArchive).has(name
string) bool`, `(*zipArchive).read(name string) ([]byte, error)` (one decompression budget per
archive; errors already wrap `ErrCorruptEPUB`, plus `ErrTooLarge` when over budget),
`newXMLDecoder(r io.Reader) *xml.Decoder`, `walkXML(d, maxDepth, fn)`; in `xhtml.go`
`xhtmlParagraphs(b []byte) []string`; in `load.go` `LoadFile(path string) (Document, error)`;
in `fixture_test.go` `fixtureFile(t, name, data) string` (writes `testdata/<name>` only with
`-update-fixtures`, else requires it to exist).

`internal/input/epub.go`, exactly these functions:
```go

// epubSpine returns the zip entry names of the linear spine items in spine order.
func epubSpine(z *zipArchive, lim Limits) ([]string, error)
```
`loadEPUB` = `openZip` → `epubSpine` → for each name `z.read(name)` → `xhtmlParagraphs` →
concatenate. (A later DRM task inserts a check between `epubSpine` and the reads; keep that
seam simple.) `epubSpine` rules:
- Read `META-INF/container.xml`; the OPF is the `full-path` attribute of the first `rootfile`
  element (match XML local names, ignore namespaces). Missing file/attribute → corrupt.
- Parse the OPF with `newXMLDecoder` + `walkXML(…, lim.MaxDepth, …)`: manifest `item`
  (`id`, `href`, `media-type`) and spine `itemref` (`idref`, `linear`). Skip itemrefs with
  `linear="no"` and items whose media-type is not `application/xhtml+xml` or `text/html`.
- Resolve each href purely as a zip entry name: strip `#fragment`, `url.PathUnescape`, then
  `path.Clean(path.Join(path.Dir(opfPath), href))`. A result that is absolute, equals `..` or
  starts with `../`, or is not present in the zip → corrupt. Never call `os`/`filepath`
  functions on entry names; nothing is ever written to disk.
- Unknown idref, an empty spine (no linear XHTML item) → corrupt.
- Every error returned by `loadEPUB` satisfies `errors.Is(err, ErrCorruptEPUB)` and keeps the
  inner chain (`fmt.Errorf("%w: <what>: %w", ErrCorruptEPUB, err)` when there is an inner
  error), so `ErrTooLarge` stays matchable. Messages are one line. No panics on any input.
