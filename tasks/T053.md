# T053: E2E focus column with a pane-screen parser (TestE2EFocusColumn)

Phase 5 · Model: sonnet: e2e test plus an SGR screen parser over tmux captures, on the existing harness (AC13 live part) · Depends-on: T011, T048

## Brief
Package `e2e` (module `github.com/0x6c6d/fastread`; every file starts with `//go:build e2e`,
`_test.go` suffix). Existing helpers in `e2e/helpers_test.go` (do not change signatures):
`buildBinary`, `stateEnv`, `newTmux(t, w, h, shellCmd)`, `capture(escapes bool)` (with
`true` = `capture-pane -e -p`: text plus SGR sequences `ESC[…m` only), `sendKeys`, `resize`,
`waitFor`, `watchWords`, the shell single-quoting helper. The module's packages may be
imported (`github.com/rivo/uniseg`, `github.com/0x6c6d/fastread/internal/tui/glyph` for
`glyph.Width(size)`).

Behaviour under test (R16, R14, Plan rows 25-27): the focus cluster's first cell is on
column w/2 (0-based, integer division) at size 1; at sizes 2–5 the focus letter is a block
glyph whose whole box (`glyph.Width(size)` columns, starting at w/2 − Width/2) is focus
styled; guide ticks `│` sit in column w/2 directly above and below the word rows. Focus
style seen by tmux: foreground red (`31`, `91`, `38;5;9`, `38;5;196` or `38;2;255;0;0`);
with `NO_COLOR=1` reverse video (`7`) and no colour parameter at all.

Create `e2e/screen_test.go` (reusable, later tasks use it; keep the names):
```go
type cell struct{ Text string; Col int; Focus, Reverse, Colored bool }
// parseScreen splits a capture(true) string into rows of cells. It tracks SGR state
// (0/empty resets; 1, 7/27, 30-37, 39, 90-97, 38;5;n, 38;2;r;g;b, 40-49, 100-107 handled;
// unknown parameters ignored), segments text into grapheme clusters with uniseg and
// assigns Col = sum of the previous clusters' display widths (min 1 per cluster).
// Focus = red foreground or reverse video; Colored = any explicit foreground colour.
func parseScreen(s string) [][]cell
// focusCols returns the sorted distinct columns of non-space Focus cells in the screen.
func focusCols(rows [][]cell) []int
// tickCols returns (row, col) of every "│" cell.
func tickCols(rows [][]cell) [][2]int
```
`TestParseScreen` (unit, no tmux): literal capture strings with each colour form, a reset
in the middle, a wide CJK cluster and a combining cluster give the expected columns and flags.

Create `e2e/focus_test.go`, `TestE2EFocusColumn`, words (≥ 20, play in order): `a I ab Hello
wonderful reading, "extraordinary" internationally (wonderful) -- naïve ¿Qué? don't
1,000,000 2026 日本語の本 한국어 Ωmega ÆØÅ “quoted” café end.` Subtests, own tmux each, env
`TERM=tmux-256color COLORTERM=truecolor` and `NO_COLOR` unset unless stated, `--no-resume`:
- `size1-w80` and `size1-w81` (`--size 1 --wpm 100`): poll `capture(true)` every 20 ms
  until `EXIT:0`; for every captured frame that shows a word: exactly one focus cluster on
  the word row and its column is 40; ticks at column 40 in the rows directly above and
  below; at least 20 distinct words observed (log the count).
- `size3` (`--size 3 --wpm 100`, ASCII words only from the list): every frame's non-space
  focus cells lie inside columns [40 − W/2, 40 − W/2 + W) with W = `glyph.Width(3)`, and
  both ticks are in column 40; ≥ 10 distinct frames.
- `nocolor` (`NO_COLOR=1 --size 1`): focus found via reverse video at column 40 and no cell
  is `Colored` in any frame.
A frame counts only when two consecutive captures are identical (a capture taken while
tmux is mid-update is skipped). On failure log the offending frame.

Constraints: create only `e2e/screen_test.go` and `e2e/focus_test.go`; never use the default
tmux server, the user's sessions or the real `~/.local/state`; every external call under a
timeout; whole test well under 120 s; `go vet -tags e2e ./...` clean.
