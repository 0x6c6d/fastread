# T026: Phase 2 gate: every committed fixture through the CLI flow

Phase 2 · Model: sonnet: one table test over existing code paths plus a text fixture; the script also runs the Phase 2 exit criterion · Depends-on: T016, T019, T020, T022, T023, T024, T025

## Brief
Prove that every input type reaches the token list through the same pre-UI path the binary
uses, and close Phase 2. Package `main` in `cmd/fastread` (module
`github.com/0x6c6d/fastread`). Existing APIs (do not change them):
- `parseFlags(args []string) (options, error)`;
  `prepare(o options, stdin io.Reader, isTTY bool) (input.Document, []tokenize.Token, error)`
  (Select, Load, Tokenize, empty check, `--start` check; no UI).
- `input.Document{Paragraphs []string; Path string; SHA256 [32]byte}`, sentinel
  `input.ErrNoText`; `tokenize.Token{Text string; ParaEnd bool}`.
- Committed fixtures in `internal/input/testdata/` (from `cmd/fastread` the path prefix is
  `../../internal/input/testdata/`): `sample.md`, `sample.epub`, `sample.fb2`, `sample.pdf`,
  `notext.pdf`.

Create `internal/input/testdata/sample.txt` with exactly these bytes (UTF-8, LF):
`Plain text sample.\n\nSecond paragraph here.\n`

Create `cmd/fastread/fixtures_test.go`, table-driven `TestPrepareFixtures` (one subtest per
fixture; options from `parseFlags([]string{"--no-resume", path})`; stdin
`strings.NewReader("")`, `isTTY` false). For every success row assert: no error; the joined
token texts (`strings.Join(texts, " ")`) equal the expected string exactly; `doc.Path` is
absolute and ends with the fixture's file name; `doc.SHA256 == sha256.Sum256(fileBytes)`;
the last token has `ParaEnd == true`. Rows:
- `sample.txt` → `Plain text sample. Second paragraph here.`, and `ParaEnd` is true on
  `sample.` (paragraph end) and false on `text`.
- `sample.md` → `Title Here Some emphasis, strong and under text with snake_case kept. A
  link text and alt words here. Use now, see there. quoted line item one item two item
  three Setext Heading a b c d Escaped 5 * 3 and html plus ref link too.` (one line, single
  spaces), `ParaEnd` true on `Here`.
- `sample.epub` → `One first & café Two second Three third`.
- `sample.fb2` → `Body Title First body paragraph. Second body paragraph. Note text.`
- `sample.pdf` → `Hello PDF world. Second page here.`, `ParaEnd` true on `world.`.
Error rows: `notext.pdf` → `errors.Is(err, input.ErrNoText)`; `sample.epub` with
`--start 9` → a usage error (`exitCode(err) == 2`, existing `func exitCode(err error) int`);
`sample.txt` with `--start 5` → no error, 6 tokens.

If a row fails because a loader disagrees with its own committed fixture, report it with the
actual output (do not edit loaders or fixtures other than `sample.txt`).

Constraints: change only `cmd/fastread/fixtures_test.go` and
`internal/input/testdata/sample.txt`; stdlib only; no terminal, window or state dir.

## Verification
`scripts/verify/T026.sh` exits 0. It runs the full Phase 2 exit criterion from Plan.md (check
plus all 17 named Phase 2 tests via `passes`), `TestPrepareFixtures`, the protected-files
check, and the binary on every fixture (exit 1 only for lack of a terminal). Negative checks:
`notext.pdf` exits 1 with `no extractable text`; a fixture copied with a mismatching
extension exits 1 with `unsupported`.
