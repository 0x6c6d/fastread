# T029: Timing multipliers (TestDelay, TestDelayPara)

Phase 3 · Model: sonnet: one pure function with a precise rule table; no security or contract decision · Depends-on: T001

## Brief
Complete R10 in package `internal/timing` (module `github.com/0x6c6d/fastread`). Existing
(keep names, values and signatures; the passing `TestDelayBase` stays unchanged):
`constants.go` with `SentenceMul = 2.0`, `ClauseMul = 1.5`, `LongWordStep = 0.05`,
`LongWordCap = 0.5`, `LongWordFrom = 8`, `ParagraphMul = 2.5`, `MinWPM = 50`, `MaxWPM = 1500`;
`delay.go` with
```go
func Delay(word string, wpm int) time.Duration          // == DelayPara(word, wpm, false)
func DelayPara(word string, wpm int, paraEnd bool) time.Duration
```
which today returns only the base (marked `// TODO(phase3): multipliers`; remove the marker).

Rule (implement exactly; use the constants; the literals `2.0`, `1.5`, `2.5`, `0.05` must not
appear anywhere in `delay.go`, comments included):
1. Clamp `wpm` to [MinWPM, MaxWPM]. base = 60000 / wpm milliseconds, as float64.
2. Punctuation multiplier p: strip trailing closers `"` `'` `)` `]` `}` `»` `”` `’` from the
   end of the word; look at the last remaining rune: one of `.` `!` `?` `…` → SentenceMul;
   one of `,` `;` `:` → ClauseMul; else (or nothing left) 1. (`...` therefore counts as a
   sentence end; only this single multiplier applies.)
3. Paragraph: if `paraEnd` and ParagraphMul > p then p = ParagraphMul (it replaces the
   sentence/clause multiplier, never multiplies with it).
4. Long word: L = number of runes with `unicode.IsLetter` or `unicode.IsDigit` (combining
   marks are not letters, so `héllo` has 5). If L > LongWordFrom, bonus = min(
   LongWordStep × (L − LongWordFrom), LongWordCap), else 0. It multiplies on top: × (1+bonus).
5. Result = base × p × (1+bonus), rounded to the nearest whole millisecond **once at the
   end** (`math.Round`), returned as `time.Duration`.
Stdlib only (`math`, `time`, `unicode`, `unicode/utf8`, `strings`); pure, no global state.
(Counting letter runes instead of grapheme clusters keeps `timing` free of third-party
imports; it equals the cluster count for Latin, Greek, Cyrillic, CJK and combining-mark text.)

exactly, ms values):

  `word;` 300; `word:` 300; `word!` 400; `word?` 400; `word…` 400; `etc...` 400; `?!` 400;
  `"word."` (with quotes) 400; `(word),` 300; `word?)` 400; `word»` 200; `’word’` 200;

  `abcdefgh` (8) 200; `wonderful` (9) 210; `abcdefghijkl` (12) 240; 18 letters 300;

  only at the end); `word,` at 450 → 200; `abcdefghijk` (11) at 450 → 153; `word.` at 0 →
