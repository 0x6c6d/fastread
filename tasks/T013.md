# T013: Hardened input helpers (size caps, zip, XML, recover)

Phase 2 · Model: opus: the single home of the untrusted-input defences (Consequential assumptions 11 and 14/16 via Risk "untrusted parsing": size caps, zip bombs, XML entities, library panics) · Depends-on: T005

## Brief
Create `internal/input/safe.go`, the only place where package `internal/input` reads untrusted
bytes, opens zip archives or builds XML decoders. Later loaders (EPUB, FB2, PDF, text files) call
these helpers and nothing else for those jobs. Also route the stdin read through the cap.

Existing in the package (keep every name and signature): sentinels `ErrNotFound`,
`ErrCorruptEPUB`, `ErrEmpty`, `ErrUnsupported`, `ErrNoText`, `ErrCorruptPDF`, `ErrTooLarge`,
`ErrNoInput`; `type Document`, `type Source`, `Kind` (`KindRaw`, `KindStdin`, `KindFile`),
`Select`, `Load(src Source, stdin io.Reader) (Document, error)`, `ParseText(b []byte) []string`.

`internal/input/safe.go` (stdlib only), exactly these declarations:
```go
const (
    MaxInputBytes = 256 << 20 // file/stdin bytes, PDF size, EPUB total decompressed bytes (A4)
    MaxZipEntries = 10000
    MaxXMLDepth   = 256
)
// Limits caps resource use while parsing untrusted input; tests pass small values.
type Limits struct {
    MaxBytes   int64
    MaxEntries int
    MaxDepth   int
}
func DefaultLimits() Limits // {MaxInputBytes, MaxZipEntries, MaxXMLDepth}

// readCapped reads all of r; more than max bytes -> error wrapping ErrTooLarge (reads at most
// max+1 bytes, never more). Read errors are wrapped with %w.
func readCapped(r io.Reader, max int64) ([]byte, error)
// readFileCapped opens path, rejects a size above max from Stat before reading (ErrTooLarge),
// then reads through readCapped (the file may grow). Not-exist -> error wrapping ErrNotFound.
func readFileCapped(path string, max int64) ([]byte, error)

// zipArchive is an in-memory zip whose entry names are only map keys, never filesystem paths.
type zipArchive struct{ /* unexported */ }
// openZip: zip.NewReader over b. A zip.NewReader error -> ErrCorruptEPUB (wrapped), except
// zip.ErrInsecurePath, which is ignored (names are never used as paths). More than
// lim.MaxEntries entries -> fmt.Errorf("%w: %w", ErrCorruptEPUB, ErrTooLarge).
func openZip(b []byte, lim Limits) (*zipArchive, error)
func (z *zipArchive) has(name string) bool
// read returns the entry with exactly this name (first one if duplicated). Missing ->
// ErrCorruptEPUB. All reads of one archive share one budget of lim.MaxBytes decompressed bytes,
// counted on the bytes actually decompressed (io.LimitReader to remaining+1, never trusting
// header sizes; a header size above the remaining budget may be rejected early). Over budget
// -> ErrCorruptEPUB and ErrTooLarge both matchable with errors.Is. Decompression/checksum errors
// -> ErrCorruptEPUB.
func (z *zipArchive) read(name string) ([]byte, error)

// newXMLDecoder: encoding/xml with Strict=false, Entity=xml.HTMLEntity,
// AutoClose=xml.HTMLAutoClose; CharsetReader accepts only utf-8/us-ascii (any case) and returns
// an error wrapping ErrUnsupported ("unsupported XML encoding") for anything else.
// encoding/xml never resolves external entities or fetches DTDs; never add code that does.
func newXMLDecoder(r io.Reader) *xml.Decoder
// walkXML calls fn for every token (xml.CopyToken'd) with the element depth (root = 1).
// Depth above maxDepth -> error wrapping ErrTooLarge. Syntax errors are wrapped with %w.
// An error from fn stops the walk and is returned.
func walkXML(d *xml.Decoder, maxDepth int, fn func(tok xml.Token, depth int) error) error

// recoverAs runs fn; a panic inside it becomes an error wrapping sentinel ("%w: internal
// parser panic: %v"). fn's own error is returned unchanged.
func recoverAs(sentinel error, fn func() error) (err error)
```

Change in `internal/input/input.go`: `Load` delegates to a new unexported
`load(src Source, stdin io.Reader, lim Limits) (Document, error)`; `KindStdin` reads via
`readCapped(stdin, lim.MaxBytes)`. Raw text (an argv string) needs no cap. Leave `KindFile`
as it is (a later task implements it inside `load`).

`internal/input/safe_test.go` (package `input`, table-driven; build zips in memory with
`archive/zip`, files only under `t.TempDir()`):
- `TestSafeReadCapped`: sizes max−1, max, max+1 with max = 10 (last → `ErrTooLarge`); a reader
  that errors → wrapped error; an endless reader (e.g. a zero reader) with max 1 MiB returns
  `ErrTooLarge` without hanging; `readFileCapped` on a missing file → `ErrNotFound`, on an
  11-byte file with max 10 → `ErrTooLarge`; `DefaultLimits()` values exact.
- `TestSafeZip`: valid zip read round trip; truncated zip (first half of the bytes) and
  non-zip bytes with a `PK\x03\x04` prefix → `ErrCorruptEPUB`; 60 entries with MaxEntries 50 →
  both sentinels; two 40 KiB zero entries with MaxBytes 64 KiB → the second read gives both
  sentinels; an entry written with `CreateRaw` whose header claims 10 bytes but whose deflate
  data expands to 1 MiB → error wrapping `ErrCorruptEPUB`; entry named `../../etc/passwd` is
  readable by that exact name, and nothing is written to disk; missing name → `ErrCorruptEPUB`.
- `TestSafeXML`: a document with `<!DOCTYPE r [<!ENTITY x SYSTEM "file:///<tempfile>">]>` and
  `<r>&x;</r>` never yields the temp file's content `SECRET`; `&amp;`/`&eacute;` decode;
  `encoding="windows-1251"` → `ErrUnsupported`; nesting 300 with maxDepth 256 → `ErrTooLarge`;
  nesting 200 passes; truncated XML → error, no panic.
- `TestSafeRecover`: panic(string) and panic(error) → `errors.Is(err, ErrCorruptPDF)`; fn error
  returned unchanged; nil → nil.
- `TestSafeLoadStdinCap`: `load` with `Limits{MaxBytes: 8}` on stdin `"123456789"` →
  `ErrTooLarge`; `"12345678"` → one paragraph.

Constraints: stdlib only; no file writes outside test temp dirs; no network; no `unsafe`.
