# T006: TUI frame renderer and ANSI encoder skeleton

Phase 1 · Model: sonnet: pure functions with a given API and table tests, moderate layout judgment · Depends-on: T003

## Brief
Create the pure (no I/O) half of package `internal/tui`: a frame model, `Render` (word → cell
grid with the focus cluster on the centre column) and `Encode` (grid → ANSI bytes with colours).
Size levels 2–5 (block glyphs), ticks, progress/help rows, splitting and control-char stripping
come in later tasks; this task renders every size as level-1 text on one row.

Existing package you use: `github.com/0x6c6d/fastread/internal/orp`:
`func Clusters(word string) []string` (grapheme clusters), `func Index(word string) int` (index of
the focus cluster). `github.com/rivo/uniseg v0.4.7` is already in `go.mod`; use
`uniseg.StringWidth(cluster)` for a cluster's cell width (do not add other dependencies).

Files to create (package doc in `render.go`: "Package tui renders and runs the terminal UI."):
- `internal/tui/color.go`:
  ```go
  type ColorMode int
  const (
      ColorNone ColorMode = iota // NO_COLOR set: focus is bold+reverse, no colour escapes
      Color16
      Color256
      ColorTrue
  )
  // DetectColorMode: NO_COLOR non-empty -> ColorNone; else COLORTERM "truecolor" or "24bit"
  // -> ColorTrue; else TERM containing "256color" -> Color256; else Color16.
  func DetectColorMode(getenv func(string) string) ColorMode
  ```
- `internal/tui/render.go`:
  ```go
  type Style uint8
  const (
      StylePlain Style = iota // white letters, blank cells
      StyleFocus              // the red focus cluster
      StyleTick               // guide tick (used by a later task)
  )
  // Cell is one terminal cell. Text is a grapheme cluster or "" for a blank cell.
  // Cont is true for the second cell of a 2-cell-wide cluster (Encode writes nothing for it).
  type Cell struct {
      Text  string
      Style Style
      Cont  bool
  }
  // Frame is a W x H grid; Cells[y][x], len(Cells) == H, len(Cells[y]) == W.
  type Frame struct {
      W, H  int
      Cells [][]Cell
  }
  // Model is everything Render needs for one frame.
  type Model struct {
      Word         string
      Size         int  // 1..5 (rendered as 1 in this task)
      Paused       bool
      ShowProgress bool
      ShowHelp     bool
      Index, Total int  // 0-based word index, word count
      WPM          int
      EffectiveWPM int  // 0 = unknown
  }
  // FocusColumn returns the fixed focus column for width w: w/2.
  func FocusColumn(w int) int
  // Render draws m into a w x h frame. It never panics (w or h <= 0 -> Frame{} with that size
  // clamped to 0); cells outside the frame are clipped.
  func Render(m Model, w, h int) Frame
  ```
  Level-1 layout: word row y = h/2; clusters = orp.Clusters(m.Word), fi = orp.Index(m.Word);
  the focus cluster starts at x = FocusColumn(w); clusters before it are placed to its left
  (left-padded, never re-centred) using their display widths, clusters after it to its right;
  a 2-wide cluster fills its cell plus one `Cont` cell; width-0 clusters are skipped. The focus
  cluster's cell gets StyleFocus, all others StylePlain.
- `internal/tui/encode.go`:
  ```go
  // Encode turns a frame into bytes for a terminal: for each row y, "\x1b[<y+1>;1H" then the
  // row's cells (blank -> ' ', Cont -> nothing), switching SGR only when the style changes,
  // and "\x1b[0m" at the end of each row.
  func Encode(f Frame, mode ColorMode) []byte
  ```
  SGR per mode, exactly: plain letters ColorTrue `\x1b[38;2;255;255;255m`, Color256
  `\x1b[38;5;231m`, Color16 `\x1b[97m`, ColorNone none; focus ColorTrue `\x1b[38;2;255;0;0m`,
  Color256 `\x1b[38;5;196m`, Color16 `\x1b[91m`, ColorNone `\x1b[1;7m`; reset `\x1b[0m` before
  each style switch. Never set a background colour.
- `internal/tui/render_test.go`, table-driven:
  - `TestRenderFocusLevel1`: words `a Hello wonderful "extraordinary" naïve -- (wonderful) é日本`
    × widths 80, 121, 20 × heights 24, 5: exactly one StyleFocus cell, at x == w/2 and y == h/2,
    with Text == `orp.Clusters(w)[orp.Index(w)]`; at widths 80 and 121, reading row h/2 left to
    right (skipping Cont and blank cells) gives back the word (at width 20 long words may clip).
  - `TestRenderClip`: a 60-letter word at width 20 and frames of size 0×0, 1×1, 3×2 do not panic
    and have `len(Cells) == H` and `len(Cells[y]) == W`.
  - `TestEncodeColors`: for each mode the encoded `Hello` frame contains the focus SGR followed
    immediately by `e`; ColorNone output matches no `\x1b\[(3[0-9]|9[0-7])(;[0-9]+)*m` colour
    sequence; no mode emits a background SGR (`\x1b[4x`/`48;`).
  - `TestDetectColorMode`: NO_COLOR=1 (+COLORTERM=truecolor) → None; COLORTERM=24bit → True;
    TERM=xterm-256color → 256; TERM=xterm → 16; NO_COLOR="" with TERM=screen-256color → 256.

Constraints: pure functions only in these files (no terminal, no os, no goroutines); do not import
`internal/state` here; standard library + orp + uniseg only.
