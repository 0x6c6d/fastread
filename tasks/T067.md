# T067: E2E every input type and error case (TestE2EInputTypes)

Phase 7 · Model: sonnet: one table-driven e2e test on the existing tmux harness and committed fixtures; the behaviour itself is built and verified (AC32, R1-R12, D16) · Depends-on: T026, T051

## Brief
Package `e2e` (module `github.com/0x6c6d/fastread`; every file starts with `//go:build
e2e`, `_test.go` suffix). Existing helpers in `e2e/helpers_test.go` (use them, do not change
signatures; read the file for the shell single-quoting helper's name):
`buildBinary(t, buildArgs...) string`, `stateEnv(t) string` (`XDG_STATE_HOME=<temp dir>`),
`newTmux(t, w, h, shellCmd) *tmuxSession` (own `-L` socket, cleanup kills it),
`capture(escapes bool) string`, `watchWords(words []string, timeout) (seen []string, exit
int)` (in-order screen lines equal to one of `words`, consecutive duplicates collapsed, exit
from a pane line `EXIT:<n>`, -1 on timeout). Shell commands follow `env <stateEnv> <bin>
<args> 2><errfile>; echo "EXIT:$?"; sleep 600`.

Committed fixtures (absolute path via `filepath.Abs("../internal/input/testdata/<name>")`)
and the word sequence each yields (one string, single spaces):
- `sample.txt` → `Plain text sample. Second paragraph here.`
- `sample.md` → `Title Here Some emphasis, strong and under text with snake_case kept. A link
  text and alt words here. Use now, see there. quoted line item one item two item three
  Setext Heading a b c d Escaped 5 * 3 and html plus ref link too.`
- `sample.epub` → `One first & café Two second Three third`
- `sample.fb2` → `Body Title First body paragraph. Second body paragraph. Note text.`
- `sample.pdf` → `Hello PDF world. Second page here.`
- `notext.pdf`: a PDF without a text layer (stands in for a scanned PDF).

Binary behaviour (exit codes 0 ok, 1 runtime error, 2 usage error; every error is exactly
one stderr line `fastread: <msg>`, usage errors add the usage text starting `Usage:`):
missing path-like file → `file not found`; zero tokens → `empty text`; PDF without text →
`no extractable text (scanned PDF?)`; extension contradicting the magic bytes → `unsupported
file type`; invalid flag value → usage error. Reaching the end of a file deletes its resume
entry; raw text and stdin never create one.

Create `e2e/inputtypes_test.go` with `TestE2EInputTypes`, table-driven, one subtest per case,
in this order, each with its own `stateEnv` and (tmux cases) its own 80×24 tmux server:
- Played in tmux with `--size 1 --wpm 300` (no `--no-resume`), `watchWords` timeout 40 s;
  the whole expected sequence must be seen in order and exit 0; afterwards the state dir
  contains no `*.json` file under `fastread/`:
  `raw` (`'Hello wonderful world'`), `stdin` (`printf 'one two three' | <bin> …`), `txt`,
  `md`, `epub`, `fb2`, `pdf` (the fixtures above).
- Run with `exec.CommandContext` (10 s timeout, `Dir` = a temp dir, stdin `/dev/null`, env =
  `os.Environ()` plus `stateEnv`), asserting exit code, stdout empty and stderr's first line
  starting `fastread: `:
  `missing-file` (`./nope.txt`) → 1, stderr contains `not found`, exactly one line;
  `empty-text` (a temp `empty.txt` holding `" \n\n\t\n"`) → 1, contains `empty text`, one
  line; `bad-flag` (`--wpm 49 hello`) → 2, stderr contains `Usage:`; `scanned-pdf`
  (`notext.pdf`) → 1, contains `no extractable text (scanned PDF?)`, one line;
  `wrong-extension` (`sample.epub` copied to a temp `book.pdf`) → 1, contains
  `unsupported`, one line. None of them may create the state directory.

Report line (the final verification report quotes it): every subtest, pass or fail, logs
exactly one line `t.Logf("CASE name=%s exit=%d output=%q", name, code, output)`, where
`output` is the words seen joined by single spaces (tmux cases; plus ` stderr=` and the
error file's content when it is not empty) or the full stderr text (exec cases); `code` is
the real exit code (-1 on timeout). Log it before asserting. On failure also log the last
captured screen.

Constraints: create only `e2e/inputtypes_test.go`; stdlib only; never the default tmux
server, the user's sessions or the real `~/.local/state`; every external call under a
timeout; no fixed sleeps longer than the 20 ms poll; whole test well under 120 s; `go vet
-tags e2e ./...` clean. If a case fails because of program behaviour (a loader output, an
exit code, a message), report the case with the real output; do not change non-test code
or fixtures.

## Verification
`scripts/verify/T067.sh` exits 0. It runs the check command, `go vet -tags e2e`,
`TestE2EInputTypes -v` with its `--- PASS` line and all twelve `CASE name=… exit=…` lines
with the expected exit codes and outputs, then independently runs the built binary on the
five error cases (codes, one-line stderr, empty stdout, no state dir), and checks no tmux
server or `fastread` process is left and the real `~/.local/state/fastread` was not created.
Negative checks: the five error cases themselves (each must fail with an ordinary code).
