# T010: CLI wiring (input → tokenize → player → TUI/GUI)

Phase 1 · Model: opus: signal handling, exit codes and the GUI `finish`/`os.Exit` path (Consequential assumption 8 via Risk "GUI exit path"; R1 TTY rule; R12) · Depends-on: T002, T005, T007, T008, T009

## Brief
Replace the placeholder at the end of `run` in `cmd/fastread/run.go` (marked `TODO(T010)`) with
the end-to-end flow. Flag parsing, usage, help and version stay as they are. Resume (save on quit,
delete at end) comes in a later task; leave a `// TODO(phase3): resume` comment where it goes.

APIs you call (already in the repo; module `github.com/0x6c6d/fastread`):
- `internal/input`: `Select(arg string, hasArg, stdinIsTTY bool) (Source, error)`,
  `Load(src Source, stdin io.Reader) (Document, error)` (`Document.Paragraphs []string`),
  sentinels `ErrNoInput`, `ErrEmpty`.
- `internal/tokenize`: `Tokenize(paragraphs []string) []Token`.
- `internal/state`: `NewPlayer(Config{Tokens, Start, WPM, Size, ShowProgress, Clock}) *Player`,
  `SystemClock{}`.
- `internal/tui`: `OpenTTY() (Terminal, error)`, `Run(ctx, t Terminal, p *state.Player,
  tui.Options{Getenv}) (last int, err error)`; `Terminal` has `Read, Write, Size() (w, h int, err
  error), MakeRaw, Restore, Close`.
- `internal/gui`: `Run(ctx, p *state.Player, gui.Options{Getenv}, finish func(last int, err
  error)) error` (returns an error synchronously when there is no display or in nogui/no-cgo
  builds; otherwise never returns and calls `finish` once from the window goroutine).
- Existing in `cmd/fastread`: `options` (`wpm size ui start startSet noResume noProgress arg
  hasArg`), `parseFlags`, `usage(w)`, `run(args, stdin, stdout, stderr, getenv) int`.

Changes:
- `cmd/fastread/run.go`: add package-level seams for tests:
  ```go
  var (
      openTerminal = tui.OpenTTY
      stdinIsTTY   = func(r io.Reader) bool // *os.File and golang.org/x/term.IsTerminal; else false
      exitProcess  = os.Exit               // only the GUI finish callback calls it
  )
  ```
  (Use `term.IsTerminal`, not `os.ModeCharDevice`: `/dev/null` is a character device.)
  Flow after successful parsing: `input.Select(o.arg, o.hasArg, stdinIsTTY(stdin))` —
  `ErrNoInput` → error line + usage on stderr, return 2; other error → 1. `input.Load` error → 1.
  `tokenize.Tokenize`; zero tokens → error wrapping `input.ErrEmpty`, return 1. `startSet` and
  `start >= len(tokens)` → error line + usage on stderr, return 2. Build the player
  (`ShowProgress: !o.noProgress`, `Clock: state.SystemClock{}`, Start = start or 0). Create
  `ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)`,
  `defer stop()`. `tui` → `openTerminal()` (error → 1) then `tui.Run` (error → 1, else 0).
  `gui` → `gui.Run` with a `finish` that prints the error line if `err != nil` and calls
  `exitProcess(0 or 1)`; a synchronous error from `gui.Run` → error line, return 1.
  Every runtime error is exactly one stderr line `fastread: <message>` (newlines in messages
  replaced by spaces); nothing else is printed on success.
- `cmd/fastread/run_test.go`, table-driven where it fits; restore the seams with `t.Cleanup`; a
  small fake terminal in the test file (Read blocks until Close, Write discards, Size 80×24):
  - `TestRunEmptyText`: raw `"   "` and stdin `""` (no arg, not a TTY) → 1, exactly one
    stderr line, containing `empty text`.
  - `TestRunNoInputTTY`: `stdinIsTTY` forced true, no argument → 2, usage on stderr.
  - `TestRunStartBeyond`: `--start 2 "a b"` → 2 with usage; `--start 1 "a b"` reaches the UI.
  - `TestRunTerminalError` (negative): `openTerminal` returns an error → 1, one stderr line,
    stdout empty.
  - `TestRunTUIPlaysToEnd`: fake terminal, `--wpm 1500 "a b c"` → 0, stderr empty.
  - `TestRunGUINoDisplay`: `--ui gui x` with getenv returning "" → 1, exactly one stderr line,
    `exitProcess` never called (works in cgo, nogui and no-cgo builds).

Constraints: `os.Exit` only in `main()` and via `exitProcess`; tests never open `/dev/tty`, a
window or the real `~/.local/state`; no network.

## Verification
`scripts/verify/T010.sh` exits 0. It runs the check command and the six `TestRun*` tests (also
with `-tags nogui`), the R30 layering check, and drives the built binary: under Xvfb `--ui gui`
stays up ≥ 2.5 s and exits 0 within 1.5 s of SIGTERM. Negative checks: no display (cgo and
nogui/no-cgo binaries, which also contain no `gioui.org` symbols) → exit 1 with one stderr line;
empty raw text and empty stdin → exit 1; no controlling terminal → exit 1 with one line; no
argument on a TTY → exit 2.
