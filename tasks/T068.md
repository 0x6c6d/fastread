# T068: Usage documentation (docs/usage.md)

Phase 7 · Model: opus: documents the public CLI contract (Risk "CLI contract", Plan rows 2-3) and the dependency/licence list (Consequential row 39); every statement must match the built code · Depends-on: T036, T056, T065, T066

## Brief
Create exactly one file, `docs/usage.md` (Markdown, English): the user documentation of the
finished `fastread` binary (spec §7 deliverable, AC31). `README.md` is the spec and stays
untouched; `CLAUDE.md` is frozen for v1 (do not edit it). Describe what was built, not what
the spec intended: read the code before writing each section and take facts (defaults,
ranges, constants, messages) from it. Read at least: `go.mod`; `cmd/fastread/*.go` (usage
text, flags, exit codes, `--` handling, error lines); `internal/input/*.go` (`LooksLikePath`,
`Select`, type detection by extension and magic bytes, size caps, loader rules);
`internal/timing/*.go` (multipliers; the long-word bonus counts letter/digit runes, not
grapheme clusters, so conjoining-jamo and Indic spacing-mark text can differ slightly);
`internal/state/*.go` (resume dir, file name, modes, start-index precedence);
`internal/tui/*.go`, `internal/tui/glyph/` (`HelpText`, colour modes, sizes, split rule,
size fallback, `terminal too small`); `internal/gui/*.go` (`LevelSp`, `MinSp`, rounding rule,
window size, the "GUI not available" message); `third_party/*/LICENSE`. Build the binary and
run `fastread --help` to copy the flags exactly.

Structure: title `# fastread usage`, a 2-4 sentence intro (RSVP: one word at a time at a
fixed position, red focus letter; terminal UI by default, Gio window with `--ui gui`), then
these `##` sections, in this order, with exactly these headings:
1. `## Install and build`: Linux only; Go >= the `go.mod` version (1.24); full build
   `go build -o fastread ./cmd/fastread` needs cgo and the Gio system libraries (the spec's
   Debian/Ubuntu apt line plus `libx11-xcb-dev`); TUI-only build `CGO_ENABLED=0 go build
   -tags nogui -o fastread ./cmd/fastread` (no system libraries; `--ui gui` then exits 1);
   `GOTOOLCHAIN=local` note; tests: `go test ./...`, `-race`, `-tags nogui`, and the e2e
   command (`-tags e2e`, needs tmux, Xvfb, xdotool).
2. `## Examples`: fenced shell examples, one real command per input type: raw text
   (quoted), stdin (`printf '…' | fastread` or `cat notes.txt | fastread`), `.txt`, `.md`,
   `.epub`, `.fb2`, `.pdf`; also `--ui gui`, `--wpm`/`--size`, `--start`/`--no-resume`, and
   the literal line `fastread -- --wpm` (raw text starting with `--`). Then a subsection
   `### Text or file?` that states the source rule exactly as the code does: existing file
   → loaded (existing directory → unsupported); otherwise path-like = no whitespace and
   (contains `/`, starts with `.` or `~`, or ends case-insensitively in `.txt .md .epub
   .fb2 .pdf`) → `file not found`, exit 1; otherwise raw text; no argument → stdin when
   piped, else usage and exit 2; only one positional argument (quote multi-word text);
   flags before it; `--` ends flags; `-` is not a stdin alias. Use the word `path-like` in
   that paragraph. Also say how the type is detected (extension and magic bytes, mismatch →
   unsupported type, unknown extension → sniffed).
3. `## Flags`: a Markdown table of every flag from `--help` (`--wpm`, `--size`, `--ui`,
   `--start`, `--no-resume`, `--no-progress`, `-h`/`--help`, `--version`) with default and
   range; exit codes 0/1/2; resume: state in `$XDG_STATE_HOME/fastread/` (fallback
   `~/.local/state/fastread/`), what one entry holds (path, SHA-256, index), modes 0700/0600,
   raw text and stdin never saved, end of text deletes the entry, precedence of `--start`
   and `--no-resume`; the environment variables read (`NO_COLOR`, `COLORTERM`, `TERM`,
   `DISPLAY`, `WAYLAND_DISPLAY`, `XDG_STATE_HOME`, `HOME`).
4. `## Keys`: a table valid for both UIs: Space, Up/Down (±25 wpm, 50-1500), `[`/`]` (size
   1-5), Left/Right (±1 word paused, ±10 playing), Home, `p`, `?`, `q`/Esc/Ctrl+C; the help
   line text and the progress row format as rendered.
5. `## Dependencies`: one bullet per module on a `require` line of `go.mod` (direct and
   indirect, exact module path) with a one-line justification (indirect: which direct
   module needs it); then the system libraries of the GUI build and the test tools.
6. `## GUI font`: Go Regular (`golang.org/x/image/font/gofont/goregular`), embedded, no
   system fonts, why; licence in `third_party/gofont/LICENSE`; the font size per level in sp
   (the `LevelSp` values), the shrink minimum (`MinSp`, written as `<n> sp`), the rounding
   rule of the focus centre (centre line `width/2`, …); the TUI block glyphs: X11 misc-fixed
   (public domain; 4x6, 6x10, 7x14, 9x18 for sizes 2-5; Latin-1 only, other runes fall back
   to level 1), notice in `third_party/misc-fixed/LICENSE`.
7. `## Limitations`: at least Linux only (no Windows/macOS); scanned PDFs (no OCR, message
   `no extractable text (scanned PDF?)`); DRM-encrypted EPUBs rejected; no right-to-left
   (RTL) shaping; Wayland not verified (X11 tested under Xvfb); a missing GUI shared library
   fails in the dynamic linker before fastread runs; input limit 256 MiB (plus the EPUB
   entry and FB2 depth caps as coded); `.fb2.zip` unsupported; the timing note above; any
   other unsupported case the code reports.

Rules: in every line that contains `fastread ` and in the Flags section, never spell a
`--name` the binary does not accept (the check compares them with `--help`); write single
keys in backticks (`` `p` ``, `` `?` ``, `` `q` ``, `` `[` ``, `` `]` ``) and quote `HelpText`
verbatim; never mention `font8x8` (not used); nothing from the spec's nice-to-have list as
if it existed; no HTML; under about 400 lines.
