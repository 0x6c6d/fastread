# T036: Phase 3 gate: core pipeline integration tests

Phase 3 · Model: sonnet: two integration tests over existing, already-verified code paths; the script also runs the Phase 3 exit criterion · Depends-on: T027, T028, T029, T031, T035

## Brief
Prove that the core packages work together on real loader output, and close Phase 3. Package
`main` in `cmd/fastread` (module `github.com/0x6c6d/fastread`). Existing APIs (do not change
them):
- `parseFlags(args []string) (options, error)`; `prepare(o options, stdin io.Reader, isTTY
  bool) (input.Document, []tokenize.Token, error)` (Select, Load, Tokenize, empty and
  `--start` checks; no UI, no state).
- `tokenize.Token{Text string; ParaEnd bool}`, `tokenize.Sanitize(s string) string` (drops
  C0, DEL, C1, U+202A–U+202E, U+2066–U+2069; invalid UTF-8 → U+FFFD).
- `orp.Index(word) int`, `orp.Clusters(word) []string`;
  `timing.DelayPara(word string, wpm int, paraEnd bool) time.Duration`.
- `state.NewPlayer(state.Config{Tokens, Start, WPM, Size, ShowProgress, Clock})`,
  `Start()`, `Tick() bool`, `Deadline()`, `Index()`, `Finished()`,
  `EffectiveWPM() (int, bool)`; `state.Clock` interface `Now() time.Time`.
- Committed fixtures, from `cmd/fastread`: `../../internal/input/testdata/` `sample.txt`,
  `sample.md`, `sample.epub`, `sample.fb2`, `sample.pdf`.

Create `cmd/fastread/core_test.go` (own fake clock type, stdlib + internal packages only):
- `TestPrepareSanitized`, table-driven; options from `parseFlags`, `isTTY` false. Input
  bytes (one Go string literal; `\x9b` is a raw invalid byte):
  ```go
  const B = "Hello \x1b[31mred\x1b[0m world.\n\n\x1b]0;pwned\x07title ‮evil⁦ \x9b2J end\n"
  ```
  - file row: `B` written to `t.TempDir()/esc.txt`, args `[--no-resume, path]`;
  - stdin row: no argument, stdin `bytes.NewReader(B)`;
  both → token texts exactly `Hello`, `[31mred[0m`, `world.`, `]0;pwnedtitle`, `evil`,
  `�2J`, `end`, with `ParaEnd` exactly on `world.` and `end`;
  - raw row: argument `"a\x1b[2Jb c"` → `a[2Jb`, `c` (last has `ParaEnd`).
  For every row: no token contains a rune in `[U+0000–U+001F, U+007F–U+009F, U+202A–U+202E,
  U+2066–U+2069]`, every token is valid UTF-8 and `tokenize.Sanitize(tok) == tok`.
- `TestCorePipeline`, one subtest per committed fixture: `prepare` → tokens (no error);
  every token: `0 <= orp.Index(t) < len(orp.Clusters(t))` and `timing.DelayPara(t, 600,
  pe) >= 100ms`; then a player at 600 wpm, Start 0, fake clock at t0: repeatedly set the
  clock to `Deadline()` and `Tick()` until finished (bounded loop) → `Finished()`,
  `Index() == len(tokens)-1`, final `Deadline() == t0 + Σ DelayPara(text, 600, paraEnd)`
  exactly, and `EffectiveWPM()` ok when there are at least 2 tokens.

If a row fails because existing code disagrees with this brief, report it with the actual
output (do not edit non-test code).

Constraints: create only `cmd/fastread/core_test.go`; no terminal, window or state dir; no
real sleeps.
