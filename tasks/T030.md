# T030: Player live keys (R26) with pause and jump timing

Phase 3 · Model: sonnet: pure model logic with a given API and fake-clock tests (routing policy example) · Depends-on: T004

## Brief
Implement the R26 key semantics in `state.Player` (package `internal/state`, file
`internal/state/player.go`, module `github.com/0x6c6d/fastread`). Existing API (keep every
name and signature): `Action` constants `ActNone ActTogglePause ActWPMUp ActWPMDown
ActSizeDown ActSizeUp ActPrev ActNext ActHome ActToggleProgress ActToggleHelp ActQuit`;
`Config{Tokens []tokenize.Token; Start, WPM, Size int; ShowProgress bool; Clock Clock}`;
`NewPlayer(cfg Config) *Player`; methods `Start() Tick() (finished bool) Apply(a Action)
(quit bool) Deadline() time.Time Index() Len() Token() Playing() Finished() WPM() Size()
ShowProgress() ShowHelp()`; `Clock` interface with `Now() time.Time`. `Tick` already uses
absolute deadlines (`deadline = previous deadline + delay(new word)`), delay(word) =
`timing.DelayPara(tok.Text, wpm, tok.ParaEnd)`; `timing.MinWPM`/`MaxWPM` exist.
Remove the `// TODO(phase3): R26 keys` marker.

`Apply(a)` semantics (now = Clock.Now(); every value clamped, never panics):
- `ActTogglePause`: playing → paused, remember `remaining = max(0, deadline − now)`;
  paused → playing, `deadline = now + remaining`. Playback starts playing (`NewPlayer`).
- `ActWPMUp` / `ActWPMDown`: wpm ± 25, clamped to [MinWPM, MaxWPM]. The current deadline is
  unchanged (the new speed applies from the next word).
- `ActSizeUp` / `ActSizeDown`: size ± 1, clamped to [1, 5].
- `ActNext` / `ActPrev`: step 1 when paused, 10 when playing; index clamped to [0, Len−1].
- `ActHome`: index 0; playing/paused state unchanged.
- Jump timer rule (Next/Prev/Home), only if the index actually changed: playing →
  `deadline = now + delay(new word)`; paused → `remaining = delay(new word)` (used on resume).
- `ActToggleProgress` / `ActToggleHelp`: flip `ShowProgress` / `ShowHelp`.
- `ActQuit`: returns true, changes nothing. `ActNone` and unknown values: no-op, false.
- After `Finished()` is true, every action except `ActQuit` is a no-op.
- `Tick` while paused never advances and returns false, however late it is called.
- `Deadline()` while paused returns the deadline that resuming at the current `Now()` would
  give (`now + remaining`) — document this in its doc comment.
