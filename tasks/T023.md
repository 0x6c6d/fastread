# T023: Flag validation table and help/version tests (R11)

Phase 2 · Model: opus: the public flag contract incl. the single-positional rule (Consequential assumption 3; Risk "CLI contract") · Depends-on: T010

## Brief
Pin down the complete R11 flag contract of the `fastread` binary with the two acceptance
tests named in Plan.md, through `run` (the real entry point), and fix any behaviour that
does not match. Package `cmd/fastread` (module `github.com/0x6c6d/fastread`), existing:
- `run(args []string, stdin io.Reader, stdout, stderr io.Writer, getenv func(string) string)
  int`; `parseFlags(args []string) (options, error)`; `usage(w io.Writer)`;
  `versionString() string` (`fastread <v>`).
- seams in `run.go`: `openTerminal` (func returning `(tui.Terminal, error)`), `stdinIsTTY
  func(io.Reader) bool`, `exitProcess`. Restore any seam you change with `t.Cleanup`.
- Contract (already intended): stdlib `flag`, `-x` and `--x` both work, `--x=v` works, flags
  before the positional argument, `--` ends flags, more than one positional argument is a
  usage error; usage errors print `fastread: <msg>` (one line) then the usage text to stderr
  and exit 2; `-h`/`--help` print usage to stdout, exit 0; `--version` prints
  `fastread <v>` to stdout, exit 0; `--start` beyond the last word is a usage error (exit 2)
  detected after loading the text.

Create `cmd/fastread/cli_test.go` (table-driven, `t.Run` per row; stdin
`strings.NewReader("")`, `stdinIsTTY` forced false):
- `TestFlags` (AC9). Seam trick: replace `openTerminal` with a func that returns the error
  `errors.New("ui reached")`, so a valid command line exits 1 with `ui reached` on stderr
  without any terminal, and an invalid one must never reach it.
  - exit 2 rows (stderr line 1 starts with `fastread: `, stderr contains `Usage:` and
    `--wpm`, stdout empty, `ui reached` absent): `--wpm 49 a`, `--wpm 1501 a`, `--wpm x a`,
    `--wpm= a`, `--wpm=49 a`, `-wpm 49 a`, `--size 0 a`, `--size 6 a`, `--size 2.5 a`,
    `--ui foo a`, `--ui TUI a`, `--start -1 a`, `--start 9999 a`, `--start 2 "a b"`,
    `--bogus a`, `-x a`, `--wpm` (missing value), `a b`, `hello --wpm 100`, `--no-resume=maybe
    a`.
  - reach-the-UI rows (exit 1, stderr exactly one line containing `ui reached`): `--wpm 50
    a`, `--wpm 1500 a`, `--wpm=300 a`, `--size 1 a`, `--size 5 a`, `--ui tui a`, `--start 0
    a`, `--start 1 "a b"`, `--no-resume --no-progress a`, `-- --wpm` (raw text `--wpm`).
- `TestHelpVersion`: `-h`, `--help`, `-help` → exit 0, stderr empty, stdout contains
  `Usage:` and each of `--wpm`, `--size`, `--ui`, `--start`, `--no-resume`, `--no-progress`,
  `--help`, `--version`, the ranges `50`, `1500`, `1`–`5` and the defaults `300` and `2`;
  `-h` and `--help` outputs are identical; `--version` and `-version` → exit 0, stderr
  empty, stdout matches `^fastread \S+\n$`; `--help` never reads stdin or opens the UI
  (the `openTerminal` seam fails the test if called).

If a row fails, fix `cmd/fastread/flags.go` or `run.go` (keep all names and signatures; all
existing tests, `TestParseFlags`, `TestRunUsage` and the `TestRun*` tests, must still pass).
Note `--wpm=` and `--no-resume=maybe` are rejected by stdlib `flag` itself; make sure such
errors are also reported as one `fastread:` line plus usage.

Constraints: stdlib only; tests never open `/dev/tty`, a window or the real state dir;
change only `cli_test.go`, `flags.go`, `run.go`.
