# T007: TUI runtime skeleton (terminal, alt screen, loop)

Phase 1 · Model: opus: terminal restore on every exit path, goroutine lifetime and dependency pins (Risks: `/dev/tty` dependence, toolchain drift; R13) · Depends-on: T004, T006

## Brief
Add the runtime half of package `internal/tui`: a `Terminal` abstraction with a real `/dev/tty`
implementation, and `Run`, which plays a `state.Player` in the alternate screen until quit, end
of text or context cancel, and always restores the terminal. Key decoding beyond quit keys,
SIGWINCH handling and the full key set come in later tasks.

Existing APIs you use (already in the repo):
- `internal/state`: `type Player`; `p.Start()`, `p.Tick() (finished bool)`,
  `p.Apply(a state.Action) (quit bool)`, `p.Deadline() time.Time`, `p.Index() int`,
  `p.Len() int`, `p.Token() tokenize.Token` (`.Text`), `p.Playing() bool`, `p.WPM() int`,
  `p.Size() int`, `p.ShowProgress() bool`, `p.ShowHelp() bool`, `p.Finished() bool`;
  `state.ActQuit`.
- `internal/tui` (same package): `Render(m Model, w, h int) Frame`,
  `Encode(f Frame, mode ColorMode) []byte`, `DetectColorMode(getenv func(string) string) ColorMode`,
  `Model{Word, Size, Paused, ShowProgress, ShowHelp, Index, Total, WPM, EffectiveWPM}`.

Dependencies: `GOTOOLCHAIN=local go get golang.org/x/term@v0.40.0 golang.org/x/sys@v0.41.0`
(exact pins; never `@latest`; `go.mod` must keep `go 1.24.x`).

Files to create:
- `internal/tui/terminal.go`:
  ```go
  // Terminal is the TUI's device. Run owns it and closes it before returning.
  type Terminal interface {
      Read(p []byte) (int, error) // raw key bytes; returns an error once Close was called
      Write(p []byte) (int, error)
      Size() (w, h int, err error)
      MakeRaw() error
      Restore() error // undoes MakeRaw; safe to call more than once
      Close() error
  }
  const (
      EnterSeq   = "\x1b[?1049h\x1b[?25l\x1b[2J" // alt screen on, cursor hidden, clear
      RestoreSeq = "\x1b[0m\x1b[?25h\x1b[?1049l" // reset SGR, cursor visible, alt screen off
  )
  // OpenTTY opens /dev/tty read-write (keys and output always use the controlling terminal,
  // even when stdin is a pipe). It returns an error when there is no controlling terminal.
  func OpenTTY() (Terminal, error)
  ```
  Real implementation: unexported type around `*os.File` from `os.OpenFile("/dev/tty",
  os.O_RDWR, 0)`; `golang.org/x/term` `MakeRaw`/`Restore`/`GetSize`. Never call
  `(*os.File).Fd()` (it switches the descriptor to blocking mode and `Close` then no longer
  unblocks a pending `Read`); obtain the descriptor once via `f.SyscallConn()` and `Control`.
- `internal/tui/run.go`:
  ```go
  type Options struct {
      Getenv func(string) string // colour detection; nil -> os.Getenv
  }
  // Run plays p on t until a quit key, the end of the text or ctx is done, and returns the
  // index of the word on screen. The caller checks p.Finished() to tell end-of-text from quit.
  func Run(ctx context.Context, t Terminal, p *state.Player, opts Options) (last int, err error)
  ```
  Required behaviour:
  1. `t.MakeRaw()`; on error close `t` and return the wrapped error without writing anything.
  2. Write `EnterSeq`. From here on, one deferred cleanup runs on every path, including panics:
     write `RestoreSeq`, `t.Restore()`, `t.Close()`, then wait until the reader goroutine has
     exited. A panic anywhere in the loop is recovered after cleanup and returned as an error
     (`tui: internal error: <value>`), never re-panicked.
  3. One reader goroutine reads `t` and forwards byte chunks on a channel; it exits when `Read`
     fails (after `Close`) and must never block forever on a send (select on a done channel).
  4. `p.Start()`, draw a frame: `t.Size()` → `Render(model from p, w, h)` → `Encode(…, mode)` →
     `t.Write`; mode = `DetectColorMode(getenv)` once at start.
  5. Loop with a `time.Timer` set to `time.Until(p.Deadline())`, stopped on exit: ctx done →
     return `p.Index(), nil`; key chunk → a chunk containing `q` or `0x03` (Ctrl+C), or a chunk
     that is exactly `0x1b` (Esc), means `p.Apply(state.ActQuit)` → return `p.Index(), nil`;
     other bytes are ignored for now; timer fired → `p.Tick()`; finished → return
     `p.Index(), nil`; else redraw and re-arm the timer.
  No `os.Exit`, no signal handling here (the caller cancels `ctx`).
- `internal/tui/run_test.go` with a fake `Terminal` in the test file (pipe-backed `Read` that
  fails after `Close`, mutex-guarded output buffer, counters for MakeRaw/Restore/Close,
  injectable size, optional panic in `Size`, optional MakeRaw error). Table-driven where it fits;
  each `Run` call bounded by a 5 s test timeout:
  - `TestRunQuitRestores`: keys `q`, `\x03`, `\x1b` each: Run returns (0, nil) at 50 wpm;
    output starts with `EnterSeq` and ends with `RestoreSeq`; MakeRaw, Restore, Close each ≥ 1.
  - `TestRunPlaysToEnd`: tokens `alpha bravo charlie` at 1500 wpm, no keys: returns (2, nil) in
    under 2 s, `p.Finished()` true; with Getenv giving `COLORTERM=truecolor` the output contains
    `\x1b[38;2;255;0;0m` followed by `l`, by `r` and by `a` (the focus letters).
  - `TestRunCtxCancel`: cancel the context after the first frame: returns quickly with
    `p.Finished()` false and the output ending in `RestoreSeq`.
  - `TestRunPanicRestores`: `Size` panics: Run returns a non-nil error, does not panic, output
    ends with `RestoreSeq`, Restore and Close were called.
  - `TestRunMakeRawFails` (negative): MakeRaw error → non-nil error, zero bytes written, Close
    called.
  - `TestRunNoGoroutineLeak`: `runtime.NumGoroutine()` after a quit run (polled up to 1 s) is
    not above the count before it.

Constraints: tests never open `/dev/tty`; no sleeps longer than needed (poll with deadlines);
must pass with `-race`; no Gio import; no `os.Exit`.
