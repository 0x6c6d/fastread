# T004: Playback model skeleton (state.Player)

Phase 1 · Model: sonnet: pure model with a given API and fake-clock tests, moderate design judgment · Depends-on: T001, T002

## Brief
Create package `internal/state` with the UI-independent playback model both UIs drive. No I/O,
no goroutines, no timers: the UI asks for `Deadline()` and calls `Tick()`.

Existing packages you use (already in the repo):
- `github.com/0x6c6d/fastread/internal/tokenize`: `type Token struct { Text string; ParaEnd bool }`.
- `github.com/0x6c6d/fastread/internal/timing`:
  `func DelayPara(word string, wpm int, paraEnd bool) time.Duration`, constants `MinWPM`, `MaxWPM`.

Files to create:
- `internal/state/clock.go`:
  ```go
  // Clock abstracts time for tests.
  type Clock interface{ Now() time.Time }
  // SystemClock is the real clock.
  type SystemClock struct{}
  func (SystemClock) Now() time.Time
  ```
- `internal/state/player.go`, package doc "Package state holds the playback model and resume
  storage. It must never import UI packages." Exactly this exported API (later tasks implement
  the remaining keys against it, keep every name):
  ```go
  type Action int
  const (
      ActNone Action = iota
      ActTogglePause    // Space
      ActWPMUp          // Up: +25
      ActWPMDown        // Down: -25
      ActSizeDown       // [
      ActSizeUp         // ]
      ActPrev           // Left
      ActNext           // Right
      ActHome           // Home
      ActToggleProgress // p
      ActToggleHelp     // ?
      ActQuit           // q, Esc, Ctrl+C
  )

  type Config struct {
      Tokens       []tokenize.Token // non-empty
      Start        int              // first word index, already validated by the caller
      WPM          int              // 50..1500
      Size         int              // 1..5
      ShowProgress bool
      Clock        Clock            // nil means SystemClock{}
  }

  type Player struct{ /* unexported fields only */ }

  func NewPlayer(cfg Config) *Player   // starts in the playing state; Start clamped to [0, len-1]
  func (p *Player) Start()             // deadline = Clock.Now() + delay(current word)
  func (p *Player) Tick() (finished bool)
  func (p *Player) Apply(a Action) (quit bool)
  func (p *Player) Deadline() time.Time
  func (p *Player) Index() int          // index of the word on screen
  func (p *Player) Len() int
  func (p *Player) Token() tokenize.Token // current word
  func (p *Player) Playing() bool
  func (p *Player) Finished() bool      // true once Tick reported the end of the text
  func (p *Player) WPM() int
  func (p *Player) Size() int
  func (p *Player) ShowProgress() bool
  func (p *Player) ShowHelp() bool
  ```
  Semantics in this task:
  - delay(word) = `timing.DelayPara(tok.Text, wpm, tok.ParaEnd)`.
  - `Tick()`: let now = Clock.Now(). While playing and `!now.Before(deadline)`: if the current word
    is the last one, set finished and return true (index stays on the last word); otherwise
    index++ and **deadline = previous deadline + delay(new word)** (absolute deadlines, never
    `now + delay`, so late ticks do not accumulate drift; one late Tick may skip several words).
    Returns false otherwise. After finishing, further Ticks keep returning true.
  - `Apply(ActQuit)` returns true. Every other action is accepted, returns false and changes
    nothing yet (mark with `// TODO(phase3): R26 keys`).
  - Accessors return the current values (ShowHelp false initially).

- `internal/state/player_test.go`, with a fake clock type in the test file:
  - `TestPlayerAdvance`: 3 tokens at 300 wpm (`a b c`, last ParaEnd), Start at t0: Tick at t0 and
    at deadline−1ns keeps index 0; Tick exactly at the deadline → index 1 and the new deadline is
    `t0 + delay(a) + delay(b)`; a Tick 1 s late jumps to the end and returns finished=true, Index
    stays 2, Finished() true.
  - `TestPlayerQuit`: table of all Actions: only ActQuit returns true; no other action changes
    Index, WPM, Size or Playing.
  - `TestPlayerStartClamp`: Start −3 → 0, Start 99 with 3 tokens → 2, Clock nil does not panic.

Constraints: standard library plus the two internal packages above only; no goroutines, no
sleeping, no real time in tests (fake clock only).
