# T025: Performance test: 5 MB load + tokenize under 2 s

Phase 2 · Model: sonnet: one timed table test with a build-tag constant; no security or contract decision · Depends-on: T015

## Brief
Add the spec's performance acceptance test (§5 Performance, AC28: loading a 5 MB UTF-8 text
file and tokenizing it takes under 2 seconds) to package `main` in `cmd/fastread` (module
`github.com/0x6c6d/fastread`). Existing APIs: `input.LoadFile(path string)
(input.Document, error)`, `input.Load(src input.Source, stdin io.Reader) (input.Document,
error)` with `input.Source{Kind: input.KindStdin}`, `Document.Paragraphs []string`,
`tokenize.Tokenize(paragraphs []string) []tokenize.Token`.

Files to create:
- `cmd/fastread/race_on_test.go` (`//go:build race`): `const raceEnabled = true`;
  `cmd/fastread/race_off_test.go` (`//go:build !race`): `const raceEnabled = false`.
- `cmd/fastread/perf_test.go`:
  - helper `perfText(size int) (data []byte, words int)`: deterministic (no randomness, or
    `math/rand` with a fixed seed), at least `size` bytes of valid UTF-8 prose: words of
    1–15 letters cycling through ASCII and a few non-ASCII words (`naïve`, `café`, `über`,
    `日本`), punctuation attached (`,` `.` `;` `!`), a blank line every 120 words; returns the
    exact number of whitespace-separated words.
  - `TestPerfLoadTokenize5MB`, table-driven over two rows: `file` (write the text to
    `t.TempDir()/big.txt`, then time `LoadFile` + `Tokenize`) and `stdin` (time
    `input.Load(Source{Kind: KindStdin}, bytes.NewReader(data))` + `Tokenize`). Size
    `5 << 20` bytes. Bound: `const perfBound = 2 * time.Second`, multiplied by 10 when
    `raceEnabled`. Generating and
    writing the file is NOT inside the timed section. Assert `len(tokens) == words` and that
    the last token has `ParaEnd == true`; log the measured duration with `t.Logf`.
  - `BenchmarkLoadTokenize5MB` doing the `file` row per iteration (not run by `check`).
- Do not use `testing.Short()` to skip; the test must run in every `go test` invocation of
  the check command (normal, `-race`, `-tags nogui`).

Constraints: stdlib only; never write outside `t.TempDir()`; do not change non-test code or
other tests (if the bound fails, stop and report the measured time instead of raising it).

## Verification
