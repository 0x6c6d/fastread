# T012: MIT LICENSE file

Phase 1 · Model: opus: licence text is a Consequential assumption (row 39, legal high-risk) despite the small diff · Depends-on: T000

## Brief
Create the file `LICENSE` in the repository root containing the standard MIT License text, verbatim
from the OSI/SPDX `MIT` template, with:
- first line exactly `MIT License`, then an empty line;
- the copyright line exactly `Copyright (c) 2026 Lucas Menke`;
- then the two standard paragraphs and the warranty disclaimer, unchanged: starting with
  `Permission is hereby granted, free of charge, to any person obtaining a copy` and ending with
  `OTHER DEALINGS IN THE SOFTWARE.`

No other file. Do not add licence headers to source files. Third-party licence texts (Go fonts,
font8x8) are a separate later task.

## Verification
`scripts/verify/T012.sh` exits 0. It checks the first line, the exact copyright line, the key
phrases of the MIT text and the final sentence; negative checks: no other licence family (GPL,
Apache, BSD clause text) and no placeholder such as `[year]` or `[fullname]` in the file.
