# T052: E2E terminal restore (TestE2ERestore)

Phase 5 · Model: sonnet: e2e test on the existing tmux harness, inspecting tmux pane state; restore logic itself is already opus-built and verified · Depends-on: T011, T050

## Brief
Package `e2e` (module `github.com/0x6c6d/fastread`; every file starts with `//go:build e2e`,
`_test.go` suffix). Existing helpers in `e2e/helpers_test.go` (do not change their
signatures): `buildBinary`, `stateEnv`, `newTmux(t, w, h, shellCmd) *tmuxSession` (own `-L`
socket, 10 s timeout per tmux call, cleanup kills the server), `capture(escapes bool)`,
`sendKeys(keys...)` (tmux key names: `q`, `C-c`, `Escape`, `Space`, …), `resize`,
`waitFor(cond, timeout) (string, bool)`, `watchWords`, the shell single-quoting helper, and
the unexported fields of `tmuxSession` (socket and session name; read the file).

Behaviour under test (R13, AC10): the TUI switches to the alternate screen, hides the cursor
and puts `/dev/tty` in raw mode; on `q`, Esc, Ctrl+C (a raw byte 0x03, not a signal), SIGTERM
and SIGINT it writes `\x1b[0m\x1b[?25h\x1b[?1049l`, restores the tty mode and exits 0.

Create `e2e/proc_test.go` with reusable helpers (later tasks use them; keep the names):
```go
// paneState returns tmux's #{alternate_on} and #{cursor_flag} for the session's pane
// (`display-message -p`), both as booleans.
func (s *tmuxSession) paneState() (altScreen, cursorVisible bool)
// appPID returns the PID of the fastread process running in the pane: the child of
// #{pane_pid} (from /proc/<pane_pid>/task/<pane_pid>/children) whose /proc/<pid>/comm is
// "fastread"; it polls up to 5 s and fails the test if none is found.
func (s *tmuxSession) appPID() int
```

Create `e2e/restore_test.go`, `TestE2ERestore`, one subtest per way out: `q`, `Escape`,
`C-c`, `SIGTERM`, `SIGINT` (signals via `syscall.Kill(appPID, …)`). Each subtest, own tmux
80×24, shell command: `echo MAIN-MARK; env <stateEnv> <bin> --no-resume --size 2 --wpm 60
'<30 words r00 … r29>'; echo "EXIT:$?"; stty -a | tr ' ' '\n' | grep -x -e icanon -e
-icanon -e echo -e -echo | sed 's/^/STTY:/'; sleep 600`. Steps: wait until the pane is on
the alternate screen (`paneState`) with the cursor hidden; then the way out; then within 2 s
the pane shows `EXIT:0`; afterwards: `paneState` reports main screen and cursor visible; the
pane shows `MAIN-MARK` (the main screen came back) and the lines `STTY:icanon` and
`STTY:echo` (canonical mode and echo restored); `capture(true)` of the final screen contains
no `?1049h` text and no block-glyph character (`▀ ▄ █`). Log the screens on failure.

Constraints: create only `e2e/proc_test.go` and `e2e/restore_test.go`; never use the default
tmux server, the user's sessions or the real `~/.local/state`; never signal a PID that
`appPID` did not verify; every external call under a timeout; no fixed sleeps longer than
the 20 ms poll; whole test well under 120 s; `go vet -tags e2e ./...` clean.

`scripts/verify/T052.sh` exits 0. It runs the check command, `go vet -tags e2e`, the helper
