# T009: CLI flags, usage, help and version

Phase 1 · Model: opus: the flag/argument contract is public behaviour (Consequential assumption 3: more than one positional argument is a usage error; Risk: CLI contract) · Depends-on: T001

## Brief
Create the `main` package `cmd/fastread` with flag parsing and validation (R11), usage, `--help`,
`--version` and exit code 2 for usage errors. Wiring to input/UI comes in a later task, which
replaces only the placeholder at the end of `run`.

Files to create:
- `cmd/fastread/main.go`:
  ```go
  // version is set with -ldflags "-X main.version=<v>".
  var version = ""
  func main() { os.Exit(run(os.Args[1:], os.Stdin, os.Stdout, os.Stderr, os.Getenv)) }
  // versionString returns "fastread <v>": version if set, else the main module version from
  // debug.ReadBuildInfo() unless it is "" or "(devel)", else "dev".
  func versionString() string
  ```
- `cmd/fastread/flags.go`:
  ```go
  type options struct {
      wpm, size            int    // defaults 300 and 2
      ui                   string // "tui" (default) or "gui"
      start                int    // valid only if startSet
      startSet             bool
      noResume, noProgress bool
      help, version        bool
      arg                  string // the positional argument
      hasArg               bool
  }
  // parseFlags parses args (without the program name). Every error it returns is a usage
  // error (exit 2) with a one-line message.
  func parseFlags(args []string) (options, error)
  // usage writes the usage text: "Usage: fastread [flags] [text | file]", one line per flag
  // (--wpm N, --size N, --ui tui|gui, --start N, --no-resume, --no-progress, -h/--help,
  // --version) with default and range, and a note that raw text with spaces must be quoted.
  func usage(w io.Writer)
  ```
  Use the stdlib `flag` package (`flag.NewFlagSet("fastread", flag.ContinueOnError)`, output
  discarded so you print your own messages); both `-x` and `--x` spellings work; define `h` and
  `help` explicitly; detect `--start` presence with `fs.Visit`. Flags must come before the
  positional argument; `--` ends flags (`fastread -- --wpm` is the raw text `--wpm`).
  Validation (each is a usage error): wpm outside 50–1500 or not an integer; size outside 1–5;
  ui not `tui`/`gui`; `--start` < 0; unknown flag; more than one positional argument (message
  says to quote raw text; this also covers flags written after the text). `--start` beyond the
  last word is checked later, after loading.
- `cmd/fastread/run.go`:
  ```go
  // run is the whole program; main only calls os.Exit(run(...)). Returns the exit code.
  func run(args []string, stdin io.Reader, stdout, stderr io.Writer, getenv func(string) string) int
  ```
  Order: parse error → `fastread: <msg>` (one line) then usage on stderr, return 2; `help` →
  usage on stdout, return 0; `version` → `versionString()` + newline on stdout, return 0;
  otherwise the placeholder `fmt.Fprintln(stderr, "fastread: not implemented yet"); return 1`
  marked `// TODO(T010): wiring`.
- `cmd/fastread/flags_test.go`, table-driven:
  - `TestParseFlags`: no args → defaults (300, 2, "tui", startSet false, hasArg false);
    `--wpm 100 --size 3 --ui gui --start 5 --no-resume --no-progress hello` → all fields set;
    `-wpm 120 x` → 120; `-- --wpm` → arg `--wpm`; `--start 0 x` → startSet true, start 0.
    Error rows: `--wpm 49`, `--wpm 1501`, `--wpm x`, `--size 0`, `--size 6`, `--ui foo`,
    `--start -1`, `--bogus`, `a b`, `hello --wpm 100`.
  - `TestRunUsage`: every error row through `run` → 2, stderr's first line starts with
    `fastread: ` and stderr contains `Usage:`, stdout empty; `-h` and `--help` → 0, stdout
    contains `Usage:` and every flag name, stderr empty; `--version` → 0, stdout matches
    `^fastread \S+\n$`, stderr empty.

Constraints: standard library only in this task; no `os.Exit` outside `main()`; no global mutable
state besides `version`; messages are one line each.

## Verification
`scripts/verify/T009.sh` exits 0. It runs the check command, requires `TestParseFlags` and
`TestRunUsage` to pass, builds the binary and checks `--help`/`-h` (exit 0, usage on stdout),
`--version` with `-ldflags -X main.version=1.2.3` (prints `fastread 1.2.3`); negative checks: each
invalid flag value, an unknown flag and two positional arguments exit 2 with a `fastread:` line and
usage on stderr and nothing on stdout.
