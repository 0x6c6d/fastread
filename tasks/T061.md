# T061: Gio window draws the pure layout, plays on Player deadlines, keys and resize

Phase 6 · Model: opus: the Gio window event loop (frame scheduling on absolute deadlines, Gio text shaping and ops, resize) is the routing policy's opus example and touches the Risk "GUI exit path" · Depends-on: T035, T046, T058, T059, T060

## Brief
Package `internal/gui` (module `github.com/0x6c6d/fastread`; Gio v0.10.3 source in
`$(go env GOMODCACHE)/gioui.org@v0.10.3`). Existing (keep names/behaviour): `window.go`
(`//go:build !nogui && cgo`): `Run(ctx, p *state.Player, opts Options, finish func(last
int, err error)) error` (no DISPLAY/WAYLAND_DISPLAY → `ErrNoDisplay` synchronously; else
the window goroutine + `app.Main()`; `finish` exactly once on quit key, close, end of text,
ctx done, `DestroyEvent.Err`, recovered panic; title `fastread`, 600×300 dp). Pure files
(no tag): `layout.go` (`Layout(LayoutInput{Word, Level, W, H, PxPerSp, Part, M})
LayoutResult{CX, Sp, Px, Parts, Part, Text, Clusters, Advances, Focus, OriginX, FocusX,
BaselineY, TickTop, TickBottom}`, `Measurer`, `Metrics`, `PxOf`), `chrome.go`
(`LayoutChrome(w, h, pxPerSp, index, total, m) Chrome{Px, Help, Progress, Bar, BarFill}`,
`HelpText`, `ProgressText(index, total, wpm, ok)`); `keys.go` (`keyFilters()`,
`keyAction(e) (state.Action, bool)`). Player: `Start Tick Apply Deadline Index Len Token
Playing Finished Size ShowProgress ShowHelp EffectiveWPM SetParts Part Parts` (`SetParts`
with equal parts is a no-op; absolute deadlines).

1. New `internal/gui/measure_gio.go` (`//go:build !nogui && cgo`): `gioMeasurer`
   implementing `Measurer` with ONE `text.Shaper` built as `text.NewShaper(text.NoSystemFonts(),
   text.WithCollection([]font.FontFace{{Font: font.Font{Typeface: "Go"}, Face: <goregular
   parsed by gioui.org/font/opentype>}}))`. Each cluster is shaped on its own
   (`LayoutString(text.Parameters{Font: …, PxPerEm: px, MaxWidth: 1<<24}, cluster)`,
   advance = sum of `Glyph.Advance`); `Metrics` = `Glyph.Ascent`/`Descent` of a shaped
   `"H"`; shaped glyphs cached per (cluster, px) and reused for drawing.
2. Each `app.FrameEvent` in `window.go` (`gtx := app.NewContext(&ops, e)`):
   a. keys: `gtx.Event(keyFilters()...)` until none; `keyAction` ok → `p.Apply`; quit →
      finish as today.
   b. first frame `p.Start()`; while `p.Playing()` and `!time.Now().Before(p.Deadline())`
      → `p.Tick()` (finished → finish(p.Index(), nil)).
   c. `res := Layout(…{Word: p.Token().Text, Level: p.Size(), W: e.Size.X, H: e.Size.Y,
      PxPerSp: e.Metric.PxPerSp, Part: p.Part(), M: m})`; `p.SetParts(res.Parts)`; if
      `p.Part() != res.Part` lay out again with `Part: p.Part()`.
   d. draw: fill black (#000000); each cluster i of `res.Clusters` at pen x = `OriginX +
      sum(Advances[:i])`, baseline `BaselineY`, via `op.Affine(f32.AffineId().Offset(…))`
      (sub-pixel, 26.6 → float32/64) and `clip.Outline{Path: sh.Shape(glyphs)}` filled red
      #FF0000 for `res.Focus`, white #FFFFFF otherwise; ticks `TickTop`/`TickBottom` filled
      white, every frame (also paused, R22); help (`p.ShowHelp()`): `HelpText` white at
      `Chrome.Help`; progress (`p.ShowProgress()`): `Bar` #404040, `BarFill` white,
      `ProgressText(p.Index(), p.Len(), wpm, ok)` (from `p.EffectiveWPM()`) light grey at
      `Chrome.Progress`, both at `Chrome.Px`. Nothing else is drawn; no other red pixel.
   e. `p.Playing()` → `gtx.Execute(op.InvalidateCmd{At: p.Deadline()})` (never `now +
      delay`); then `e.Frame(gtx.Ops)`. Resize needs nothing extra: every frame lays out
      `e.Size` anew (R23).
3. Keep the exit-path rules; keep the single window goroutine and the ctx helper; the
   Player is touched only by the window goroutine.

Test `internal/gui/measure_gio_test.go` (`//go:build !nogui && cgo`, no window):
`TestGioMeasurer`: for ≥ 30 words of ASCII and Latin-1 letters/punctuation (no combining
marks, no CJK/emoji) × px ∈ PxOf(10, 20, 32, 48, 64, 96) at k 1, `gioMeasurer.Advances`
equals `newFontMeasurer(t).Advances` exactly and `Metrics` are equal (checked here: the
Gio shaper and x/image give identical unhinted advances for every printable Latin-1 rune);
for the same words `Layout` with either measurer gives the same result.
