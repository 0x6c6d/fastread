# T034: Resume wiring in cmd (TUI path, signals, raw/stdin never persisted)

Phase 3 · Model: opus: signal-driven save, exit codes on save failure and the never-persist rule for raw text and stdin (Consequential assumptions 21–23, Risk "Resume privacy and data", R29, R32) · Depends-on: T024, T033

## Brief
Wire resume (R29) into `cmd/fastread` (module `github.com/0x6c6d/fastread`). Existing (keep
names/behaviour): `run`/`runErr`/`prepare`/`exitCode`/`usageError` and the seams
`openTerminal`, `stdinIsTTY`, `exitProcess` in `run.go`; `options` (`start startSet noResume
…`); a `// TODO(phase3): resume` marker where resume goes (remove it). From
`internal/state`: `Dir(getenv) (string, error)`, `NewStore(dir) *Store`, `(*Store).Load(path,
sum) (index int, ok bool, err error)` (corrupt → error wrapping `ErrCorruptState`),
`Save(path, sum, index) error`, `Delete(path) error`, `EntryPath(path) string`,
`StartIndex(start int, startSet, noResume bool, saved int, haveSaved bool, n int) int`,
`(*Player).Finished() bool`, `Index()`, `Start()`, `Tick()`, `Deadline()`. From
`internal/input`: `Document{Paragraphs; Path (abs, symlinks resolved; "" for raw/stdin);
SHA256}`. From `internal/tui`: `Run(ctx, t Terminal, p *state.Player, opts Options) (last
int, err error)` (returns on quit, end of text or ctx done).

New `cmd/fastread/resume.go`:
```go
// resumer persists the position of a file source; a nil *resumer does nothing.
type resumer struct{ store *state.Store; path string; sum [32]byte }
// newResumer: doc.Path == "" → nil, without reading the environment or the filesystem. Else
// state.Dir(getenv); on error one stderr line "fastread: warning: resume disabled: <err>",
// return nil. Creates nothing on disk.
func newResumer(doc input.Document, getenv func(string) string, stderr io.Writer) *resumer
// start = state.StartIndex(o.start, o.startSet, o.noResume, saved, haveSaved, n); Load only
// when r != nil && !o.startSet && !o.noResume. Load error → one stderr line
// "fastread: warning: ignoring saved position: <err>", continue as if nothing was saved.
func (r *resumer) start(o options, n int, stderr io.Writer) int
// finish: r == nil → nil; p.Finished() → Delete; else Save(path, sum, last). Errors are
// wrapped as "saving reading position: %w".
func (r *resumer) finish(p *state.Player, last int) error
```
At most one warning line per run. The state directory is created only by `Save`.

`run.go` changes: new seams `runTUI = tui.Run` and `notifyContext = signal.NotifyContext`
(used as `notifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)`). After
`prepare`: `r := newResumer(...)`, player `Start` = `r.start(o, len(tokens), stderr)`. TUI
branch: `openTerminal` error → exit 1, nothing saved; `last, err := runTUI(...)`; then always
`ferr := r.finish(p, last)`; exit 1 with `err` if non-nil, else 1 with `ferr` if non-nil,
else 0. SIGINT/SIGTERM cancel the context, `tui.Run` returns, the position is saved, exit 0.
Do not change the GUI branch (a later task wires it).

Tests `cmd/fastread/resume_test.go` (table-driven where it fits; getenv returns
`XDG_STATE_HOME=<tmp>/state`, `HOME=<tmp>/home`; seams restored with `t.Cleanup`; a minimal
fake `tui.Terminal` type defined in this file; a fake `runTUI` records `p.Index()` on entry
and returns a chosen `(last, err)`; "play to end" = `p.Start()` then `for !p.Tick() {
time.Sleep(time.Until(p.Deadline())) }`, return `p.Index()`):
- `TestRunRawNoState`: raw `"a b c"` and stdin `"a b c"` (`stdinIsTTY` false), each quit at
  1 and played to end, plus raw with `--no-resume`, raw with `--start 1`, raw with a getenv
  returning "" for everything → exit 0, stderr empty, and neither `<tmp>/state` nor
  `<tmp>/home` exists afterwards.
- `TestRunResumeFile` on `book.txt` with words `w00`…`w19` (entry =
  `state.NewStore(<tmp>/state/fastread).EntryPath(<EvalSymlinks abs path>)`), in order:
  first run starts at 0, returns 7 → exit 0, entry 0600 in a 0700 dir, JSON index 7, no
  `w0` text in it; next run starts at 7; `--start 3` starts at 3 (returns 4 → index 4);
  `--no-resume` starts at 0 (returns 2 → index 2); file changed (append ` w20`) → starts at
  0, stderr empty; `--wpm 1500 --start 18` played to end → exit 0, entry deleted; entry
  overwritten with `{` → exit 0, exactly one stderr line containing `warning`, starts at 0,
  entry valid afterwards; `runTUI` returning `(5, errors.New("boom"))` → exit 1, one line
  containing `boom`, index 5 saved. Negative: XDG_STATE_HOME below a regular file with

  XDG_STATE_HOME and no HOME → exit 0, one `resume disabled` line, nothing created;
  `openTerminal` failing → exit 1, entry unchanged.
- `TestRunSignalSaves`: real `tui.Run` (runTUI not replaced) with a fake terminal (Read

  exit 0 within 2 s, stderr empty, entry saved with index 0.

All existing `cmd/fastread` tests keep passing unchanged.

Constraints: change only `cmd/fastread/run.go`, `cmd/fastread/resume.go`,
`cmd/fastread/resume_test.go`; no new dependency; tests never touch the real `~/.local/state`,
`/dev/tty` or a window.

## Verification
`scripts/verify/T034.sh` exits 0. It runs the check command and the three tests (also
`-tags nogui`, `-race`), checks seams and `signal.NotifyContext`, then drives the built binary
in an isolated tmux: SIGTERM saves (0600 entry in 0700 dir, no text), restart resumes at
the saved word, `--start`/`--no-resume` override, `q` saves, reaching the end deletes.
Negative checks: corrupt entry → one warning, exit 0; unwritable state dir → exit 1; raw
text and stdin create no state; the real state dir is untouched.
