# T032: Resume store: directory, atomic save, delete, modes

Phase 3 · Model: opus: the only persisted data (absolute paths) with atomic writes, file modes and concurrent writers (Consequential assumption 21, Risk "Resume privacy and data", §5 data/privacy) · Depends-on: T004

## Brief
Add the write half of resume storage (R29) to package `internal/state` (module
`github.com/0x6c6d/fastread`) in a new file `internal/state/store.go`. Reading entries and the
start-index rule come in a later task. Stdlib only.

API (exact):
```go
var ErrNoStateDir = errors.New("no state directory: XDG_STATE_HOME is not absolute and HOME is not set")

// Dir returns the resume directory without creating anything: filepath.Join(XDG_STATE_HOME,
// "fastread") when XDG_STATE_HOME is an absolute path; else filepath.Join(HOME, ".local",
// "state", "fastread") when HOME is an absolute path; else ErrNoStateDir. A relative
// XDG_STATE_HOME is ignored (XDG rule).
func Dir(getenv func(string) string) (string, error)

// Store keeps one JSON entry per source file in its directory.
type Store struct{ /* unexported: dir */ }
func NewStore(dir string) *Store
func (s *Store) Dir() string
// EntryPath is filepath.Join(dir, hex(sha256([]byte(path))) + ".json") (lowercase hex).
func (s *Store) EntryPath(path string) string
// Save atomically writes {"path":path,"sha256":hex(sum),"index":index} for path.
func (s *Store) Save(path string, sum [32]byte, index int) error
// Delete removes the entry for path; a missing entry is not an error.
func (s *Store) Delete(path string) error
```
Entry content: exactly the three JSON keys `path` (the absolute path as given), `sha256`
(64 lowercase hex chars of `sum`) and `index` (int); nothing else, never any text of the file.
Encode via a struct with json tags (`encoding/json`).

`Save` steps (any failure returns an error wrapped with `%w` naming the entry path, and leaves
no temporary file behind):
1. Reject `index < 0` or a `path` that is not absolute (nothing is created).
2. `os.MkdirAll(dir, 0o700)`; then `os.Lstat(dir)`: must be a directory (not a symlink or
   file), else error; if its permission bits are not exactly 0700, `os.Chmod(dir, 0o700)`.
3. `os.CreateTemp(dir, ".entry-*.tmp")`, `Chmod(0o600)`, write the JSON through the seam
   `writeData`, `Sync`, `Close`, then the seam `renameFile(tmp, EntryPath(path))`. Rename
   replaces an existing entry (also one that is a symlink: the link is replaced, its target
   is never written). Best effort: `os.Open` the directory and `Sync` it after the rename.
   `store.go` never calls `os.Create`, `os.OpenFile` or `os.WriteFile`.
Unexported seams in `store.go` (tests swap them and restore with `t.Cleanup`):
```go
var (
    writeData  = func(f *os.File, b []byte) error { _, err := f.Write(b); return err }
    renameFile = os.Rename
)
```
Concurrent `Save` calls for the same path (two instances) must each leave a complete entry:
last rename wins, never a mixed or partial file. No package-level mutable state besides the
two seams.

Tests in `internal/state/store_test.go` (table-driven; only `t.TempDir()` paths; never the
real HOME; tests that swap seams or umask do not call `t.Parallel()`):
- `TestResumeDirFallback`: getenv tables: XDG `/x/state` → `/x/state/fastread`; XDG
  `/x/state/` → `/x/state/fastread`; XDG "" + HOME `/home/u` → `/home/u/.local/state/fastread`;
  XDG `rel/dir` + HOME `/home/u` → HOME fallback; XDG "" + HOME "" → `ErrNoStateDir`; XDG
  `rel` + HOME `u` → `ErrNoStateDir`. `Dir` with a temp XDG creates nothing.
- `TestResumeModes`: with `syscall.Umask(0)` (restored after): a fresh dir (parents missing)
  is 0700 and the entry 0600; a pre-existing dir with 0755 becomes 0700; a pre-existing entry
  with 0644 becomes 0600 after Save. Negative: `dir` exists as a regular file → error, file
  untouched; `dir` is a symlink to a directory → error; `index -1` and relative path →
  error and no dir created.
- `TestResumeAtomic`: an existing entry for P (index 3); `renameFile` failing → Save error,
  entry bytes unchanged, the dir contains only that entry; `writeData` writing half the
  bytes then failing → same; 8 goroutines saving P with indices 0..7 concurrently (`-race`)
  → the entry parses as JSON with an index in 0..7, no other file in the dir; the entry is
  a symlink to an outside file → after Save the outside file is unchanged and the entry is a
  regular 0600 file.
- `TestResumeDeleteAtEnd`: Save then Delete → the entry is gone, the dir remains (0700) and
  is empty; Delete again → nil; Delete of another path leaves the first entry intact; Save
  for two paths → two distinct entry files named by `EntryPath`, whose JSON decodes into a
  `map[string]any` with exactly the keys `path`, `sha256`, `index`.

Constraints: create only `internal/state/store.go` and `internal/state/store_test.go`; stdlib
only; no UI imports; no logging of paths.
