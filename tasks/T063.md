# T063: E2E Xvfb harness and TestE2EGUIXvfb

Phase 6 · Model: sonnet: e2e test plus process helpers on the existing harness; the window and exit path are already opus-built and verified (AC19) · Depends-on: T011, T062

## Brief
Package `e2e` (module `github.com/0x6c6d/fastread`; every file starts with `//go:build
e2e`, `_test.go` suffix). Existing helpers in `e2e/helpers_test.go` (do not change
signatures): `buildBinary(t, buildArgs...) string`, `stateEnv(t) string`
(`XDG_STATE_HOME=<t.TempDir()>`), the tmux helpers and a shell single-quoting helper.

Behaviour under test (R21, R23, R24, AC19): `fastread --ui gui [flags] <text|file>` opens a
window titled `fastread`, 600×300 px under Xvfb, black, playing; `q`, Escape and Ctrl+C
quit with exit 0 and empty stderr; SIGTERM/SIGINT exit 0 (file position saved under
`$XDG_STATE_HOME/fastread/<hash>.json`, mode 0600, `{"path","sha256","index"}`); the end
of the text exits 0 by itself; resizing re-lays out without crashing. Facts checked here
with xdotool 3.20160805 on Xvfb (no window manager): keys reach the window only after
`xdotool windowfocus --sync <wid>`; key names `q`, `Escape`, `ctrl+c`, `space`, `Home`,
`Left`, `Right`, `Up`, `Down`, `bracketleft`, `bracketright`, `p`, `question`;
`windowsize <wid> W H` resizes; `windowclose` does NOT end a Gio window (do not test the
close button live).

Create `e2e/xvfb_test.go` (reusable, keep the names):
```go
// newXvfb starts `Xvfb -displayfd 3 -screen 0 1280x1024x24 -nolisten tcp` (fd 3 = pipe via
// ExtraFiles), reads the display number within 10 s and returns ":N"; t.Cleanup kills it
// and waits. Fail (not skip) if Xvfb or xdotool is missing.
func newXvfb(t *testing.T) string
// guiEnv: os.Environ() without DISPLAY, WAYLAND_DISPLAY, XDG_STATE_HOME, plus
// DISPLAY=display and XDG_STATE_HOME=stateDir.
func guiEnv(display, stateDir string) []string
type guiApp struct{ /* cmd, pid, display, window id, stderr buffer (mutex), done chan, exit code */ }
// startGUI starts bin args with env (stdin /dev/null, stdout/stderr captured, a 120 s
// context), then waits up to 10 s for `xdotool search --sync --name ^fastread$` (under its
// own 10 s context) and keeps the window id; t.Cleanup kills the process if still running.
func startGUI(t *testing.T, display string, env []string, bin string, args ...string) *guiApp
func (a *guiApp) keys(names ...string)            // windowfocus --sync <wid> key --delay 60 …
func (a *guiApp) wait(d time.Duration) int        // exit code, -1 on timeout
func (a *guiApp) alive() bool
func (a *guiApp) geometry() (w, h int)            // from `xdotool getwindowgeometry <wid>`
func (a *guiApp) resize(w, h int)                 // `xdotool windowsize <wid> w h`
func (a *guiApp) stderr() string
// readIndex reads "index" from the single *.json entry in <stateDir>/fastread and checks
// its mode is 0600 (fails the test otherwise).
func readIndex(t *testing.T, stateDir string) int
```
Every xdotool call runs under a context timeout (10 s) with `DISPLAY` set to the Xvfb
display only; never touch the user's display or `WAYLAND_DISPLAY`.

Create `e2e/gui_test.go`, `TestE2EGUIXvfb`, one Xvfb for the whole test, one process per
subtest (sequential), raw text `hello` × 60 unless stated, `--no-resume`:
- `quit-q`, `quit-escape`, `quit-ctrl-c` (`--wpm 60`): window geometry 600×300; still
  alive after 2 s; key → exit 0 within 3 s; stderr empty.
- `sigterm`, `sigint` (book file `w000`…`w199`, `--wpm 300`): after 1.5 s the signal to the
  pid → exit 0 within 2 s; `readIndex` ≥ 1.
- `end-of-text`: `--wpm 1500 'a b c'` without waiting for a window: exit 0 within 8 s.
- `resize` (`--wpm 60`): 801×401 → geometry 801×401; 1×1, after 1 s still alive; 600×300;
  `q` → exit 0.
Log stderr and the subtest's timings on failure.

Constraints: create only `e2e/xvfb_test.go` and `e2e/gui_test.go`; stdlib only; every
external call under a timeout; no process or Xvfb left running; never the real
`~/.local/state`; whole test well under 120 s; `go vet -tags e2e ./...` clean.
