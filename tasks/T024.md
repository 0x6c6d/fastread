# T024: Typed-error chain and exit-code mapping (R12)

Phase 2 · Model: opus: exit codes and error wrapping are the public CLI contract across every loader (Risk "CLI contract"; R7, R12, AC6, AC27) · Depends-on: T014, T015, T018, T021

## Brief
Make the error → exit-code path in `cmd/fastread` (module `github.com/0x6c6d/fastread`)
explicit and testable, so `errors.Is` on the sentinels of `internal/input` works on the error
that `run` acts on. Existing (keep names/signatures and behaviour): `run(args []string,
stdin io.Reader, stdout, stderr io.Writer, getenv func(string) string) int`, `options`
(`wpm size ui start startSet noResume noProgress help version arg hasArg`),
`parseFlags`, `usage(w)`, `versionString()`, seams `openTerminal`, `stdinIsTTY`,
`exitProcess` in `run.go`. From `internal/input`: `Select(arg string, hasArg, stdinIsTTY
bool) (Source, error)`, `Load(src Source, stdin io.Reader) (Document, error)`, sentinels
`ErrNotFound ErrCorruptEPUB ErrEmpty ErrUnsupported ErrNoText ErrCorruptPDF ErrTooLarge
ErrNoInput`; from `internal/tokenize`: `Tokenize(paragraphs []string) []Token`.

Refactor `cmd/fastread/run.go` into these functions (exact names):
```go
// usageError marks a usage error: exit 2, usage printed after the error line.
type usageError struct{ err error }
func (e usageError) Error() string
func (e usageError) Unwrap() error

// prepare is the part of the flow before any UI starts: Select, Load, Tokenize, the empty
// check (error wrapping input.ErrEmpty) and the --start range check (usageError).
func prepare(o options, stdin io.Reader, isTTY bool) (input.Document, []tokenize.Token, error)

// exitCode maps an error: nil → 0; usageError or input.ErrNoInput in the chain → 2; else 1.
func exitCode(err error) int

// runErr is run without printing errors: it prints only help/version output and returns
// the exit code and the error that caused a non-zero code (nil when the code is 0).
func runErr(args []string, stdin io.Reader, stdout, stderr io.Writer, getenv func(string) string) (int, error)
```
`parseFlags` errors are wrapped in `usageError` by `runErr`. `run` = `runErr`, then for a
non-nil error one stderr line `fastread: <message>` (newlines replaced by spaces), followed
by `usage(stderr)` when the code is 2; it returns the code. The GUI `finish` callback keeps
printing its own line and calling `exitProcess`. Every loader error is wrapped with `%w` on
its way up (never `%v`, never re-created), with the file path in the message.

Tests in `cmd/fastread/errors_test.go` (table-driven; temp files in `t.TempDir()`; reuse
the fake terminal type that `run_test.go` already defines, read that file for its name):
- `TestErrorsIsChain` (AC27), rows through `runErr` with `stdinIsTTY` forced false; each row
  asserts `errors.Is(err, want)` for its sentinel, `!errors.Is` for the other listed
  sentinels, code 1, and that `run` with the same input prints one line containing the
  sentinel's own message:
  - missing `filepath.Join(dir, "nope.txt")` → `ErrNotFound` (`file not found`);
  - the first half of `../../internal/input/testdata/sample.epub` saved as `half.epub` →
    `ErrCorruptEPUB`;
  - raw text `"   "` and stdin `"\n\n"` → `ErrEmpty` (`empty text`);
  - `x.pdf` containing `hello world` → `ErrUnsupported` (AC6), and a directory argument →
    `ErrUnsupported`;
  - `../../internal/input/testdata/notext.pdf` → `ErrNoText`
    (`no extractable text (scanned PDF?)`).
  Also: `exitCode` table (nil, `usageError`, wrapped `ErrNoInput`, each sentinel wrapped twice
  with `fmt.Errorf("a: %w", …)`, a plain error).
- `TestExitCodes` (R12), rows through `run` with seams: 0 for `--help`, `--version`, and
  `--wpm 1500 "a b"` with the fake terminal (plays to end); 1 for each `TestErrorsIsChain`
  input, `openTerminal` failing, and `--ui gui x` with getenv returning `""`
  (`exitProcess` must not be called); 2 for `--wpm 49 x`, `--bogus x`, `a b`,
  `--start 5 "a b"` and no argument with `stdinIsTTY` forced true. Assert stderr: code 0 →
  empty; code 1 → exactly one line starting `fastread: `; code 2 → first line starts
  `fastread: ` and `Usage:` follows. stdout is empty except for help/version.

All existing tests in `cmd/fastread` must keep passing unchanged.

Constraints: no `os.Exit` outside `main()`/`exitProcess`; no new dependency; change only
`run.go`, `errors_test.go` (and `flags.go` only if a usage error is not wrapped).
