# T015: File type detection, file loading and loader stubs

Phase 2 · Model: opus: reads untrusted files through the size caps and fixes the resume key path (Consequential assumptions 11 and 21; R2 mismatch rule) · Depends-on: T010, T013

## Brief
Implement `KindFile` loading in package `internal/input` (module `github.com/0x6c6d/fastread`):
read the file through the cap, detect its type by extension AND magic bytes, dispatch to a
loader, fill `Document.Path`/`SHA256`. Markdown/EPUB/FB2/PDF loaders are stubs here with fixed
signatures; later tasks replace each stub file entirely.

Existing (keep names/signatures): sentinels `ErrNotFound ErrCorruptEPUB ErrEmpty ErrUnsupported
ErrNoText ErrCorruptPDF ErrTooLarge ErrNoInput`; `Document{Paragraphs []string; Path string;
SHA256 [32]byte}`; `Source`/`KindFile`; `ParseText(b []byte) []string`;
`load(src Source, stdin io.Reader, lim Limits) (Document, error)` in `input.go`; in `safe.go`:
`Limits`, `DefaultLimits()`, `readFileCapped(path string, max int64) ([]byte, error)`
(ErrNotFound / ErrTooLarge).

`internal/input/detect.go`:
```go
type FileType int
const (
    TypeText FileType = iota + 1
    TypeMarkdown
    TypeEPUB
    TypeFB2
    TypePDF
)
// DetectType picks the loader from the file name and head (the first up to 64 KiB).
func DetectType(name string, head []byte) (FileType, error)
```
Magic: EPUB = head starts with `PK\x03\x04`; PDF = starts with `%PDF-`; FB2 = within the first
4 KiB, after an optional UTF-8 BOM, whitespace, one optional `<?xml …?>` declaration and any
`<!-- … -->` comments, the first element starts with `<FictionBook` (followed by space, `>` or
`/`). Extension = `strings.ToLower(filepath.Ext(name))`. Rules:
- `.epub`/`.pdf`/`.fb2` → that type iff its own magic matches, else error.
- `.txt`/`.md` → TypeText/TypeMarkdown unless EPUB, PDF or FB2 magic matches (then error).
- any other or no extension → EPUB/PDF/FB2 by magic; else head is valid UTF-8 (a rune cut off
  at the 64 KiB end is allowed) without NUL → TypeText; else error.
Every error wraps `ErrUnsupported` and names the extension and the detected content, one line.

`internal/input/load.go`:
```go
// LoadFile reads path (capped at DefaultLimits().MaxBytes), detects the type and loads it.
func LoadFile(path string) (Document, error)   // == loadFile(path, DefaultLimits())
func loadFile(path string, lim Limits) (Document, error)
```
`loadFile`: `readFileCapped(path, lim.MaxBytes)`; `DetectType(path, first 64 KiB)`; dispatch:
TypeText → `ParseText`; TypeMarkdown → `loadMarkdown(b)`; TypeEPUB → `loadEPUB(b, lim)`;
TypeFB2 → `loadFB2(b, lim)`; TypePDF → `loadPDF(b, lim)`. `Path` = `filepath.Abs` then
`filepath.EvalSymlinks` (symlinks resolved; the resume key); `SHA256` = `sha256.Sum256(b)`.
Loader errors are returned wrapped with `%w` and the path in the message. In `input.go`, make
`load` handle `KindFile` via `loadFile(src.Path, lim)` (replacing the "not implemented" error).

Stub files (exact signatures; later tasks replace the bodies):
- `markdown.go`: `func loadMarkdown(b []byte) ([]string, error)` → `ParseText(b), nil`.
- `epub.go`: `func loadEPUB(b []byte, lim Limits) ([]string, error)`
- `fb2.go`: `func loadFB2(b []byte, lim Limits) ([]string, error)`
- `pdf.go`: `func loadPDF(b []byte, lim Limits) ([]string, error)`
  The last three return `fmt.Errorf("%w: <TYPE> loader not implemented yet", ErrUnsupported)`.

Tests (package `input`, table-driven, temp files only in `t.TempDir()`):
- `detect_test.go` `TestDetectType`: `a.txt` text → Text; `A.TXT` → Text; `n.Md` → Markdown;
  `b.epub` + PK → EPUB; `d.pdf` + `%PDF-1.4` → PDF; `x.fb2` + `<?xml version="1.0"?>\n<!-- c
  --><FictionBook xmlns="…">` → FB2; BOM + `<FictionBook>` → FB2; no extension with each of the
  three magics → that type; no extension UTF-8 → Text; head of 65536 bytes ending in a cut
  2-byte rune → Text; `.FB2` with `<FictionBook` after 5000 bytes of spaces → error.
- `TestUnsupportedMismatch` (AC6): via `LoadFile` on temp files: `x.pdf` containing
  `hello world` → `errors.Is(err, ErrUnsupported)`; also `.epub` with text, `.fb2` without
  `<FictionBook`, `.txt` starting `%PDF-`, `.md` starting `PK\x03\x04`, no extension with a NUL
  byte, `.dat` with invalid UTF-8 → `ErrUnsupported`.
- `load_test.go` `TestLoadFile`: a `.txt` file → paragraphs, `Path` absolute and equal to
  `EvalSymlinks` of it, `SHA256` = `sha256.Sum256(content)`; a symlink to it → same `Path`;
  missing file → `ErrNotFound`; `loadFile` with `Limits{MaxBytes: 4, MaxEntries: 1,
  MaxDepth: 1}` on a 5-byte file → `ErrTooLarge`; an empty `.txt` → no paragraphs, no error;
  `Load(Source{Kind: KindFile, Path: p}, nil)` equals `LoadFile(p)`; a `.md` file loads (stub).

Constraints: stdlib only; never write outside test temp dirs; do not touch tests of other files.
