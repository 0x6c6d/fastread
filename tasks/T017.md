# T017: XHTML to paragraphs (EPUB content converter)

Phase 2 · Model: opus: converts untrusted EPUB content and adds the pinned `golang.org/x/net` dependency (R4; Consequential assumption 13: script/style/head dropped, block elements; Risk "untrusted parsing") · Depends-on: T013

## Brief
Add the converter that turns one EPUB content document (XHTML bytes) into paragraphs, in
package `internal/input` (module `github.com/0x6c6d/fastread`). The EPUB loader (a later task)
calls it once per spine item; it never sees zip or file paths.

Dependency: run exactly `GOTOOLCHAIN=local go get golang.org/x/net@v0.50.0` after adding the
import. `go.mod` must keep its `go 1.24.x` line and gain no module other than `golang.org/x/net`
(an indirect `golang.org/x/text v0.34.0` line is acceptable only if `go mod tidy` adds it).

`internal/input/xhtml.go`, exactly this function (unexported; it never fails):
```go
// xhtmlParagraphs extracts the readable text of an XHTML/HTML document as paragraphs.
func xhtmlParagraphs(b []byte) []string
```
Implementation rules:
- Use the streaming tokenizer `html.NewTokenizer(bytes.NewReader(b))` from
  `golang.org/x/net/html`; never the tree builder `html.Parse` (no DOM, no depth issues).
  Stop at the first `html.ErrorToken` (EOF or otherwise).
- Text tokens: `z.Text()` (entities such as `&amp;`, `&eacute;`, `&#8217;`, `&nbsp;` are
  decoded by the tokenizer). Make the text valid UTF-8 (`strings.ToValidUTF8(s, "�")`).
- Skipped content: everything inside `head`, `script`, `style`, `template`, `noscript`,
  `title` (track a nesting counter; start tags increment, matching end tags decrement).
- XHTML gotcha: the tokenizer switches to raw-text mode after `script`, `style`, `title`,
  `textarea`, `noscript`, `iframe`, `xmp`, `noembed`, `noframes`, `plaintext` start tags, even
  for a self-closing `<script src="a.js"/>`, which would swallow the rest of the document.
  On every `html.SelfClosingTagToken` call `z.NextIsNotRawText()`; self-closing tags never
  change the skip counter.
- Paragraph boundaries: a start, end or self-closing tag of any of `p div h1 h2 h3 h4 h5 h6
  li blockquote br tr section article aside header footer nav pre ul ol table dl dt dd
  figure figcaption hr body` ends the current paragraph. Other (inline) tags such as `span em
  strong b i a sup sub small code` never split a word: `wo<em>rd</em>` yields `word`.
- A paragraph is its text with whitespace runs collapsed to one space and trimmed
  (`strings.Join(strings.Fields(s), " ")`); empty paragraphs are dropped.
- Comments, doctype, `<?xml …?>` and CDATA sections produce no text.

`internal/input/xhtml_test.go` (package `input`), table-driven `TestXHTMLText` comparing the
exact `[]string` result:
- `<p>a</p><p>b</p>` → `[a b]` (two paragraphs); `<p>x<br/>y</p>` → `[x y]` (two);
  `<div><p>one</p>two</div>` → `[one two]` (two); `<h2>Head</h2>text` → `[Head text]` (two).
- full document `<?xml version="1.0" encoding="utf-8"?><!DOCTYPE html><html xmlns="http://www.w3.org/1999/xhtml"><head><title>Head Title</title><style>p{color:red}</style></head><body><h1>One</h1><p>first &amp; caf&eacute;</p><script>var hidden = 1;</script></body></html>`
  → `["One", "first & café"]`.
- `<head><title/></head><body><script src="a.js"/><p>visible</p></body>` → `["visible"]`.
- `<p>wo<em>rd</em> and <a href="x">link</a></p>` → `["word and link"]`.
- `<table><tr><td>a</td><td>b</td></tr><tr><td>c</td></tr></table>` → `["a b", "c"]`.
- `<p>&#8217;q&nbsp;r</p>` → `["’q r"]` (U+00A0 is whitespace and collapses).
- `<!-- hidden comment --><p>shown</p>` → `["shown"]`; `<noscript>no</noscript><p>yes</p>` →
  `["yes"]`; `""` → no paragraphs; `"\xff<p>ok</p>"` → `["�", "ok"]`.
- unclosed `<p>tail` → `["tail"]`; `<script>never closed` → no paragraphs; no panic for 1000
  nested `<div>`s around a word (→ that word).
- performance: a generated 2 MiB document of `<p>` paragraphs is converted in under 2 s
  (20 s when built with `-race`; detect with a `//go:build race` constant file pair
  `race_on_test.go`/`race_off_test.go` declaring `const raceEnabled`, unless a constant with
  that name already exists in the package's tests, then reuse it).

Constraints: `golang.org/x/net/html` is imported only in `xhtml.go`; no network code; do not
change other files except `go.mod`/`go.sum` and the two race constant files.
