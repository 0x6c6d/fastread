# T016: Markdown stripper

Phase 2 · Model: sonnet: hand-written text transform with a fixed expected word list; no untrusted-binary parsing · Depends-on: T015

## Brief
Replace the stub in `internal/input/markdown.go` (package `input`, module
`github.com/0x6c6d/fastread`) with a real stripper. Keep the exact signature:
```go
func loadMarkdown(b []byte) ([]string, error)
```
It is called for `.md` files after detection. Decode like `ParseText` (existing:
`func ParseText(b []byte) []string`: invalid UTF-8 → U+FFFD, BOM dropped, CRLF/CR → LF,
paragraphs separated by blank lines). Never returns an error for any input; never panics.

Strip (R3 plus Plan rules), line-oriented, then inline:
- Fenced code blocks (``` or ~~~, 3+ chars, optional info string, up to 3 spaces indent) are
  dropped entirely, including content; an unclosed fence drops everything to the end.
- ATX heading markers (`#`–`######` + space, optional closing `#`s); Setext underline lines
  (`===`/`---` under a text line) removed, the text kept as its own paragraph.
- Headings are always their own paragraph.
- Blockquote `>` prefixes, list markers (`-`, `*`, `+`, `1.`, `1)`) removed; each list item
  is its own paragraph.
- Horizontal rules (`***`, `---`, `___`, 3+ with optional spaces) removed.
- Tables: separator rows (`|---|:--:|`) removed; leading/trailing `|` and cell pipes become
  spaces.
- Reference definitions (`[id]: url ...`) removed.
- Inline: images `![alt](url)` → `alt`; links `[text](url "title")` → `text`;
  reference links `[text][id]` and `[text][]` → `text`; autolinks `<http…>`/`<mailto:…>` dropped;
  inline HTML tags (`<span>`, `</span>`, `<br/>`) removed, their text kept; inline code
  `` `…` `` (any backtick-run length) dropped with its content; emphasis/strong markers
  `*`, `**`, `***`, `_`, `__` removed when they wrap text (an `_` inside a word such as
  `snake_case` stays; a lone ` * ` between spaces stays); backslash escapes resolved
  (`\*` → `*`, `\#` → `#`, `\_` → `_`, `\\` → `\`), after the emphasis pass.
- Collapse runs of spaces left behind; drop paragraphs that become empty.

  Here"`; some paragraph equals `Setext Heading`; no paragraph contains `http`, `fenced`,
  `inline code`, `|`, `#`, `` ` ``, `](`, `**`, `===`, `img.png`.
- inline rows on `loadMarkdown`: `**a** _b_ ***c***` → `a b c`; `[x](u "t")` → `x`;
  a double-backtick code span that contains a single backtick, followed by ` d` → `d`;
  `"~~~\ncode\n~~~\nafter"` → `after`; an unclosed triple-backtick fence drops the rest;
  backslash-hash `\# not heading` → `# not heading` (kept, not a heading); `---` as the only
  line → nothing; empty input and `"\xff"` (→ `�`) do not panic; a 100 000-line input
  finishes in under 5 s (also under `-race`).

Constraints: stdlib only, no regexp backtracking blowups on long lines (prefer hand scanning or
simple regexps applied per line); do not change other loaders or tests.
