# T033: Resume store: load, corrupt-entry handling, start index

Phase 3 · Model: opus: parses an on-disk file anyone could have edited (untrusted input) and decides the start position contract (Consequential assumption 21, §5 data/privacy: corrupt state is never fatal) · Depends-on: T032

## Brief
Add the read half of resume storage (R29) to package `internal/state` (module
`github.com/0x6c6d/fastread`), in `internal/state/store.go` next to the existing write half.
Existing (keep exactly): `Dir(getenv)`, `ErrNoStateDir`, `NewStore(dir) *Store`,
`(*Store).Dir()`, `(*Store).EntryPath(path string) string` (= dir/hex(sha256(path)).json),
`(*Store).Save(path string, sum [32]byte, index int) error` (atomic; JSON
`{"path","sha256","index"}`, sha256 = 64 lowercase hex chars), `(*Store).Delete(path)`,
seams `writeData`, `renameFile`. Stdlib only.

Add (exact):
```go
// ErrCorruptState marks an entry that exists but cannot be used. Callers print at most one
// warning and continue as if there were no entry; it is never fatal.
var ErrCorruptState = errors.New("unreadable or corrupt resume state")

// Load returns the saved index for path. No entry → (0, false, nil). Stored sha256 differs
// from sum (the file changed) → (0, false, nil). Unusable entry → (0, false, err) with
// errors.Is(err, ErrCorruptState). Never panics, never modifies or deletes anything.
func (s *Store) Load(path string, sum [32]byte) (index int, ok bool, err error)

// StartIndex returns the first word for a text of n >= 1 words: startSet → start (the caller
// already rejected start >= n as a usage error; clamp into [0, n-1] defensively); else
// noResume or !haveSaved → 0; else saved when 0 <= saved < n, otherwise 0 (stale entry for
// a text that is now shorter).
func StartIndex(start int, startSet, noResume bool, saved int, haveSaved bool, n int) int
```
Pure helper (unexported, fuzzed):
```go
// decodeEntry parses entry bytes for path and sum with the same results as Load.
func decodeEntry(b []byte, path string, sum [32]byte) (index int, ok bool, err error)
```
Rules for `Load`/`decodeEntry` (every failure wraps `ErrCorruptState` with `%w`; messages
never contain file contents):
- `os.Lstat` the entry: not exist (`errors.Is(err, fs.ErrNotExist)`) → (0, false, nil); any
  other stat error, or not a regular file (symlink, directory, FIFO, …) → corrupt (do not
  follow symlinks; never open a FIFO).
- Read at most 64 KiB + 1 bytes through `io.LimitReader`; more than 64 KiB → corrupt; read
  or permission error → corrupt.
- `json.Decoder` with `DisallowUnknownFields`; exactly one JSON object (trailing data other
  than whitespace → corrupt); all three keys required (`path` string, `sha256` string,
  `index` integer: use pointer fields to detect absence); `path` must equal the requested
  path; `sha256` must be 64 lowercase hex chars; `index >= 0`. Wrong JSON types, `null`,
  arrays, floats like `1.5` → corrupt.
- Valid entry with `sha256 != hex(sum)` → (0, false, nil). Else (index, true, nil). An index
  beyond the word count is not Load's concern (StartIndex ignores it).

Tests in `internal/state/store_load_test.go` (table-driven; `t.TempDir()` only):
- `TestResumeRoundTrip`: Save/Load for indices 0, 1, 41, 1<<30 → same index, ok true; Save
  over an existing entry → Load returns the new index; two paths keep separate indices;
  Load for a never-saved path → (0, false, nil); Load on a store whose dir does not exist →
  (0, false, nil) and creates nothing.
- `TestResumeHashMismatch`: Save with sum A; Load with sum B → (0, false, nil); Load with A →
  ok; Save with B then Load with B → new index.
- `TestResumeCorruptIgnored`: rows written directly to `EntryPath`: empty file, `{`, `null`,
  `[]`, `"x"`, missing `index`, missing `path`, `"index":-1`, `"index":"3"`, `"index":1.5`,
  unknown extra key, `sha256` of 63 chars, uppercase hex, non-hex, other `path`, two objects
  `{…}{…}`, 100 KiB of spaces after a valid object, entry is a directory, entry is a symlink
  to a valid entry file elsewhere, entry is a FIFO (`syscall.Mkfifo`; Load must return
  promptly, test bounded with a 5 s timer), entry mode 000 (skip that row when
  `os.Geteuid() == 0`). Each → ok false, `errors.Is(err, ErrCorruptState)`, no panic, the
  entry bytes/mode unchanged afterwards; a later `Save` replaces the corrupt entry and Load
  then succeeds.
- `TestStartIndex`: table over (start, startSet, noResume, saved, haveSaved, n): --start
  wins over a saved index; --start 0 wins over saved 5; noResume → 0 even with saved;
  saved 7 of n 10 → 7; saved 10 of n 10 → 0; saved −1 → 0; !haveSaved → 0; start 99 with
  n 10 → 9 (defensive clamp); start −3 → 0; n 1 → 0 always.
- `FuzzDecodeEntry(f *testing.F)`: seeds: a valid entry, the corrupt rows above; property:
  never panics; either err is nil or `errors.Is(err, ErrCorruptState)`; ok implies err nil and
  index >= 0; !ok with nil err only for a valid entry whose sha256 differs.

Constraints: change only `internal/state/store.go` and create
`internal/state/store_load_test.go`; stdlib only; `store.go` never calls `os.Stat`,
`os.ReadFile` or an unbounded `io.ReadAll(f)`; all `TestResume*` tests from the write half
keep passing.
