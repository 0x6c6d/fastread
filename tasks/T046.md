# T046: Player split-step timing (SetParts)

Phase 5 · Model: sonnet: pure fake-clock model extension with exact expected deadlines, no I/O or concurrency · Depends-on: T031

## Brief
Package `internal/state`, file `internal/state/player.go` (module `github.com/0x6c6d/fastread`).
A word wider than the screen is shown in several display steps (R20, Plan row 28: non-final
parts timed as plain words, the final part keeps trailing punctuation and `ParaEnd`). The UI
computes the parts; the `Player` owns their timing so the absolute-deadline schedule stays
drift-free. Existing API (keep every name, signature and behaviour): `NewPlayer(Config{Tokens,
Start, WPM, Size, ShowProgress, Clock})`, `Start()`, `Tick() (finished bool)` (absolute
deadlines: next deadline = previous deadline + delay; may advance several words when called
late), `Apply(a Action) (quit bool)` with pause (`remaining`), WPM change (current deadline
unchanged), Next/Prev/Home jump rule (playing → deadline = now + delay(new word); paused →
remaining = delay(new word)), `Deadline()`, `Index()`, `Len()`, `Token()`, `Playing()`,
`Finished()`, `WPM()`, `EffectiveWPM() (int, bool)`; `timing.Delay(word, wpm)`,
`timing.DelayPara(word, wpm, paraEnd)`.

Add:
```go
// SetParts sets the display steps of the current word, as computed by the UI (R20).
// nil, an empty slice or a single element means the word is one step (the default after
// every word change). Step i < last lasts timing.Delay(strings.TrimSuffix(parts[i], "-"), wpm);
// the last step lasts timing.DelayPara(parts[last], wpm, Token().ParaEnd). Parts equal to
// the current ones (nil ≡ []string{Token().Text}) change nothing. Otherwise the current step
// index is clamped to the new count and the time already spent in the current step is kept:
// playing → deadline = (deadline − old step delay) + new step delay; paused → remaining =
// max(0, new step delay − (old step delay − remaining)). No-op after Finished.
func (p *Player) SetParts(parts []string)
// Part returns the 0-based display step of the current word; Parts the number of steps (≥ 1).
func (p *Player) Part() int
func (p *Player) Parts() int
```
Rules:
- A step's delay is computed with the wpm current when the step starts (or when `SetParts`
  replaces it); a WPM change still leaves the current deadline unchanged.
- `Tick` (playing, now ≥ deadline, repeated while that holds): if `Part() < Parts()−1` →
  next step, deadline += its delay; else the word is complete (counts once for
  `EffectiveWPM`): last word → finished, as today; otherwise next word with steps reset to
  one, deadline += `DelayPara` of the new token. A step change alone never counts a word.
- Next/Prev/Home jumps that change the index reset steps to one (existing jump rule
  unchanged). Without any `SetParts` call every existing behaviour and test is unchanged.

Tests in new `internal/state/steps_test.go` (reuse the fake clock from `player_test.go`; no
real time, no sleeps; table-driven where cases repeat). `W := strings.Repeat("abcdefghij",
6)`; at 300 wpm `Delay` of a 20-letter part is 300 ms, of a 10-letter part 220 ms; the part
`X+"."` with X 20 letters lasts 600 ms; a `ParaEnd` 2-letter word 500 ms.
- `TestPlayerSteps`: tokens `aa`, `W+"."`, `bb` (last, `ParaEnd`), 300 wpm, Start at t0.
  `P3 := [20 letters + "-", 20 letters + "-", 20 letters + "."]` (cut from `W+"."`).
  Tick at t0+200ms → Index 1, Parts 1; `SetParts(P3)` → Parts 3, Part 0, `Deadline() ==
  t0+500ms`; Ticks at the deadlines → Part 1 (t0+800ms), Part 2 (t0+1400ms), then Index 2
  with Parts 1 and `Deadline() == t0+1900ms`; Tick there → finished. Further rows: calling
  `SetParts(P3)` again or `SetParts` after an Up key with equal parts leaves `Deadline()`
  unchanged; at t0+300ms (100 ms into step 0) `SetParts` with six 10-letter parts (last ends
  `.`) → `Deadline() == t0+420ms`; paused at t0+300ms, the same `SetParts`, resume at
  t0+5s → `Deadline() == t0+5s+120ms`; at Part 2 of 3, `SetParts(nil)` → Part 0, Parts 1;
  a Next jump at Part 2 → new index, Part 0, Parts 1; one late Tick at t0+1450ms from Part 0
  ends on Index 2 Part 0; `EffectiveWPM` counts the split word once; after finish
  `SetParts` changes nothing.
- `TestPlayerStepsNoDrift`: 50 tokens, every 5th `W` (others `word`, `word,`, `word.`
  cycling, last `ParaEnd`), 600 wpm, Start at t0. After `Start` and after every Tick call
  `SetParts(chunks)` where chunks cuts the current token into 20-cluster pieces, every
  non-final piece + `-` (a short token gives one piece). Loop: clock = `Deadline()` + jitter
  (0, 3, 7, 9 ms cycling), `Tick()`, until finished. After every step assert `Deadline() ==
  t0 + Σ step delays so far` exactly; at the end `Finished()`, `Index() == 49`.
