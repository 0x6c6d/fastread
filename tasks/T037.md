# T037: Block-glyph font tables from X11 misc-fixed (internal/tui/glyph)

Phase 4 · Model: sonnet: self-contained generator plus lookup API, pinned by a byte-exact regeneration diff and literal glyph rows · Depends-on: T001

## Brief
Create package `internal/tui/glyph` (module `github.com/0x6c6d/fastread`; package doc:
"Package glyph holds the embedded block-glyph font for TUI sizes 2–5.") with Go tables made
from the public-domain X11 misc-fixed fonts installed on this machine (gzip PCF files under
`/usr/share/fonts/X11/misc/`): size 2 ← `4x6-ISO8859-1.pcf.gz`, size 3 ← `6x10-ISO8859-1.pcf.gz`,
size 4 ← `7x14-ISO8859-1.pcf.gz`, size 5 ← `9x18-ISO8859-1.pcf.gz`. Their font cells are
4×6, 6×10, 7×14 and 9×18 pixels (width × (fontAscent+fontDescent)); every rune 0x20–0x7E and
0xA0–0xFF is present. No download, no new module.

Files (create exactly these four):
1. `gen.go`, first line `//go:build ignore`, `package main`, stdlib only (`compress/gzip`,
   `encoding/binary`, `go/format`, …). Flags `-fontdir` (default `/usr/share/fonts/X11/misc`)
   and `-o` (default `data.go`). PCF in short: magic `"\x01fcp"`, little-endian int32 table
   count, then per table four LE int32 (type, format, size, offset). Every table starts with
   its own LE int32 format; format bit 0x4 set → the table's further integers are big-endian.
   METRICS (type 1<<2): format bit 0x100 = compressed: int16 count, then 5 bytes per glyph,
   each minus 0x80: left bearing, right bearing, width, ascent, descent; otherwise int32
   count and per glyph 6 int16 (same order + attributes as uint16). BITMAPS (1<<3): int32
   count, int32 offsets[count], int32 sizes[4], data; row stride = ceil((rb−lb)/8) bytes
   rounded up to `1<<(format&3)`; format bit 0x8 → most significant bit is the leftmost pixel,
   else the least significant. BDF_ENCODINGS (1<<5): int16 minByte2, maxByte2, minByte1,
   maxByte1, defaultChar, then uint16 glyph indices row-major (0xFFFF = none); rune =
   byte1<<8 | byte2. BDF_ACCELERATORS (1<<8, else ACCELERATORS 1<<1): after the format,
   8 flag bytes, then int32 fontAscent, int32 fontDescent. Pixel (x, y) of a glyph bitmap
   lands in the font cell at column lb+x, row fontAscent−ascent+y. Each glyph is its full
   font cell, right-padded with blank columns to `Width(size)` (7x14 → 8, 9x18 → 10).
   Output: gofmt'ed via `go/format`, first line exactly
   `// Code generated by gen.go from the public-domain X11 misc-fixed fonts; DO NOT EDIT.`,
   a comment naming the four source files and the licence line
   `Public domain font.  Share and enjoy.`, unexported tables (e.g. per size one `[]uint16`
   of pixel-row bitmasks per rune slot). Deterministic: same fonts → byte-identical file.
   Exit ≠ 0 with a message if a file is missing or unreadable, a cell size differs from the
   above, or a required rune is absent.
2. `data.go`: the output of `cd internal/tui/glyph && GOTOOLCHAIN=local go run gen.go`,
   committed as generated (never hand-edited).
3. `glyph.go`:
   ```go
   func Rows(size int) int  // 1, 3, 5, 7, 9 for size 1..5; 0 otherwise
   func Width(size int) int // 1, 4, 6, 8, 10 for size 1..5; 0 otherwise
   func Has(r rune) bool    // 0x20 <= r <= 0x7E || 0xA0 <= r <= 0xFF
   // Block returns the glyph of r at size 2..5 as Rows(size) strings of exactly Width(size)
   // runes; cell row y shows pixel rows 2y (top) and 2y+1 (bottom): both ink '█', top only
   // '▀', bottom only '▄', neither ' '. ok is false when !Has(r) or size is not 2..5.
   // The result is shared and must not be modified by callers.
   func Block(r rune, size int) (rows []string, ok bool)
   ```
   Block runs on every frame: build all strings once (package init or `sync.Once`), then
   only index.
4. `glyph_test.go`, `TestGlyphTables`, table-driven:
   - Rows/Width for sizes 0..6 as documented.
   - Sizes 2..5 × every covered rune: ok, `len(rows) == Rows(size)`, each row exactly
     `Width(size)` runes, all from `' ' '▀' '▄' '█'`; every rune 0x21–0x7E has at least one
     non-space rune at every size; `' '` and U+00A0 are all spaces.
   - Not covered → `Has` false and `Block` not ok: 0x1F, 0x7F, 0x80, 0x9F, 0x100, `€`, `日`,
     `—`, -1; `Block('A', 1)` and `Block('A', 6)` not ok.
   - Literal rows (from the real fonts): `Block('H',2)` = `"█ █ "`, `"█▀█ "`, `"▀ ▀ "`;
     `Block('H',3)` = `"▄   ▄ "`, `"█   █ "`, `"█▀▀▀█ "`, `"█   █ "`, `"      "`;
     `Block('é',3)` = `"  ▄▀  "`, `" ▄▄▄  "`, `"█▄▄▄█ "`, `"▀▄▄▄  "`, `"      "`;
     `Block('-',4)` = three rows of 8 spaces, `" ▄▄▄▄▄  "`, three rows of 8 spaces;
     `Block('-',5)` = four rows of 10 spaces, `" ▄▄▄▄▄▄▄  "`, four rows of 10 spaces.
   If a literal row fails, fix the generator, never the expectation.

Constraints: tests never read `/usr/share/fonts`; the package imports only the standard
library and nothing from this module; do not create `third_party/` (the licence notice is a
later task); no other files.

## Verification
`scripts/verify/T037.sh` exits 0. It checks that the four source fonts exist, runs the check
command and `TestGlyphTables`, regenerates the tables into a temp file and requires a
byte-identical `data.go`, and checks the generated header, the ignore tag and the API.
Negative checks: the generator fails on a missing font directory, the package imports nothing
outside the standard library, and no test reads the system font files.
