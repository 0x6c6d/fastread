# T065: Phase 6 gate: live GUI keys e2e and the exit criterion

Phase 6 · Model: sonnet: one e2e test on the existing Xvfb helpers; the script runs the Phase 6 exit criterion · Depends-on: T063, T064

## Brief
Package `e2e` (module `github.com/0x6c6d/fastread`; every file starts with `//go:build
e2e`, `_test.go` suffix). Existing helpers (do not change signatures): `e2e/helpers_test.go`
(`buildBinary`, `stateEnv`, tmux helpers), `e2e/xvfb_test.go` (`newXvfb(t) string`,
`guiEnv(display, stateDir) []string`, `startGUI(t, display, env, bin, args...) *guiApp`,
`(*guiApp).keys(names...)` = xdotool `windowfocus --sync` + `key --delay 60`,
`wait(d) int`, `alive()`, `stderr()`, `readIndex(t, stateDir) int`).

Behaviour under test (R26 live in the GUI, R29 through the GUI): Space pause/resume;
Left/Right ±1 word when paused, ±10 when playing; Home → word 0 (pause state unchanged);
Up/Down wpm ±25; `[`/`]` size; `p`, `?` toggles; `q`, Escape, Ctrl+C quit with exit 0;
other keys (`x`, PageUp, F1, Shift+q) do nothing. On quit the word index on screen is
saved for a file source (also with `--no-resume`, which only ignores the saved start); a
later run without `--no-resume` and without `--start` resumes there; `--start N` starts at
N. xdotool key names: `space`, `Home`, `Left`, `Right`, `Up`, `Down`, `bracketleft`,
`bracketright`, `p`, `question`, `x`, `Prior`, `F1`, `shift+q`, `q`, `Escape`, `ctrl+c`.

Create `e2e/guikeys_test.go`, `TestE2EGUIKeys`: one Xvfb, one temp state dir, book file
`w000`…`w199` (one line), `--wpm 50` (1.2 s per word) unless stated; after each window
appears wait 500 ms before the first key; each run must exit 0 within 3 s of its quit key
with empty stderr; log every run's keys, exit code and saved index. Runs in order:
1. `--no-resume`: `space Home Right Right Right Left` then `q` → index 2.
2. no flags (resumes at 2): `Escape` → index r ∈ {2, 3} (at most one natural advance; 0
   or 1 would mean no resume).
3. no flags (resumes at r), playing: `Right` then at once `q` → index r+10 or r+11.
4. `--start 5`: `space Home Right Right Right Right Right`, then `Up Up Down bracketright
   bracketleft p question p question x Prior F1 shift+q` (none of these may quit or move),
   then `ctrl+c` → index 5.
5. `--start 7`: after 500 ms check still alive, then `space space space` (paused again)
   and `q` → index 7 or 8.

Constraints: create only `e2e/guikeys_test.go`; stdlib only; every external call under a
timeout; nothing left running; never the user's display or the real `~/.local/state`; whole
test well under 120 s; `go vet -tags e2e ./...` clean. If a step fails because of program
behaviour, report the keys, the expected and the seen index; do not change non-test code.
