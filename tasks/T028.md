# T028: Unicode ORP table tests (TestPosition, TestIndex)

Phase 3 · Model: sonnet: test-only against an existing, fixed definition; no security or contract decision · Depends-on: T003

## Brief
Package `internal/orp` (module `github.com/0x6c6d/fastread`) already implements the focus
(ORP) rule. Add the full acceptance table (§8 AC7, R9) as tests and fix `orp.go` only if a
row fails because the code disagrees with the definition below (never change the definition
or the API). Existing API (keep exactly):
```go
func Position(word string) int     // R9 rank of the focus among letter/digit clusters
func Index(word string) int        // grapheme-cluster index of the focus in the whole word
func Clusters(word string) []string // extended grapheme clusters (github.com/rivo/uniseg v0.4.7)
```
Definition: a *letter/digit cluster* is a grapheme cluster whose first rune satisfies
`unicode.IsLetter` or `unicode.IsDigit`; L = their number; R9: L=1 → 0, 2–5 → 1, 6–9 → 2,
10–13 → 3, 14+ → 4. `Index` = index (in `Clusters`) of the letter/digit cluster with rank
`Position`. With L = 0: both return `(n-1)/2` for n clusters (0 for `""`).

Create `internal/orp/orp_table_test.go` with one shared table `orpCases` of
`{word string; pos, idx int; focus string}` and two tests over it:
- `TestPosition`: `Position(word) == pos` for every row.
- `TestIndex`: `Index(word) == idx`, `Clusters(word)[idx] == focus` (skip the cluster check
  for `""`), and `strings.Join(Clusters(word), "") == word` (clusters never split or lose
  bytes).

Rows (word → pos, idx, focus; Go string literals):
`"a"`→0,0,`a` · `"ab"`→1,1,`b` · `"hello"`→1,1,`e` · `"wonderful"`→2,2,`n` ·
`"reading,"`→2,2,`a` · `"\"extraordinary\""`→3,4,`r` · `"internationally"`→4,4,`r` ·
`"--"`→0,0,`-` · `"—"`→0,0,`—` · `"..."`→1,1,`.` · `"…"`→0,0,`…` · `"héllo"` (precomposed
U+00E9)→1,1,`é` · `"héllo"` (decomposed)→1,1,`"é"` · `"naïve"`→1,1,`a` ·
`"«naïve»"`→1,2,`a` · `"¿Qué?"`→1,2,`u` · `"don't"`→1,1,`o` · `"👍"`→0,0,`👍` ·
`"👍👍👍"`→1,1,`👍` · `"👩‍👩‍👧"` (one cluster)→0,0,the whole word ·
`"👍🏽"`→0,0,the whole word · `"ok👍"`→1,1,`k` · `"🇩🇪"`→0,0,the whole word ·

Also add `TestIndexInRange`: for at least 30 mixed words (the table words plus `"\xff\xfe"`,
