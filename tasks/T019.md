# T019: EPUB DRM detection (encryption.xml)

Phase 2 · Model: opus: legal/DRM rule, detect and reject, never decrypt (Consequential assumption 13; Risk "DRM/legal") · Depends-on: T018

## Brief
Encrypted (DRM) EPUBs must be rejected with a clear "unsupported" error before any spine item
is read; fonts that are only obfuscated must not block loading. No decryption or
de-obfuscation code is ever written.

Existing in package `internal/input` (module `github.com/0x6c6d/fastread`; keep them):
`loadEPUB(b []byte, lim Limits) ([]string, error)` = `openZip` → `epubSpine(z, lim)
([]string, error)` (zip entry names of the linear spine items) → `z.read` each →
`xhtmlParagraphs`; `zipArchive` with `has(name) bool` and `read(name) ([]byte, error)`;
`newXMLDecoder(r io.Reader) *xml.Decoder`; `walkXML(d *xml.Decoder, maxDepth int, fn
func(tok xml.Token, depth int) error) error`; sentinels `ErrUnsupported`, `ErrCorruptEPUB`.
Test helpers (in `epub_fixture_test.go`): `type epubEntry struct{ Name string; Data []byte }`,
`epubZip(t, entries []epubEntry) []byte`, `sampleEPUBEntries() []epubEntry` (spine entries
`OEBPS/text/b.xhtml`, `OEBPS/text/c.xhtml`, `OEBPS/text/a.xhtml`; words `One first & café
Two second Three third`).

Create `internal/input/epub_drm.go`:
```go
// errDRM is returned (wrapped) for EPUBs whose content documents are encrypted.
// checkEncryption parses META-INF/encryption.xml (if present) and fails when any of the
// given spine entry names is encrypted.
func checkEncryption(z *zipArchive, spine []string, lim Limits) error
```
Rules:
- No `META-INF/encryption.xml` → nil. Parse it with `newXMLDecoder` + `walkXML(…,
  lim.MaxDepth, …)`; collect the `URI` attribute of every element whose local name is
  `CipherReference` (any namespace). Each URI is relative to the zip root: strip
  `#fragment`, `url.PathUnescape`, `path.Clean`; a leading `/` is removed.
- If any collected name equals a spine entry name → return
  `fmt.Errorf("%w: encrypted EPUB (DRM) not supported", ErrUnsupported)`; this error must
  NOT match `ErrCorruptEPUB`.
- References to non-spine entries only (fonts, images, with any `EncryptionMethod`, e.g.
  `http://www.idpf.org/2008/embedding`) → nil; fonts are never read anyway.
- A malformed encryption.xml (XML syntax error, too deep, unreadable entry) →
  error wrapping `ErrCorruptEPUB` (and keeping inner `ErrTooLarge` where it applies).
- `META-INF/rights.xml` alone does not mean encryption; ignore it.
In `epub.go`, change only `loadEPUB`: call `checkEncryption(z, spine, lim)` after
`epubSpine` and before the first `z.read` of a spine item; return its error unchanged.

Test `internal/input/epub_drm_test.go`, table-driven `TestEPUBEncrypted` (start each case
from `sampleEPUBEntries()` plus an extra `META-INF/encryption.xml` entry, standard
`urn:oasis:names:tc:opendocument:xmlns:container` and `http://www.w3.org/2001/04/xmlenc#`
namespaces, `xenc:` prefixes):
- `CipherReference URI="OEBPS/text/b.xhtml"` → `errors.Is(err, ErrUnsupported)`,
  `!errors.Is(err, ErrCorruptEPUB)`, message contains `encrypted EPUB (DRM) not supported`.
- the same with `URI="OEBPS/text/a%20b.xhtml"` for a spine entry `OEBPS/text/a b.xhtml`, with
  `URI="/OEBPS/text/c.xhtml"` and with `URI="./OEBPS/text/a.xhtml"` → unsupported.
- only `URI="OEBPS/fonts/f.otf"` (entry present, algorithm
  `http://www.idpf.org/2008/embedding`) → loads, words exactly as the sample.
- encryption.xml present with no `CipherReference` → loads; `META-INF/rights.xml` only →
  loads.
- encryption.xml cut off inside a tag → `ErrCorruptEPUB`; nested 300 deep with `MaxDepth`
  256 → `ErrCorruptEPUB` and `ErrTooLarge`.
- via `LoadFile` on a temp `drm.epub` with the first case → `ErrUnsupported`.
- the encrypted spine item is never read: give it invalid deflate data (write it with
  `CreateRaw` and garbage bytes) and still expect the DRM error, not a corrupt error.

Constraints: stdlib only; no `crypto/*` import in `internal/input` other than the existing
`crypto/sha256` (resume hash); change only
`epub_drm.go`, `epub_drm_test.go` and `loadEPUB` in `epub.go`.
