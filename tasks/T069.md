# T069: Global Definition of Done gate (D1-D17)

Phase 7 · Model: supervisor: the final gate is run by the supervisor itself, no worker; it creates nothing · Depends-on: T012, T045, T067, T068 (together they reach every other task)

## Brief
Run by the supervisor, not dispatched to a worker, when every other row of `Tasks.md` is
`done` (or `superseded`). This is both Plan.md's Phase 7 exit criterion and its Global
Definition of Done. Run `scripts/verify/T069.sh` from the repository root with the working
tree committed (only `Tasks.md`, `Improvements.md` and `.README.md.swp` may differ from
`HEAD`, otherwise D17 fails); expect it to take 15-30 minutes. It reports one labelled
line per check, in Plan order:

- D0: every other task row is `done` or `superseded`.
- D1 check (verbatim); D2 toolchain (verbatim).
- D3-D8: every named Phase 2-6 test via `passes`; D4 also runs the binary on each invalid
  flag row (`--wpm 49`, `--wpm 1501`, `--wpm x`, `--size 0`, `--size 6`, `--ui foo`,
  `--start -1`, `--start 9999`, `--bogus`: exit 2, one `fastread:` line plus usage on
  stderr, empty stdout) and `-h`/`--help`/`--version`; D5 also runs
  `scripts/verify/_dodcheck.go` (copied into a temporary `./.dodcheck.*` directory and run
  with `go run`), which checks the README AC7 ORP and AC8 `Delay` numbers directly on
  `internal/orp` and `internal/timing`; D6 also checks the golden files and the
  `TestFocusColumn` word classes; D8 the `TestLayoutFocusXAllSizes` coverage line.
- D9: the whole e2e suite (`-timeout 600s -v`) with the 14 named `--- PASS` lines, then
  no Xvfb, tmux server or `fastread` process left.
- D10-D13 verbatim; D14 verbatim plus the T012 and T066 licence scripts and the documented
  path-like rule; D15 verbatim plus "the real `~/.local/state/fastread` was not created".
- D16 report material: the `TestE2EInputTypes` `CASE name=… exit=… output=…` lines (raw,
  stdin, txt, md, epub, fb2, pdf, missing file, empty text, bad flag, scanned PDF, wrong
  extension) with their expected codes; the Wayland line (always "not run": no headless
  compositor here and the user's own session is off limits; X11 verified under Xvfb); the
  optional AC19 pixel check with `xwd` on an own Xvfb (or "not run" if `xwd` is missing).
- D17: D1 passed, `HEAD` did not move since, and no uncommitted code existed while D1 ran.
- Negative checks: a missing path-like file, `--wpm 49` and the text-less PDF must fail.

Afterwards paste the script's complete output (every `ok`/`FAIL` line plus the D4 and D16
lines it prints) into the final loop summary as the verification report (spec §7, D16).
If a line fails, the failing D line names the task area to repair (SKILL.md, Definition-of-
Done repair); do not edit this script to make it pass.
