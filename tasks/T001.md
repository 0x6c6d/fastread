# T001: Go module and timing skeleton

Phase 1 · Model: opus: creates `go.mod` and fixes the Go directive/toolchain (Consequential assumption: toolchain pins, Risk: toolchain drift) · Depends-on: T000

## Brief
Create the Go module and the first package, `internal/timing`, so later tasks have a module to
build in. Go 1.24.4 is installed; `GOTOOLCHAIN=local` must be set for every `go` command so no
newer toolchain is ever downloaded.

Files to create:
- `go.mod`: exactly `module github.com/0x6c6d/fastread`, `go 1.24.1`, and `toolchain go1.24.4`
  (or no toolchain line). No `require` lines in this task (dependencies are added later, each by
  the task that first imports it). Create it with `GOTOOLCHAIN=local go mod init
  github.com/0x6c6d/fastread` and then set the `go` line to `1.24.1`; never let the `go` line
  rise above 1.24.x.
- `internal/timing/constants.go`: the timing constants, in this one place, exported, with doc
  comments: `SentenceMul = 2.0`, `ClauseMul = 1.5`, `LongWordStep = 0.05`, `LongWordCap = 0.5`,
  `LongWordFrom = 8`, `ParagraphMul = 2.5`, plus `MinWPM = 50`, `MaxWPM = 1500`. Package doc
  comment: "Package timing computes per-word display durations. It imports only the standard
  library and must never import UI packages."
- `internal/timing/delay.go` with exactly these exported functions (signatures are a contract
  later tasks rely on):
  ```go
  // Delay returns how long word is shown at wpm words per minute. Pure function.
  func Delay(word string, wpm int) time.Duration   // == DelayPara(word, wpm, false)
  // DelayPara is Delay with the paragraph-end flag (paraEnd = last word of a paragraph).
  func DelayPara(word string, wpm int, paraEnd bool) time.Duration
  ```
  Walking-skeleton behaviour only: base = 60000/wpm milliseconds as a `time.Duration`, rounded to
  the nearest millisecond; `wpm` below `MinWPM` or above `MaxWPM` is clamped first (never divide by
  zero, never panic). Punctuation, long-word and paragraph multipliers are NOT applied yet (a
  later task adds them using the constants above); `paraEnd` is accepted and ignored for now.
  Mark that with a `// TODO(phase3): multipliers` comment.
- `internal/timing/delay_test.go`: table-driven `TestDelayBase` using only plain lowercase words
  without punctuation and at most 8 letters (so the rows stay true after multipliers are added):
  300 wpm → 200 ms, 50 → 1200 ms, 1500 → 40 ms, 600 → 100 ms, 0 → clamped to 50 (1200 ms),
  -5 → 1200 ms, 99999 → clamped to 1500 (40 ms); `DelayPara(w, 300, false) == Delay(w, 300)`.

Constraints: stdlib only (`time`); no global state; `gofmt` clean.
