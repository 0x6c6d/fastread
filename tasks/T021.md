## Brief

`fixtureFile(t, name, data) string` in `fixture_test.go` (writes `testdata/<name>` only with
`-update-fixtures`, else requires it).

`internal/input/pdf.go` rules:
- `const MaxPDFPages = 10000`. `pdf.go` is the only file importing
  `github.com/ledongthuc/pdf`, and every library call happens inside ONE
  `recoverAs(ErrCorruptPDF, func() error {…})`.
- `len(b) > lim.MaxBytes` → `ErrTooLarge`. `pdf.NewReader(bytes.NewReader(b), int64(len(b)))`:
  `errors.Is(err, pdf.ErrInvalidPassword)` → `fmt.Errorf("%w: encrypted PDF not supported",
  ErrUnsupported)`; any other error → `fmt.Errorf("%w: %v", ErrCorruptPDF, err)`.
- Do NOT use `Reader.NumPage`/`Reader.Page`/`Reader.GetPlainText` (they trust the `/Count`
  value and loop forever on self-referencing page trees). Walk the page tree yourself from
  `r.Trailer().Key("Root").Key("Pages")`: depth-first over `Kids` in order, `Type` `Pages` →
  recurse, `Type` `Page` → collect `pdf.Page{V: kid}`; recursion depth above 32 or more than
  100000 visited nodes → `ErrCorruptPDF`; stop collecting after `MaxPDFPages` pages.
- Per page `p.GetPlainText(nil)`; an error → `ErrCorruptPDF` (wrapped, page number in the
  message). Keep a running total of extracted bytes; above `lim.MaxBytes` → `ErrTooLarge`.
  The page text goes through `ParseText([]byte(text))`; append its paragraphs (page order; a
  page with text yields ≥ 1 paragraph). Never `io.ReadAll` anything.
- No paragraph with a non-space rune after all pages → `ErrNoText` (wrapped or returned as
  is; `errors.Is` must hold and `err.Error()` must contain `no extractable text`).
