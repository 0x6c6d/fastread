# T002: Tokenizer skeleton

Phase 1 · Model: haiku: one small stdlib-only file with a given signature and a table test · Depends-on: T001

## Brief
Create package `internal/tokenize` (module `github.com/0x6c6d/fastread`, already has `go.mod`).
It turns paragraphs into words. Later tasks add sanitising; this task fixes the types.

Files to create:
- `internal/tokenize/tokenize.go`, package doc: "Package tokenize splits text into words with
  paragraph-end flags. It must never import UI packages." Exactly this exported API:
  ```go
  // Token is one displayed word. ParaEnd is true for the last word of a paragraph
  // (and therefore for the last word of the whole text).
  type Token struct {
      Text    string
      ParaEnd bool
  }

  // Tokenize splits every paragraph on Unicode whitespace (unicode.IsSpace) into tokens.
  // Punctuation stays attached to its word. Paragraphs that contain no word add nothing.
  // The result is nil or empty when there is no word at all.
  func Tokenize(paragraphs []string) []Token
  ```
  Implementation hint: `strings.FieldsFunc(p, unicode.IsSpace)` per paragraph; set `ParaEnd` on
  the last token of each paragraph that produced at least one token.
- `internal/tokenize/tokenize_test.go`: table-driven `TestTokenizeBasic` with cases:
  - `nil` → no tokens; `[]string{"", "   \n\t "}` → no tokens.
  - `{"Hello wonderful world"}` → `Hello`, `wonderful`, `world` (only `world` has ParaEnd).
  - `{"Hello, world.", "Next  para\nline"}` → `Hello,` `world.`(ParaEnd) `Next` `para`
    `line`(ParaEnd) (punctuation attached, newline inside a paragraph is plain whitespace).
  - `{"a b c"}` (no-break space, em space) → `a`, `b`, `c`(ParaEnd).
  - `{"x", "", "y"}` → `x`(ParaEnd) `y`(ParaEnd).
  Compare with `reflect.DeepEqual` on `[]Token` (treat nil and empty as equal for the empty cases
  by checking `len`).

Constraints: standard library only; no package-level mutable state; `gofmt` clean.
