# T058: GUI shrink and split (R23) and the all-sizes focus invariant

Phase 6 · Model: sonnet: pure greedy shrink/split algorithm with literal expected steps and invariant tests (R23, R33) · Depends-on: T057

## Brief
Package `internal/gui` (module `github.com/0x6c6d/fastread`), file `internal/gui/layout.go`
(no build tag, no `gioui.org`). Existing (keep every name and rule): `LevelSp = [6]int{0, 20,
32, 48, 64, 96}`, `MinSp = 10`, `ShrinkStepSp = 2`, `Metrics`, `Measurer` (`Advances(clusters,
px) []fixed.Int26_6`, `Metrics(px)`), `LayoutInput{Word, Level, W, H, PxPerSp, Part, M}`,
`LayoutResult{CX, Sp, Px, Parts, Part, Text, Clusters, Advances, Focus, OriginX, FocusX,
BaselineY, TickTop, TickBottom}`, `PxOf(sp, pxPerSp)`, `Layout(in)`: today `Sp =
LevelSp[level]`, `Parts = []string{Word}`; OriginX/FocusX from the focus rule, baseline and
ticks from the LEVEL size (they must stay independent of shrinking and splitting).
Test helpers exist in `measure_test.go`: `newFontMeasurer(t)` (Go Regular via
`x/image/font/opentype`), `fixedMeasurer`.

Replace the "Sp/Parts" spot with the R23 rule (Plan row 29: shrink in 2 sp steps down to
10 sp, then split as R20):
1. A text t with clusters cs (`orp.Clusters`), focus `fi` (`orp.Index`) and advances `adv`
   at px *fits* iff `o := fixed.I(CX) − sum(adv[:fi]) − adv[fi]/2` satisfies `o >= 0 && o +
   sum(adv) <= fixed.I(W)`.
2. If the whole word fits at `PxOf(MinSp, k)`: `Sp` = the first sp of `LevelSp[L],
   LevelSp[L]−2, …, MinSp` at which it fits; `Parts = []string{Word}`. Measure MinSp first so
   a word that does not fit there is never measured at the other sizes.
3. Else `Sp = MinSp` and the word is split greedily at MinSp, exactly like the TUI rule:
   from cluster i, `j := i+1`; while `j < n` and `cand(j+1)` fits, `j++`; emit `cand(j)`;
   `i = j`. `cand(j)` = clusters `i..j` joined, plus `"-"` if `j < n` (the `-` is one more
   non-letter cluster for the focus rule and is measured as the cluster `"-"`). Every step
   has at least one cluster, so it terminates (in a tiny window a one-cluster step may
   overflow; it never panics or loops).
4. Work stays linear in the word: measure the word's clusters once at MinSp (and `"-"`
   once), keep prefix sums and letter/digit flags, and derive each candidate's focus index
   with the R9 rule (letter/digit clusters L: 1 → rank 0, 2–5 → 1, 6–9 → 2, 10–13 → 3, 14+ →
   4; none → middle cluster `(n−1)/2`, n counting the `-`) instead of calling `orp` per
   candidate. `Part` is clamped to the steps; `Text`, `Clusters`, `Advances`, `Focus`,
   `OriginX`, `FocusX` are for `Parts[Part]` at `Px = PxOf(Sp, k)`.
