# T011: E2E harness and TestE2EBasic (tmux)

Phase 1 · Model: sonnet: test harness over an existing binary, process handling with timeouts, moderate judgment · Depends-on: T010

## Brief
Create the end-to-end test package `e2e/` (build tag `e2e`, so plain `go test ./...` skips it) with
reusable helpers and the first test, `TestE2EBasic`. Later tasks add more `TestE2E*` tests on top
of these helpers, so keep their names and signatures exactly.

The binary under test is `./cmd/fastread` (module root is the parent of `e2e/`). Relevant
behaviour: `fastread [--ui tui|gui] [--wpm N] [--size N] [--no-resume] [text]` plays the words
one at a time in the terminal's alternate screen (`/dev/tty`), exits 0 at the end of the text and
restores the main screen; with no argument it reads stdin when stdin is not a TTY. At `--size 1`
the word is plain text on one row (at larger sizes it becomes block glyphs, so the e2e tests in
this task always pass `--size 1`).

Files to create (every file starts with `//go:build e2e`, package `e2e`, `_test.go` suffix only):
- `e2e/helpers_test.go`:
  ```go
  // buildBinary runs `go build <buildArgs...> -o <dir>/fastread ./cmd/fastread` from the module
  // root (once per distinct buildArgs per test binary run, cached) and returns the path.
  func buildBinary(t *testing.T, buildArgs ...string) string
  // stateEnv returns "XDG_STATE_HOME=<t.TempDir()>" so no test touches the real state dir.
  func stateEnv(t *testing.T) string
  type tmuxSession struct{ /* socket name, session name, t */ }
  // newTmux starts an isolated tmux server (`tmux -L fastread-e2e-<pid>-<n> -f /dev/null`)
  // with one detached session of size w x h running `sh -c shellCmd`; t.Cleanup kills the
  // server. Every tmux call runs under a context timeout (10 s).
  func newTmux(t *testing.T, w, h int, shellCmd string) *tmuxSession
  // capture returns the visible pane (`capture-pane -p`, plus `-e` when escapes is true).
  func (s *tmuxSession) capture(escapes bool) string
  // sendKeys sends tmux key names (e.g. "q", "Space", "C-c", "Escape").
  func (s *tmuxSession) sendKeys(keys ...string)
  // resize resizes the window (`resize-window -x w -y h`).
  func (s *tmuxSession) resize(w, h int)
  // waitFor polls capture(false) every 20 ms until cond is true or timeout; returns the last
  // screen and whether cond became true.
  func (s *tmuxSession) waitFor(cond func(screen string) bool, timeout time.Duration) (string, bool)
  // watchWords polls every 20 ms until a line equal to "EXIT:<n>" appears or timeout, and
  // returns, in order without consecutive duplicates, every trimmed screen line that is one of
  // words, plus the exit code (-1 on timeout).
  func (s *tmuxSession) watchWords(words []string, timeout time.Duration) (seen []string, exit int)
  ```
  Shell commands use the pattern `env <stateEnv> <bin> <args>; echo "EXIT:$?"; sleep 600` so the
  pane survives the process and the exit code is visible; quote arguments with a helper that
  single-quotes for `sh`.
- `e2e/basic_test.go`: `TestE2EBasic` with two subtests (80×24 each, own tmux server each):
  - `raw`: `<bin> --ui tui --no-resume --size 1 --wpm 60 'Hello wonderful world'` → `watchWords`
    (timeout 20 s) sees exactly `Hello`, `wonderful`, `world` in that order and exit 0.
  - `stdin`: `printf 'a b c' | <bin> --no-resume --size 1 --wpm 60` → sees `a`, `b`, `c` in order,
    exit 0.
  On failure log the last captured screen.

Constraints: needs only `tmux` and Go; skip nothing (if tmux is missing, fail with a clear
message); never use the default tmux server or the user's sessions; no fixed sleeps longer than
the 20 ms poll; whole test well under 120 s; `go vet -tags e2e ./...` clean.

## Verification
`scripts/verify/T011.sh` exits 0. It runs the check command, `go vet -tags e2e`, and Plan.md's
Phase 1 exit criterion (`check && GOTOOLCHAIN=local go build ./... && go test -tags e2e -count=1
-timeout 120s -run '^TestE2EBasic$' ./e2e/` with `--- PASS: TestE2EBasic` in the output), then
checks that no tmux server named `fastread-e2e-*` and no `fastread` process is left and that the
real `~/.local/state/fastread` was not created.
