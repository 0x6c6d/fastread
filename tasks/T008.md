# T008: GUI skeleton (Gio window, nogui stub)

Phase 1 · Model: opus: Gio pins and the `app.Main`/`finish` exit path (Consequential assumptions 4–5, Risks: GUI exit path, Gio v0.10.3 newness, toolchain drift) · Depends-on: T004

## Brief
Create package `internal/gui`, the only package allowed to import `gioui.org`. It must build in
three configurations: default cgo build (real Gio window), `-tags nogui`, and `CGO_ENABLED=0`
(both get a stub without any Gio code). Exact focus alignment, ticks, shrink/split, progress/help
and the full key set come in later tasks; this task opens a minimal window.

Existing API you use: `internal/state`: `type Player` with `p.Start()`, `p.Tick() (finished
bool)`, `p.Apply(a state.Action) (quit bool)`, `p.Deadline() time.Time`, `p.Index() int`,
`p.Token() tokenize.Token` (`.Text`), `p.Size() int`; `state.ActQuit`.

Dependencies: `GOTOOLCHAIN=local go get gioui.org@v0.10.3 golang.org/x/image@v0.36.0` (exact pins,
never `@latest`). Afterwards `go.mod` must still say `go 1.24.x`, no toolchain above go1.24, and
keep `golang.org/x/sys v0.41.0` and `golang.org/x/term v0.40.0`. The Gio v0.10.3 API is in
`$(go env GOMODCACHE)/gioui.org@v0.10.3` (read it there; no web access needed).

Files to create:
- `internal/gui/gui.go` (no build tag, imports no Gio package): package doc "Package gui is the
  Gio window UI; it is the only package that imports gioui.org." and
  ```go
  type Options struct {
      Getenv func(string) string // nil -> os.Getenv; used for DISPLAY / WAYLAND_DISPLAY
  }
  var (
      ErrUnavailable = errors.New("GUI not available in this build (built with nogui or without cgo)")
      ErrNoDisplay   = errors.New("no display: neither DISPLAY nor WAYLAND_DISPLAY is set")
  )
  ```
  plus an unexported helper that reports whether DISPLAY or WAYLAND_DISPLAY is non-empty.
- `internal/gui/stub.go`, first line `//go:build nogui || !cgo`:
  `func Run(ctx context.Context, p *state.Player, opts Options, finish func(last int, err error)) error`
  returns `ErrUnavailable` and never calls `finish`.
- `internal/gui/window.go`, first line `//go:build !nogui && cgo`, same `Run` signature:
  1. Getenv nil → `os.Getenv`. No DISPLAY and no WAYLAND_DISPLAY → return `ErrNoDisplay`
     synchronously, before any Gio call, without calling `finish`.
  2. Otherwise start the window loop in a goroutine, then call `app.Main()` (never returns on
     Linux); `return nil` after it only to satisfy the compiler.
  3. The window goroutine calls `finish(p.Index(), err)` exactly once (guard with `sync.Once`):
     `q`, Esc or Ctrl+C key → `p.Apply(state.ActQuit)`, err nil; the window close button
     (`app.DestroyEvent` with nil `Err`) → err nil; `DestroyEvent.Err` non-nil → that error;
     end of text (`p.Tick()` finished) → err nil; `ctx` done → err nil (a helper goroutine waits
     on `ctx.Done()` and calls `w.Invalidate()` so the loop notices); a panic in the window
     goroutine is recovered → `fmt.Errorf("gui: internal error: %v", r)`.
  4. Window: title `fastread`, size 600×300 dp, resizable. Each `app.FrameEvent`: fill black,
     draw the current word in white, centred, at a size derived from `p.Size()` (20/32/48/64/96
     sp for levels 1–5); call `p.Start()` once on the first frame; `p.Tick()` each frame;
     schedule the next frame with `op.InvalidateCmd{At: p.Deadline()}`.
  5. Font: embedded Go Regular only, `golang.org/x/image/font/gofont/goregular.TTF` parsed with
     `gioui.org/font/opentype`, shaper built with `text.NewShaper(text.NoSystemFonts(),
     text.WithCollection(...))`. No system fonts.
- `internal/gui/gui_test.go` (no build tag): `TestRunNoDisplay`: Getenv returning "" for every
  key → `Run` returns a non-nil error at once, `errors.Is(err, ErrNoDisplay) ||
  errors.Is(err, ErrUnavailable)`, the message has no newline, `finish` was never called.
- `internal/gui/stub_test.go` (`//go:build nogui || !cgo`): `TestStubUnavailable`: with Getenv
  giving `DISPLAY=:0`, `errors.Is(err, ErrUnavailable)`, `finish` not called.
- `internal/gui/window_test.go` (`//go:build !nogui && cgo`): `TestWindowNoDisplay`: empty env →
  `errors.Is(err, ErrNoDisplay)`. Tests must never open a window.

Constraints: no file outside `internal/gui/` may import `gioui.org`; `gui.go` and `stub.go`
import no Gio package; no `os.Exit` in this package (the caller's `finish` exits).
