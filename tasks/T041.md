# T041: Long-word splitting and the focus-column invariant

Phase 4 · Model: sonnet: pure greedy algorithm with literal expected parts and invariant tests (R16, R20) · Depends-on: T039, T040

## Brief
Package `internal/tui` (module `github.com/0x6c6d/fastread`). Existing (keep):
```go
type Frame struct { W, H int; Cells [][]Cell; Size int } // Size = level drawn, 0 = too small
type Model struct { Word string; Size int; Paused, ShowProgress, ShowHelp bool
    Index, Total, WPM, EffectiveWPM int }
func Render(m Model, w, h int) Frame
func EffectiveSize(word string, size, w, h int) int // already guarantees a 2-glyph step fits
```
Geometry (keep): level 1: the focus cluster (`orp.Index`) starts at column w/2, cluster cell
width = max(1, `uniseg.StringWidth`). Size s ≥ 2: `W := glyph.Width(s)`, glyph box k starts
at `w/2 - W/2 + (k-fi)*W`, the focus box is all `StyleFocus`.

Add R20 splitting (Plan row 28):
1. `Model.Part int` (0-based display step) and `Frame.Parts int` (number of steps; 0 when
   too small).
2. In `layout.go`:
   ```go
   // Split returns the display steps of word at size level size (1..5, from EffectiveSize)
   // and width w. A text t fits iff, with fi = orp.Index(t) over its clusters cs:
   // level 1: sum(width cs[:fi]) <= w/2 and w/2 + sum(width cs[fi:]) <= w;
   // size >= 2: fi*W <= w/2-W/2 and w/2-W/2 + (len(cs)-fi)*W <= w.
   // Greedy over the word's clusters c[0..n): from i, j := i+1; while j < n and
   // cand(j+1) fits, j++; emit cand(j); i = j. cand(j) = join(c[i:j]) + "-" if j < n,
   // else join(c[i:j]). A word that fits is one step equal to the word; "" → [""].
   func Split(word string, size, w int) []string
   ```
   Every step has at least one cluster, so it always terminates. Work must stay linear in
   the word: segment the word once (`orp.Clusters`), keep per-cluster width and
   letter/digit flags, and derive each candidate's focus index with the same rule as
   `orp.Index` (R9 rank 1→0, 2–5→1, 6–9→2, 10–13→3, 14+→4 among letter/digit clusters; none
   → middle cluster `(n-1)/2`, the appended `-` counting as one non-letter cluster) instead
   of calling orp on every candidate.
3. `Render`: `s := EffectiveSize(m.Word, m.Size, w, h)` (whole word); `parts := Split(...)`;
   `p := clamp(m.Part, 0, len(parts)-1)`; draw `parts[p]` with its own `orp.Index`;
   `Frame.Parts = len(parts)`.
4. Race constant for timing bounds: `internal/tui/race_on_test.go` (`//go:build race`,
   `const raceEnabled = true`) and `race_off_test.go` (`//go:build !race`, `false`).
