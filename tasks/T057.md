API (exact names; doc comments state the rounding rule):
```go
var LevelSp = [6]int{0, 20, 32, 48, 64, 96} // sp per size level 1..5
const ( MinSp = 10; ShrinkStepSp = 2; TickGapPx = 4; TickWidthPx = 2 )
type Metrics struct{ Ascent, Descent fixed.Int26_6 } // both positive, px
type Measurer interface { // measures grapheme clusters in the embedded Go Regular font
    Advances(clusters []string, px fixed.Int26_6) []fixed.Int26_6 // one per cluster
    Metrics(px fixed.Int26_6) Metrics
}
type LayoutInput struct {
    Word    string
    Level   int     // clamped to 1..5
    W, H    int     // window px; values < 1 count as 1
    PxPerSp float32 // from unit.Metric; <= 0 counts as 1
    Part    int     // display step, clamped to [0, len(Parts)-1]
    M       Measurer
}
type LayoutResult struct {
    CX        int             // W/2, integer division
    Sp        int             // font size used, sp
    Px        fixed.Int26_6   // PxOf(Sp, PxPerSp)
    Parts     []string        // display steps; []string{Word} for now
    Part      int
    Text      string          // Parts[Part]
    Clusters  []string        // orp.Clusters(Text)
    Advances  []fixed.Int26_6 // M.Advances(Clusters, Px)
    Focus     int             // orp.Index(Text)
    OriginX   fixed.Int26_6   // pen x of the first cluster
    FocusX    fixed.Int26_6   // centre of the focus cluster
    BaselineY fixed.Int26_6
    TickTop, TickBottom image.Rectangle
}
func PxOf(sp int, pxPerSp float32) fixed.Int26_6 // Int26_6(math.Round(float64(sp)*float64(pxPerSp)*64))
func Layout(in LayoutInput) LayoutResult
```
Rules (Plan row 29):
- `L` = clamped level, `k` = PxPerSp. In this task `Sp = LevelSp[L]`, `Parts =
  []string{Word}` (shrink/split is the next task: keep it one replaceable spot).
- `prefix` = sum of `Advances[:Focus]`, `fa = Advances[Focus]` (0 without clusters).
  `OriginX = fixed.I(CX) − prefix − fa/2` (Go integer division on 26.6), `FocusX = OriginX +
  prefix + fa/2` (== `fixed.I(CX)`; the true centre is off by ≤ 1/128 px).
- Vertical metrics always from the LEVEL size: `mt := M.Metrics(PxOf(LevelSp[L], k))`,
  `BaselineY = fixed.I(H/2) + (mt.Ascent − mt.Descent)/2` (same for every word).
- Ticks: `base := BaselineY.Round()`, `a := mt.Ascent.Ceil()`, `d := mt.Descent.Ceil()`,
  `tl := max(2, a/3)`; `TickTop = image.Rect(CX−1, base−a−TickGapPx−tl, CX+1,
  base−a−TickGapPx)`, `TickBottom = image.Rect(CX−1, base+d+TickGapPx, CX+1,
  base+d+TickGapPx+tl)`.
- Never panics: empty word (`Parts == [""]`, `OriginX == FocusX == fixed.I(CX)`), W/H ≤ 0,
  level 0 or 9, PxPerSp 0.
