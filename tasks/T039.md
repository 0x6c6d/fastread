# T039: Guide ticks and the too-small screen

Phase 4 · Model: sonnet: two small pure rendering rules with exact table tests · Depends-on: T038

## Brief
Package `internal/tui` (module `github.com/0x6c6d/fastread`). Existing (keep):
```go
type Style uint8 // StylePlain, StyleFocus, StyleTick
type Cell struct { Text string; Style Style; Cont bool } // Text "" = blank cell
type Frame struct { W, H int; Cells [][]Cell; Size int } // Cells[y][x]; Size 0 = nothing drawn
type Model struct { Word string; Size int; Paused, ShowProgress, ShowHelp bool
    Index, Total, WPM, EffectiveWPM int }
func Render(m Model, w, h int) Frame
func EffectiveSize(word string, size, w, h int) int // 0 when w < 20 or h < 5
```
Render geometry today: `s := EffectiveSize(...)`, `R := glyph.Rows(s)` (1,3,5,7,9 for sizes
1–5, package `internal/tui/glyph`), word rows y0..y0+R−1 with `y0 := h/2 - (R-1)/2`; the
focus is on column w/2; rows 0 and h−1 are reserved for help and progress.

Add to `render.go`:
1. R19 guide ticks: whenever s ≥ 1, cells (w/2, y0−1) and (w/2, y0+R) get `Text "│"`
   (U+2502) and `StyleTick`. They depend only on s, w, h: identical whether `Paused` is true
   or false, and whatever `ShowProgress`/`ShowHelp` are. No other cell is ever `StyleTick`.
2. R17 too-small screen: `const TooSmallText = "terminal too small"`. When s == 0 and
   w > 0 and h > 0: the text is written on row h/2 starting at column max(0, (w−18)/2),
   one cell per rune, clipped at the right edge, `StylePlain`; every other cell blank; no
   ticks, no focus. w ≤ 0 or h ≤ 0 → a frame of max(w,0) × max(h,0) blank cells, no panic.

Tests, `internal/tui/ticks_test.go`, table-driven:
- `TestTicks`: words `a`, `Hello`, `naïve`, `日本` × sizes 1–5 × sizes 80×24, 121×30,
  40×8, 20×5 × `Paused` false/true × `ShowProgress` false/true: exactly two `StyleTick`
  cells, both at x == w/2 with Text `│`, at rows y0−1 and y0+R where R =
  `glyph.Rows(frame.Size)` and y0 is the first row holding a `StyleFocus` cell; R rows hold
  `StyleFocus` cells between them; both tick rows are within 1..h−2; the paused frame equals
  the playing frame cell by cell. Spot rows at 80×24 by `Frame.Size`: 1 → ticks on rows 11
  and 13; 3 → rows 9 and 15; 5 → rows 7 and 17; at 40×8 size 2 → rows 2 and 6; at 20×5
  size 1 → rows 1 and 3.
- `TestTooSmall`: (w×h) 19×4, 19×24, 80×4, 18×5, 5×2, 1×1, 0×0, −3×7 → `Frame.Size == 0`,
  no `StyleFocus` or `StyleTick` cell, `len(Cells) == max(h,0)` and every row `max(w,0)`
  long; when w > 0 and h > 0 the concatenated row h/2 trimmed of spaces is the prefix of
  `terminal too small` that fits (19×4 → row 2 is `terminal too small ` from column 0;
  80×4 → text starts at column 31; 5×2 → row 1 is `termi`); all other rows blank. Negative
  boundary: 20×5 is not too small (`Size == 1`, focus at column 10, row 2).

Constraints: change only `internal/tui/render.go` (and `layout.go` if needed) and create
`internal/tui/ticks_test.go`; earlier internal/tui tests must keep passing unchanged; pure, no
I/O.
