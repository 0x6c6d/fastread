# T045: Phase 4 gate: frame performance and render invariants

Phase 4 · Model: sonnet: test-only performance bound, benchmark and a property test over already-verified code; the script also runs the Phase 4 exit criterion · Depends-on: T044

## Brief
Package `internal/tui` (module `github.com/0x6c6d/fastread`). Existing (do not change
non-test code; if a test exposes a bug, report the failing input and output):
```go
type ColorMode int // ColorNone, Color16, Color256, ColorTrue
type Style uint8   // StylePlain, StyleFocus, StyleTick
type Cell struct { Text string; Style Style; Cont bool }
type Frame struct { W, H int; Cells [][]Cell; Size, Parts int } // Size 0 = too small
type Model struct { Word string; Size int; Paused, ShowProgress, ShowHelp bool
    Index, Total, WPM, EffectiveWPM, Part int }
func Render(m Model, w, h int) Frame
func Encode(f Frame, mode ColorMode) []byte
func EffectiveSize(word string, size, w, h int) int
func Split(word string, size, w int) []string
```
Also existing: `glyph.Width(size)`, `glyph.Rows(size)` (package `internal/tui/glyph`) and the
test constant `raceEnabled` (true under `-race`). Measured focus column of a frame = min x of
its `StyleFocus` cells, plus `glyph.Width(f.Size)/2` when `f.Size >= 2`.

Create:
1. `internal/tui/perf_test.go`:
   - `TestRenderFast` (§5 performance, AC28): `bound := 20 * time.Millisecond`, ×10 when
     `raceEnabled`. For sizes 1–5 × words `Hello`, `wonderful`, `naïve`, `日本語の本`,
     `strings.Repeat("abcdefghij", 6)` × frames 80×24 and 200×60, both toggles on: the
     average of `Render` + `Encode(…, ColorTrue)` over 50 iterations is below `bound`.
     A 100 000-letter word, last part (`Part: 1 << 20`), 80×24, size 1: one
     `Render` + `Encode` is below 10×`bound`.
   - `BenchmarkRenderFrame`: `Render(Model{Word: "wonderful", Size: 3, ShowProgress: true,
     ShowHelp: true, Index: 41, Total: 1000, EffectiveWPM: 300}, 120, 40)` then
     `Encode(f, ColorTrue)` per iteration; `b.ReportAllocs()`.
2. `internal/tui/invariants_test.go`, `TestRenderInvariants`: deterministic
   `math/rand/v2` (`rand.New(rand.NewPCG(1, 2))`), at least 3000 cases. Word = 1–40 picks
   from the pool `a b c x y z H é ï 0 7 , . - " ( ) « » ¿ — “ ” 日 本 한 👍 👩‍👩‍👧 🇩🇪`
   plus `"e\u0301"`, `"\u0301"`, `"\u200b"`, `"\x1b"`, `"\u202e"`, `"\x9b"`, `"\t"`;
   `Size` −1..6, w −2..200, h −2..60, `Part` −1..5, random toggles, `Index` 0..999,
   `Total` 1..1000, `EffectiveWPM` 0..1500. For every case (no panic allowed):
   `len(Cells) == max(h,0)`, every row `max(w,0)` cells; if w < 20 or h < 5: `Size == 0`,
   `Parts == 0`, no `StyleFocus`/`StyleTick` cell; else `Size == EffectiveSize(word, size,
   w, h)`, `1 <= Size <= max(1, min(size, 5))`, `Parts == len(Split(word, Size, w))`,
   measured focus column == w/2, exactly two `StyleTick` cells, both in column w/2 and in
   rows 1..h−2; every `Cont` cell has a non-`Cont` cell directly left of it; for all four
   colour modes `Encode` output is valid UTF-8 and, after removing every match of
   `\x1b\[[0-9;]*[Hm]`, contains no rune in U+0000–U+001F, U+007F–U+009F, U+202A–U+202E,
   U+2066–U+2069. Log the case count exactly as `t.Logf("cases: %d", n)`.

Constraints: create only these two test files; stdlib `testing` only (plus the module's
own packages); no sleeps.
